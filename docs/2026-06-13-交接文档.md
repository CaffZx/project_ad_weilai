### 2. 决策批次面板 7 bug + 缺口 1（`889a0db`）
- B1 `_renderSynthesis` 用 `vm.executable`（原 `state` 未定义 → 汇总 tab ReferenceError）。
- B2 ViewModel `_itemDefaults` 加 `...item` 透传（natural_rank/confirm_status 等被剥）；后端 `_item_from_skipped` 补 keyword_count。
- B3 localStorage GC 正确解析 run_id（原 `parseInt` 恒判过期，误删当前审核态）。
- B5 `jumpToDetail` 门禁 `mode` → `executable`（统一）。
- B7 预算「已勾选合计」遍历 `_campaignItems` 全集（原 `_filteredItems` 漏算被筛掉的）。
- B6 `onComplete` 用真实 ctx 派生三态/executable（原硬编码 B 态）。
- 缺口 1 C 态新增「放弃本次分析」按钮 → `/decision/cancel-event`。
- 实时切 tab 重复触发：`_campaignRealtimeRunning` 标志（await 期间 `_campaignPanelAPI` 为 null，切回 tab 会覆盖正在跑的面板并撞幂等锁）。

### 3. 缓存按 filter 分 key（`ecc207e`）
- 根因：`_ensure_data` 的 `meta_filter` 分支直接 `return fetch(...)`，**不读不写缓存** → 同 ASIN 当天每次「加载分析」都重拉 MCP/Doris。
- 修：`redis_cache` key 加 `:f<md5(sorted(meta_filter))>` 维度；`_ensure_data` filter 分支三级查找（本 filter 缓存 → 全量超集复用 → miss 才 fetch）；refresh 删本 filter + 全量 key。
- 运维注意：Redis 未起时只剩 30s 进程内 LRU，缓存几乎无效。

### 4. ERP 执行层全链路落库接线（`53fa5b3` + 未提交 mappers）
**目标**：让快照轨（B 态读库）拿到完整数据。表结构经核对 **0 加列**（`docs/ERP数据库改造方案.md` 的 DDL 已落地，含 synthesis 三表/card 新列/summary 新列）。
- `auto_push`：payload 带 overview/synthesis/new_campaigns/skipped。
- `models`：`SuggestCardCanonical` +campaign_key/keyword_class/review_level/is_core/perf_json/is_prefiltered/prefilter_reason；`CanonicalRun` +overview_text/synthesis/create_count。
- `mappers`：cards 扩展（adjustments + **新增 CREATE 卡 + 预过滤 prefiltered 卡**）；提取 overview/synthesis；新增/预过滤卡 `campaign_id=NULL`（避免撞 `uk(decision_id,campaign_id)`）。
- `repository`：summary 写 `analysis_overview`/`create_count`；card 写 6 新列；新增 `_upsert_synthesis`（写 reason_group/member/special，member.suggest_card_id 用 card_id）；read_snapshot 读 synthesis 三表；pending 行主键种子改 `card_id`。
- `campaign_viewmodel.from_db_snapshot`：读 synthesis 三表组装；`target_budget` 取 `decision.daily_budget_suggest`（不在 summary 冗余存）。
- **batch_no**（未提交）：从 run_id 派生本地 `YYYYMMDD-HHMM-序号`（复刻旧格式、与历史 7 天一致、重试稳定），与 decision_id 解耦。
- **confidence_level**（未提交）：原 `to_int("high")=None → _confidence_level→"low"` 把所有卡写成 low；改为直接用字符串 high/medium/low。

### 5. 前端展示修复（未提交 render.js / panel.js）
- reason 完整显示在卡片正文（`white-space:pre-wrap`），不截断、不在展开详情里重复。

### 6. synthesis 截断修复（未提交 reasoner.py）
- 现象：「AI 汇总合成失败: Unterminated string」→ synthesis 0 组。

- 修：synthesis 输入只留语义字段（删 bid/budget/数值/元数据）；`max_tokens`→16384、timeout→240。
