# 协作指南

文件级引用关系与修改注意见 [项目模块与文件说明.md](项目模块与文件说明.md)。

## 模块归属


| 模块        | 路径                                          | 修改范围                              |
| --------- | ------------------------------------------- | --------------------------------- |
| HTTP 入口   | `ad-direction-agent/app/api/`               | 路由与参数；业务委托 `WorkflowOrchestrator` |
| 工作流步骤     | `ad-direction-agent/app/workflow/steps/`    | 四层向导各步实现                          |
| LangGraph | `ad-direction-agent/app/agents/`            | 节点、图、Bridge（默认关闭）                 |
| 领域逻辑      | `ad-direction-agent/app/core/`              | 评分、校验、决策包、场景                      |
| 数仓        | `ad-direction-agent/app/data/db_adapter.py` | SQL 与字段映射                         |
| 规则        | `ad-direction-agent/app/rules/`             | PN/KE/OA/BM/CROSS                 |
| LLM       | `ad-direction-agent/app/llm/reasoner.py`    | Prompt、解析、运营文案清洗                  |
| 策略 AI     | `ad-purpose-agent/`                         | 勿在 direction-agent 重复实现目的/词类      |
| 前端        | `ad-direction-agent/demo/`                  | 仅 UI                              |
| 配置        | `app/config/*.toml`                         | **以 .toml 为准**                    |


## 分支建议

- `main` / `master`：可演示版本
- 功能分支：`feat/<模块>-<简述>`
- 勿在未沟通情况下修改 `app/models/layers.py` 响应字段（破坏 Demo）

## 本地开发

协作开发优先 `--data-source mock`，避免占用共享数仓连接。

```bash
cd ad-direction-agent
pytest tests/ -q
```

## LangGraph 开关

`USE_LANGGRAPH=false`（默认）：走 `app/workflow/steps` → 与历史行为一致。  
`USE_LANGGRAPH=true`：经 `app/agents/bridge.py` 单步执行图节点，需通过 parity 测试后再默认开启。

## API 约定

旧版根路径 `/recommend`、`/validate`、`/confirm` 已移除。新功能请使用四层向导 API（`strategy` / `tactics` / `diagnosis` / `execution` / `wizard`）。策略层 AI 知识库见 `ad-purpose-agent/knowledge_base/`。
