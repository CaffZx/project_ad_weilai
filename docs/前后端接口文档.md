> **最后更新**: 2026-06-06

> **分支**: chenv3.0

## 1. 概述

| 项目 | 值 |
|------|-----|
| **Base URL** | `http://{host}:{port}/api/v1/agent/ad-direction` |
| **健康检查** | `GET /health`（不在 API 前缀下） |
| **前端入口** | `demo/ad-asisitant-agent.html`（主看板）+ `demo/campaign_test.html`（Campaign 调试） |
| **内容类型** | 均为 `application/json`，chat 为 `text/event-stream`（SSE） |
| **超时** | 前端 `callAPI` 默认 timeout 因调用而异（10s–5min） |

## 3. 主看板：ad-asisitant-agent.html

### 3.0 ASIN 输入（左侧栏顶部）

| 前端触发 | 输入 ASIN 后点击「加载分析」按钮 → `loadAll()` |
|----------|----------|
| **涉及端点** | 依次调用 strategy → diagnosis（并行）→ tactics → execution → P3（见下各节） |
| **days 参数** | 全局时间窗口，前端从左侧栏下拉框读取（默认 7），随所有 POST 请求发送 |

---

### 3.1 战略层（Tab 左侧配置区，始终可见）

#### 3.1.1 加载战略选项

| 前端触发 | 「加载分析」→ `loadStrategy()` |
|----------|----------|
| **端点** | `POST /api/v1/agent/ad-direction/strategy/options` |
| **请求体** | `{"asin": "B0B7S3PWWB", "days": 7}` |
| **响应** | `StrategyOptionsResponse` |
| | `asin: str` |
| | `dimensions: [{id, label, description, options: [{value, label}], selection_type: "radio"}]` — 3 个维度 |
| | `current_selection: {product_level, product_stage, season_stage} \| null` |
| | `data_ok: bool` |
| | `missing_fields: [str]` |
| | `partial_failures: [str]` |
| **前端行为** | 渲染 3 组 radio 单选按钮（产品等级 / 产品阶段 / 季节阶段）；已有 long_term_config 则自动回填 |
| **文件** | [app/api/strategy.py](ad-direction-agent/app/api/strategy.py) |

#### 3.1.2 保存战略

| 前端触发 | 战略区「保存」按钮 → `confirmStrategy()` |
|----------|----------|
| **端点** | `POST /api/v1/agent/ad-direction/strategy/confirm` |
| **请求体** | `{"asin": "B0B7S3PWWB", "product_level": "头部", "product_stage": "推进期", "season_stage": "旺季准备"}` |
| **响应** | `{"asin": "B0B7S3PWWB", "accepted": true, "config_saved": true, "next_layer": "tactics"}` |
| **前端行为** | `accepted=true` → 显示「已保存」绿色徽章，解锁 Tab1（策略推荐），自动调用 `loadTactics()` |
| | `accepted=false` → 弹窗提示 `reject_reason` |

### 3.2 策略层（Tab1 — 广告目的与关键词推荐）

#### 3.2.1 加载策略推荐

| 前端触发 | Tab1 首开 / 战略保存后 / 「加载分析」→ `loadTactics()` |
|----------|----------|
| **端点** | `POST /api/v1/agent/ad-direction/tactics/options` |
| **请求体** | `{"asin": "B0B7S3PWWB", "days": 7}` |
| **响应** | `TacticsOptionsResponse` |
| | `asin: str` |
| | `dimensions: [{id, label, description, options, selection_type: "multi_select", recommendations: [str], recommendation_reason: str}]` |
| | `strategy_context: StrategyConfirmRequest \| null` |
| | `current_selection: {ad_purposes, target_keyword_strategy} \| null` |
| | `target_scores: [{purpose, score, level}]` — 4 个广告目的评分卡 |
| | `keyword_analysis: [{keyword_text, search_volume, ...}]` — 关键词分析表 |
| | `llm_status: "ok" \| "degraded" \| "failed"` |
| | `data_completeness: {ad_data, keywords, competitors, ...}` |
| | `scoring_error: str` |
| **前端行为** | 渲染多选复选框（广告目的 ×4 + 关键词策略 ×5），AI 推荐项打橙色标记 |
| | 渲染目标评分卡片（引流型/转化型/排名型/盈利型，各带进度条+等级标签） |
| | 渲染关键词监控表（排名/搜索量/CPC/ACOS） |
| **文件** | [app/api/tactics.py](ad-direction-agent/app/api/tactics.py) |

#### 3.2.2 AI 重新推荐（策略层）

| 前端触发 | Tab1 「AI 重新推荐」琥珀色按钮 → `refreshTacticsRecommendations()` |
|----------|----------|
| **端点** | `POST /api/v1/agent/ad-direction/tactics/recommend` |
| **请求体** | `{"asin": "B0B7S3PWWB", "days": 7}` |
| **响应** | `dict`（与 tactics/options 的推荐部分结构一致，不含 option 元数据） |
| **前端行为** | 刷新复选框推荐标记 + 评分卡 + 关键词表；不清除已保存的当前选择 |

#### 3.2.3 保存策略

| 前端触发 | Tab1 「保存」按钮 → `confirmTactics()` |
|----------|----------|
| **端点** | `POST /api/v1/agent/ad-direction/tactics/confirm` |
| **请求体** | `{"asin": "B0B7S3PWWB", "ad_purposes": ["转化型", "引流型"], "target_keyword_strategy": ["长尾词", "大词"]}` |
| **响应** | `{"asin": "B0B7S3PWWB", "accepted": true, "config_saved": true, "next_layer": "diagnosis"}` |
| **前端行为** | `accepted=true` → 解锁 Tab2（数据监控）+ Tab3（ACOS预算），显示 P3 手动覆盖输入框，调用 `loadMainInsightPanels()` |

### 3.3 诊断层（Tab2 — 数据监控）

#### 3.3.1 加载诊断数据

| 前端触发 | Tab2 首开 / 策略保存后 / 「加载分析」→ `loadDiagnosis(false)` |
|----------|----------|
| **端点** | `POST /api/v1/agent/ad-direction/diagnosis` |
| **请求体** | `{"asin": "B0B7S3PWWB", "refresh": false, "days": 7}` |
| **响应** | `DiagnosisResponse` |
| | `asin: str` |
| | `data_summary: dict` — 业务指标摘要（ACOS / CPC / CVR / 销量 / 利润率等） |
| | `strategy_context: StrategyConfirmRequest \| null` |
| | `tactics_context: TacticsConfirmRequest \| null` |
| | `alert_signals: [str]` — 预警信号列表（如「ACOS 超标 40%」「库存不足」） |
| | `metric_board: {metric_id: {value, status, threshold}} \| null` — 北极星指标看板 |
| | `keywords: [{keyword_text, natural_rank, sp_rank, acos, cpc, ...}]` |
| | `trend_data: [{date, acos, cpc, sales, ...}]` — ECharts 趋势图数据 |
| | `data_completeness: dict` |
| **前端行为** | 渲染北极星指标看板（指标卡 + 绿/黄/红状态灯） |
| | 渲染预警信号列表 |
| | 渲染 ECharts 趋势折线图（ACOS/CPC/销量） |
| | 渲染关键词监控详情表 |
| **文件** | [app/api/diagnosis.py](ad-direction-agent/app/api/diagnosis.py) |

#### 3.3.2 刷新诊断

| 前端触发 | Tab2 「⟳ 刷新」青色按钮 → `refreshDiagnosis()` |
|----------|----------|
| **端点** | `POST /api/v1/agent/ad-direction/diagnosis` |
| **请求体** | `{"asin": "B0B7S3PWWB", "refresh": true, "days": 7}` |
| **响应** | 同 `DiagnosisResponse`（跳过缓存，强制重新拉取数据） |
| **前端行为** | 按钮显示加载状态 → 刷新所有看板卡片 + 趋势图 + 关键词表 |
| **注** | 诊断层为只读，无「保存」按钮 |

### 3.4 执行层 P3（Tab3 — 目标ACOS和预算推荐）

| 前端触发 | Tab3 首开 / 策略保存后 / 「加载分析」→ `loadP3Rec()` |
|----------|----------|

| | `risk_warnings: [str]` |

## 7. 常见响应模式

### 7.1 降级标记

多个端点返回 `llm_status` 字段指示 LLM 服务质量：
| 值 | 含义 |
|----|------|
| `"ok"` | LLM 正常响应 |
| `"degraded"` | LLM 成功但数据不完整（通过 `data_completeness` 查看缺失项） |
| `"failed"` | LLM 完全失败，返回算法降级结果 |

### 7.2 缓存控制

| 端点 | 缓存参数 | 默认行为 |
|------|---------|---------|
| `/diagnosis` | `refresh: bool` | `false` → 命中缓存（TTL 4h） |
| `/execution/recommend` | `refresh: bool` | `false` → 命中 LLM 缓存（至次日 5:00） |
| `/campaign/analyze` | `refresh: bool` | `false` → 命中 Redis 缓存（TTL 30min） |

### 7.3 错误兜底

所有端点返回 200 + `partial_failures` / `warnings` 字段，而非 HTTP 500：
- 数据拉取失败 → `partial_failures` 包含失败模块名，其余模块正常返回
- LLM 调用失败 → 算法降级结果 + `llm_status: "failed"`
- Campaign analyze 全链路 → 各环节 `try/except` + warning 入栈
