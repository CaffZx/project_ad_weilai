# 触发规则（triggers.yaml）

定义 Agent 判断”当前应该做什么”的触发条件。每条规则由条件组合 + 结果动作组成。

## 1. 数据质量触发

### 缺少库存数据

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 父ASIN库存天数数据缺失 |
| 结果 | 状态=BLOCKED，阻断所有增长型动作（提价/加预算/加广告位/扩词） |
| 原因码 | DATA_REQUIRED_INVENTORY_MISSING |

### 冲排名但缺少自然排名数据

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 广告目的=ranking，但关键词自然排名数据缺失 |
| 结果 | 阻断ranking目的，建议改为conversion，审核等级=MANUAL_REVIEW |
| 原因码 | ORGANIC_RANK_REQUIRED_FOR_RANKING |

### 缺少广告位数据

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 广告位指标数据不可用 |
| 结果 | 阻断所有广告位加价，审核等级=MANUAL_REVIEW |
| 原因码 | PLACEMENT_DATA_MISSING |

## 2. 广告目的触发

### 新品或低样本 → 建议引流

| 项目 | 内容 |
| --- | --- |
| 触发条件（满足任一） | 上线<14天 / 3天曝光<1000 / 3天点击<15/ 预算利用率<50% |
| 结果 | 建议目的=traffic，方向=expand_keywords，审核等级=MANUAL_REVIEW |

### 起步期Traffic策略保留规则

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 产品阶段=testing + 淡旺季=旺季前期/旺季 + SOP命中Traffic |
| 必须保留的核心策略 | Traffic / Conversion |
| 风险修正方式 | 若ACOS偏高、利润偏低、库存/退货存在风险，仅可将Traffic降级为低预算诊断型Traffic |
| 允许动作 | 自动/广泛/场景词/长尾词低预算测词；验证曝光、点击、CVR、退货和Listing承接 |
| 禁止行为 | 不得将Traffic替换为Profit或Ranking；不得因风险存在而删除Traffic标签。若需要保守执行，仅可将执行方向降级为balance_maintain或低预算诊断型Traffic |
| 输出要求 | core_strategy_tags 仍须包含 Traffic；blocked_actions 或 downgraded_actions 中须说明Traffic预算/强度已降级 |

### 曝光充足但CVR过低 → 阻断引流

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 3天曝光>1500 且 CVR<品类均值×30% |
| 结果 | 阻断traffic目的，建议页面诊断，审核等级=MANUAL_REVIEW |
| 原因码 | EXPOSURE_OK_BUT_CONVERSION_WEAK |

### P0保护：淡季/旺季末期阻断Traffic主策略

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 产品定位=P0 + 淡旺季=淡季/旺季末期 |
| 结果 | 阻断Traffic作为唯一主策略，输出P0保护策略：方向=balance_maintain + conversion/profit；Traffic仅允许作为小比例、低预算补充测试，审核等级=MANUAL_REVIEW |

### 非P0旺季末期尾部承接规则

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 产品定位≠P0 + 产品阶段=pushing/harvesting + 淡旺季=旺季末期 + 近7日订单>0 |
| 必须保留的核心策略 | Conversion / Profit |
| 允许降级动作 | Traffic降级为小比例低预算测试；Ranking降级为核心自然位保护词或停止新增冲排名词 |
| 禁止行为 | 不得因ACOS偏高、亏损、滞销库存直接删除Conversion；不得仅输出Profit控损。需要维持时使用balance_maintain方向表达 |
| 输出要求 | 须写明"旺季末期尾部承接：保留高效词/自然流量保护词，优化ACOS+平衡维持，逐步降低低效Traffic/Ranking" |
| 审核等级 | MANUAL_REVIEW |

### 订单不足 → 建议转化

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 7天订单达成率<80% + ACOS在目标+10%以内 + 自然单比例≥30% |
| 结果 | 建议目的=conversion，方向=expand_keywords / push_natural_rank |

### 排名机会 → 建议冲排名

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 自然位≤48 + 7天排名上升≥2位 + ACOS在目标内 + 7天预算利用率≥60% + CVR不下降 |
| 结果 | 建议目的=ranking，方向=push_natural_rank |

### 效率稳定 → 建议利润模式

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 14天订单波动≤20% + ACOS超标（需优化） + 自然单比例≥60% |
| 结果 | 建议目的=profit，方向=optimize_acos / balance_maintain |

### 全面稳定 → 维持现状

| 项目 | 内容 |
| --- | --- |
| 触发条件 | ACOS在目标范围内 + 花费节奏正常 + 订单达标 + 核心排名稳定 + 库存支持当前节奏 |
| 结果 | 广告目的保持原值或建议profit/conversion（按当前策略背景）；方向=balance_maintain，审核等级=AUTO_APPROVED |

## 3. 特殊场景触发

### 库存严重不足（非清仓模式）

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 父ASIN库存天数<7天 且 非紧急清仓 |
| 结果 | 状态=BLOCKED，添加inventory_low标签，阻断提价/加预算/加广告位/扩词 |

### 核心SKU短缺

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 核心子SKU库存比例<70% |
| 结果 | 添加风险标记core_sku_shortage，阻断TOS加价和激进提价，审核等级=MANUAL_REVIEW |

### 高退货率

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 30天退货率≥30% |
| 结果 | 添加bad_reviews标签，阻断流量扩张/TOS加价/激进提价，审核等级=HIGH_RISK_REVIEW |

### 低评分

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 评分<3.8 |
| 结果 | 添加bad_reviews标签，阻断TOS加价和扩词，审核等级=MANUAL_REVIEW |

## 4. 竞品触发

### 竞品Deal压力 + 我方无价格优势

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 竞品促销占优 且 我方价格持平或更贵 |
| 结果 | 避免主词提价和TOS加价，优先长尾词扩展和PP加价，审核等级=MANUAL_REVIEW |

### 竞品弱 + 流量窗口

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 竞争强度低/中 + 流量机会中/强 + 库存健康(≥30天) + 核心SKU充足(≥70%) |
| 结果 | 允许核心词提价、PP加价、TOS加价，审核等级=MANUAL_REVIEW |
