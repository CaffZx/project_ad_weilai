# 名词定义（glossary.yaml）

确保 Agent 对高频术语的理解与运营一致，消除歧义。

## 1. 有效词

| 项目 | 内容 |
| --- | --- |
| 定义 | 已投放的keyword target，近3天ACOS≤目标×1.5，近3天≥3单，近7天≥5订单 |
| 数据来源 | get_keyword_performance(asin) |
| P0/P1阈值 | ≥7个 |
| P2阈值 | ≥5个 |
| P3阈值 | ≥3个 |
| 注意 | 排除search_term（搜索词是数据，不直接调价） |

## 2. 有效词根

| 项目 | 内容 |
| --- | --- |
| 定义 | 从有效词中提取的共享词干，用于扩词 |

## 3. 核心词

| 项目 | 内容 |
| --- | --- |
| 定义 | 近14天订单≥3 + ACOS≤目标线 + 自然排名2-48位 + CVR≥品类均值×0.8 |
| 最大数量 | 30个 |
| 更新频率 | Agent每周自动筛选，运营确认 |
| 注意 | 不是花费最高的词，不是订单最多的词，不是运营标注的词——是三条件交叉筛选的结果 |

## 4. 品类均值

| 项目 | 内容 |
| --- | --- |
| 定义 | 预置在阈值表的品类基准中，按类目节点分，运营每周更新 |
| 降级方案 | KB中没有该品类 → Agent标记DATA_MISSING，使用全账户均值（保守） |

## 5. 竞品池

| 项目 | 内容 |
| --- | --- |
| 定义 | ERP中market_segment下标记为”AI直接竞品”的ASIN |
| 数据来源 | get_competitive_insight(asin) |
| 降级方案 | 竞品池为空 → 跳过竞品分析模块，策略仅基于自身数据 |

## 6. 链接承接

| 项目 | 内容 |
| --- | --- |
| 定义 | Listing CVR。广告CVR vs 自然CVR的比值 |
| 阈值 | 比值 < 0.7 → 承接有问题（Listing页比竞品弱） |
| 数据来源 | get_ad_metrics(asin) + Brand Analytics session转化率 |

## 7. 自然位

| 项目 | 内容 |
| --- | --- |
| 定义 | 关键词在Amazon搜索结果中的自然排名位置（非广告位） |
| 数据来源 | get_keyword_performance(asin)的organic_rank字段 |
| 时间窗口 | 近7天最新值 |

## 8. 预算弹性

| 项目 | 内容 |
| --- | --- |
| 定义 | 日预算可上浮比例 |
| 数据来源 | 产品定位阈值中的日预算最高比例 |

## 9. 主力活动

| 项目 | 内容 |
| --- | --- |
| 定义 | 近7天ACOS≤目标线 AND 花费占比≥15% |
| 数据来源 | get_ad_metrics by campaign |

## 10. 可售天数

| 项目 | 内容 |
| --- | --- |
| 定义 | 当前FBA可售库存 / 近7天日均销量 |
| 数据来源 | get_inventory_status(asin) |

## 11. TACOS

| 项目 | 内容 |
| --- | --- |
| 定义 | 广告花费 / 总销售额（广告单+自然单） |
| 数据来源 | 广告指标花费 + 销售数据总销售额 |
| 时间要求 | 两个数据源时间窗口必须一致（都是7天） |

## 12. 订单稳定

| 项目 | 内容 |
| --- | --- |
| 定义 | 近14天日均订单的标准差/均值 ≤ 20%（变异系数≤20%） |

## 13. 淡季维持

| 项目 | 内容 |
| --- | --- |
| 定义 | 产品阶段的维持期（客观状态）在淡季的表现。与广告目的Maintain（不做策略调整）是两个不同概念 |

## 14. 有效词/词根样本少

| 项目 | 内容 |
| --- | --- |
| 定义 | 未跑出方向，需积累词库 |
| 阈值 | 有效词数量低于对应P级的Conversion触发阈值 |

## 15. 页面承接排查

当曝光/点击充足但CVR异常低时触发。检查项：

- 主图是否展示多场景穿搭（女装重点）

- 尺码表是否清晰（退货率关联）

- 颜色选项是否完整

- 价格/Coupon是否有竞争力

- 评价是否有尺码/面料负面反馈

- A+内容是否充分（多场景/卖点完整）

- 尺码选项是否完整

- 链接类目节点是正确

- 链接是否有购物车
