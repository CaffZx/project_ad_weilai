# 广告位规则（placement_rules.yaml）

Amazon SP广告三个广告位的加价策略。

> **适用范围**：`campaign_type = exact_keyword`（精准广告）与 `campaign_type = product_targeting`
> （商品/类目定投，归属 `auto_broad_group` 的 `product_targeting` 子桶，PP 优先于 TOS/RoS，见 `ONT-010`；v3.4.3）。
> `broad_keyword / phrase_keyword / auto_discovery` 一律不得输出 Placement 调整，字段统一填 `N/A`。
>
> **v3.4.0 切片修正**：本文在 v3.3.0 从未被任何 prompt 切片注入（整份文件是死件），
> 精准侧的广告位口径只能靠 `15号§3` / `19号§5§9` / `22号§2.3` 三处二手转述，
> 而这三处本身对 P2/P3 能否用 TOS 给出三个不同答案。本文已纳入
> `campaign_adjustment_product_targeting` 切片（`00号§4`）。

## 1. Top of Search（搜索结果顶部）

| 项目 | 内容 |
| --- | --- |
| 操作对象 | 广告位 |
| 动作类型 | 广告位调整 |
| 默认加幅 | +10% |
| 最大加幅 | 按 `03号§6.2` 定位分档：P0/P1 30%、P2 15%、P3 10% |
| 状态 | ️✅ 已确认 |

适用条件（必须同时满足）：

- 产品定位：**P0 / P1 / P2 / P3 均可用，但加价上限按 `03号§6.2` 分档**
  （P0/P1 上限 30%，P2 上限 15%，P3 上限 10%）
- 产品阶段：推进期、维持期、收割期
- 广告目的：冲排名或转化
- 广告方向：推自然位或平衡维持

准入条件（满足任一）：

- 触发了冲排名机会（`ranking_opportunity`）
- 7天 TOS ACOS ≤ **有效容忍上限**（`15号§4`）
- 7天 TOS 订单 ≥ 2 单

> **v3.4.0 修正（C-15 / G3）**：原文写「产品定位：P0 或 P1」，即 P2/P3 完全不能用 TOS；
> 而 `17号§5.1` 写「P3：TOS 加价上限 10%」（可用，上限低）、`15号§3.1` 主投位矩阵不分定位。
> 三处三个答案。已统一为 `03号§6.2` 的四档表：**P2/P3 可用但上限更低**。
> 理由：P2/P3 的长尾词在 TOS 上 CPC 往往不高且转化尚可，完全禁止会消灭一批真实机会；
> 用更低的上限控制风险比一刀切更准确。

必需证据： - TOS 7天ACOS、CVR、订单量 - 关键词7天自然排名变化 - 父ASIN库存天数 - 核心SKU库存比例 - 评分、退货率 - 竞品态势

硬阻断条件： - 父ASIN库存严重不足 - 核心SKU短缺 - 高退货率 - 低评分 - 缺少广告位数据

审核等级：

| 条件 | 等级 |
| --- | --- |
| 默认 | MANUAL_REVIEW |
| 加价≤10% | AUTO_APPROVED |
| 加价>20% | HIGH_RISK_REVIEW |

## 全局阻断条件

以下情况会全局限制广告位加价：

| 场景 | 影响 |
| --- | --- |
| 库存严重不足（非清仓） | 阻断TOS和PP |
| 差评或高退货率 | 阻断TOS |
| 页面优化中 | 所有广告位加价上限为5% |
| 缺少广告位数据 | 阻断TOS、PP以及RoS加价 |

补充：若 `campaign_type` 为 `broad_keyword / phrase_keyword / auto_discovery`，则不进入本文件判断，直接输出 `placement = N/A`（`ONT-002`、`ONT-RUNTIME-001`）。
`product_targeting` 进入本文件判断，但主投位默认 PP（`15号§3.1` 竞品截流行）。

## 广告位最终出价计算公式

广告位加价百分比是在基础 Bid 上叠加计算，不替代基础 Bid。

计算公式：

`placement_effective_bid = base_bid × (1 + placement_pct / 100)`

其中：

| 字段 | 含义 |
| --- | --- |
| `base_bid` | 关键词或 Target 的基础竞价 |
| `placement_pct` | 对应广告位的加价百分比 |
| `placement_effective_bid` | 该广告位下的理论有效出价 |

示例：

若 `base_bid = 0.50`：

| 广告位 | 加价比例 | 计算 | 最终理论出价 |
| --- | ---: | --- | ---: |
| TOS 搜索结果顶部 | 20% | `0.50 × (1 + 20%)` | `0.60` |
| RoS 搜索结果其余位置 | 10% | `0.50 × (1 + 10%)` | `0.55` |
| PP 商品页面 | 0% | `0.50 × (1 + 0%)` | `0.50` |

注意：
- Placement 加价只适用于允许 Placement 调整的广告类型。
- `broad_keyword / phrase_keyword / auto_discovery` 不输出 Placement 调整，字段填 `N/A`。
- 若基础 Bid 同时发生变化，应先计算新的基础 Bid，再基于新的基础 Bid 计算各广告位有效出价。

## 广告位输出字段

每条广告位调整建议必须包含：

活动ID、广告位类型、当前百分比、建议百分比、变化幅度、知识库允许的最大值、证据、风险评分、审核等级
