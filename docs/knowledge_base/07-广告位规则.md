# 广告位规则（placement_rules.yaml）

Amazon SP广告三个广告位的加价策略。

## 1. Top of Search（搜索结果顶部）

| 项目 | 内容 |
| --- | --- |
| 操作对象 | 广告位 |
| 动作类型 | 广告位调整 |
| 默认加幅 | +10% |
| 最大加幅 | 30% |
| 状态 | ️✅ 已确认 |

适用条件（必须同时满足）： - 产品定位：P0或P1 - 产品阶段：推进期、维持期、收割期 - 广告目的：冲排名或转化 - 广告方向：推自然位或平衡维持

准入条件（满足任一）： - 触发了冲排名机会 - 7天TOS ACOS ≤ 目标ACOS × 1.2 - 7天TOS订单 ≥ 2单

必需证据： - TOS 7天ACOS、CVR、订单量 - 关键词7天自然排名变化 - 父ASIN库存天数 - 核心SKU库存比例 - 评分、退货率 - 竞品态势

硬阻断条件： - 父ASIN库存严重不足 - 核心SKU短缺 - 高退货率 - 低评分 - 缺少广告位数据

审核等级：

| 条件 | 等级 |
| --- | --- |
| 默认 | MANUAL_REVIEW |
| 加价≤10% | AUTO_BATCHABLE |
| 加价>20% | SENIOR_APPROVAL |

## 2. Product Pages（商品页面）

| 项目 | 内容 |
| --- | --- |
| 操作对象 | 广告位 |
| 动作类型 | 广告位调整 |
| 默认加幅 | +10% |
| 最大加幅 | 10% |
| 状态 | ✅ 已确认 |

适用条件： - 产品定位：P0/P1/P2/P3 均可用 - 产品阶段：测试/推进/维持/清仓 - 广告目的：引流/转化/利润/维持 - 广告方向：扩词/优化ACOS/平衡维持

适用场景： - 竞品Deal压价且我方无价格优势 - 竞品页面薄弱有机会 - 清仓或清理库存 - 长尾词或竞品定位投放

必需证据： - PP 7天ACOS、CVR - 竞品价格定位 - 竞品评价定位 - 目标相关性评分

硬阻断条件： - 缺少广告位数据 - 高退货率

审核等级：

| 条件 | 等级 |
| --- | --- |
| 默认 | MANUAL_REVIEW |
| 加价≤10% | AUTO_BATCHABLE |
| 加价>20% | SENIOR_APPROVAL |

| --- | --- |
| 操作对象 | 广告位 |
| 动作类型 | 广告位调整 |
| 默认模式 | 维持 |
| 默认加幅 | 10% |

| 状态 | ✅ 已确认 |

适用条件：所有产品定位/阶段/广告目的均可用

适用场景： - 平衡维持 - 低风险测试 - 无明确TOS或PP信号

审核等级：AUTO_BATCHABLE

## 全局阻断条件

以下情况会全局限制广告位加价：

| 场景 | 影响 |
| --- | --- |
| 库存严重不足（非清仓） | 阻断TOS和PP |
| 差评或高退货率 | 阻断TOS |
| 页面优化中 | 所有广告位加价上限为5% |
| 缺少广告位数据 | 阻断TOS、PP以及RoS加价 |

## 广告位输出字段

每条广告位调整建议必须包含：

活动ID、广告位类型、当前百分比、建议百分比、变化幅度、知识库允许的最大值、证据、风险评分、审核等级
