# 广告位规则（placement_rules.yaml）

Amazon SP广告三个广告位的加价策略。

> 适用范围限定：本文件仅适用于 `campaign_type=exact_keyword` 的精准广告。
> `broad_keyword / phrase_keyword / auto_discovery` 一律不得输出 Placement 调整，相关字段统一填写 `N/A`。

## 1. Top of Search（搜索结果顶部）

| 项目 | 内容 |
| --- | --- |
| 操作对象 | 广告位 |
| 动作类型 | 广告位调整 |
| 默认加幅 | +10% |
| 最大加幅 | 30% |
| 状态 | ️✅ 已确认 |

适用条件（必须同时满足）： - 产品定位：P0或P1 - 产品阶段：推进期、维持期、收割期 - 广告目的：冲排名或转化 - 广告方向：推自然位或平衡维持

准入条件（满足任一）： - 触发了冲排名机会 - 7天TOS ACOS ≤ 目标ACOS × 1.2 - 7天TOS订单 ≥ 2单

必需证据： - TOS 7天ACOS、CVR、订单量 - 关键词7天自然排名变化 - 父ASIN库存天数 - 核心SKU库存比例 - 评分、退货率 - 竞品态势

硬阻断条件： - 父ASIN库存严重不足 - 核心SKU短缺 - 高退货率 - 低评分 - 缺少广告位数据

审核等级：

| 条件 | 等级 |
| --- | --- |
| 默认 | MANUAL_REVIEW |
| 加价≤10% | AUTO_BATCHABLE |
| 加价>20% | SENIOR_APPROVAL |

## 全局阻断条件

以下情况会全局限制广告位加价：

| 场景 | 影响 |
| --- | --- |
| 库存严重不足（非清仓） | 阻断TOS和PP |
| 差评或高退货率 | 阻断TOS |
| 页面优化中 | 所有广告位加价上限为5% |
| 缺少广告位数据 | 阻断TOS、PP以及RoS加价 |

补充：若 `campaign_type` 为 `broad_keyword / phrase_keyword / auto_discovery`，则不进入本文件判断，直接输出 `placement = N/A`。

## 广告位输出字段

每条广告位调整建议必须包含：

活动ID、广告位类型、当前百分比、建议百分比、变化幅度、知识库允许的最大值、证据、风险评分、审核等级
