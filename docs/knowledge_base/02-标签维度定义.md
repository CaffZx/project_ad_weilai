# 标签维度定义（dimensions.yaml）

## 维度总览

共 7 个标签维度，用于给每个 ASIN 打标签，指导广告策略决策。

| 维度 | 类型 | 维护方 | 更新频率 | Agent权限 |
| --- | --- | --- | --- | --- |
| 产品定位 | 单选 | 运营手动 | 长周期 | 仅建议 |
| 产品阶段 | 单选 | 运营手动 | 长周期 | 仅建议 |
| 淡旺季 | 单选 | 运营手动 | 长周期 | 仅建议 |
| 广告目的 | 单选或多选 | Agent建议+运营确认 | 长周期 | 可提议变更 |
| 关键词类型 | 单选或多选 | Agent建议+运营确认 | 长周期 | 可提议变更 |
| 广告方向 | 单选或多选 | Agent建议+运营确认 | 每日 | 可提议变更 |
| ACOS目标 | 数值 | Agent建议+运营手动 | 每日 | 仅建议 |
| 预算 | 数值 | Agent建议+运营手动 | 每日 | 仅建议 |
| 特殊场景 | 单选或多选 | 混合 | 事件驱动 | 可提议或遵循 |
| 广告位 | 单选或多选 | Agent建议+运营确认 | 每日或活动变更 | 可提议调整 |
| 市场竞争态势 | 衍生对象 | Agent从ERP数据衍生 | 每日 | 可衍生存储并提议 |

## 1. 产品定位

战略资源优先级，开发阶段即定，不因短期ACOS/销量波动自动变更。

| 级别 | 定义 |
| --- | --- |
| P0 | 战略级产品，全年核心主推或旺季爆款。准入条件：月订单≥3000 + BSR Top50 + 评≥4.0 + 退货率≤25% + 库存≥30天。 |
| P1 | 重点产品，市场已验证且有机会推成主力款。P2→P1需满足任意3条：日均订单≥50 / 环比≥20% / 自然单>30% / 核心词Top50 / 退货率≤30% |
| P2 | 常规产品，稳定出单、控制成本、保护利润（兜底类型） |
| P3 | 差异化/设计驱动产品，高毛利、小众或风格化，不追大词排名，ACOS通常≤30% |

## 2. 产品阶段

产品当前客观运营阶段。

| 阶段 | 说明 | 关键约束 |
| --- | --- | --- |
| testing | 验证品质、退换货、价格、Listing承接和词路 | 日预算≤$30，最多测60天 |
| pushing | 测试通过后放量、推排名、扩大有效词 | ACOS可+10pp容忍→有效上限50%，P0日预算≥$150，P1≥$100 |
| harvesting | 销量和结构稳定后提升广告效率和利润 | ACOS收紧至30% |
| maintaining | 数据健康，无需大动作 | 保排名、稳单量、稳利润 |
| liquidating | 清库存阶段 | AI可建议但必须人工确认，ACOS放宽至60%，日预算≤$80 |

## 3. 淡旺季

AI可建议但必须人工确认-类目/直接竞品市场环境，不能只按月份判断。

| 阶段 | 判定条件 |
| --- | --- |
| 淡季 | 类目搜索量<峰值40% + 竞品销量<峰值50% |
| 旺季前期 | 类目搜索量环比>15%/2周 + CPC周环比>5% + ≥3竞品BSR爬升 |
| 旺季 | 类目搜索量达峰值±15% + ≥3竞品BSR飙升 |
| 旺季末期 | 类目搜索量降>20% + ≥2竞品降价清库存 |

## 4. 广告目的

当前广告目标。

| 目的 | 说明 | 倾向的广告方向 |
| --- | --- | --- |
| traffic | 引流 | expand_keywords |
| conversion | 转化 | expand_keywords, push_natural_rank, balance_maintain |
| ranking | 冲排名 | push_natural_rank |
| profit | 利润 | optimize_acos, balance_maintain |

切换冷却：≥7天，30天内≤2次。

## 5. 关键词类型

关键词或Target的策略类型，用于出价、扩词、否词和预算分配。

| 类型 | 出价系数 | 说明 |
| --- | --- | --- |
| broad（大词） | 0.5 | 低成本曝光筛词，允许阶段性偏高ACOS但必须换来有效词根 |
| long_tail（长尾词） | 0.8 | 3-6单词，精准意图高转化，ACOS严格监控，是整体ACOS锚定点 |
| competitor（竞品词） | 0.8 | 直接竞品反查得出的关键词，初始中低Bid测试 |
| brand（品牌词） | 0.3 | 借品牌流量做平替转化，小比例补充策略 |
| custom（自定义词） | 0.5 | 运营经验词/节日词/趋势 |

## 6. 广告方向

每日执行方向。

| 方向 | 说明 |
| --- | --- |
| push_natural_rank（推自然位） | 自然位上升+ACOS可控+花费稳定+CVR不降 |
| expand_keywords（新增扩词） | 三信号：花不完/效果差/想更大 |
| optimize_acos（优化ACOS） | 按层级排查：整体→组合→活动→关键词→搜索词 |
| balance_maintain（平衡维持） | 有意识不作为，所有指标正常时默认 |

## 7. 特殊场景

覆盖日常策略的特殊场景。优先级规则：特殊场景 > 硬护栏 > 库存 > 退货/评价 > 产品阶段 > 淡旺季 > 广告目的 > 竞品 > 广告方向 > 产品定位。

| 场景 | 维护方 | 核心规则 |
| --- | --- | --- |
| promotion（活动促销） | 运营手动 | ACOS容忍度+0.15，预算+0.15，库存<30天时阻断 |
| inventory_low（库存不足） | Agent建议+运营确认 | Ranking→Maintain降级，出价系数0.7，预算最多降50% |
| bad_reviews（差评） | Agent建议+运营确认 | Ranking降级为Conversion |
| listing_optimization（页面优化） | 运营手动 | 强制Maintain 7天，最大出价调整0.05，不新增否定词 |
| urgent_liquidation（紧急清仓） | 运营手动 | 暂停ACOS逻辑，预算模式激进，需SENIOR_APPROVAL |

## 8. 广告位

Amazon SP广告位加价策略。详见广告位规则。

| 位置 | 适用说明 |
| --- | --- |
| top_of_search（搜索结果顶部） | P0/P1推进期/maintaining可用，单次≤30%，>20%需高级审批 |
| product_pages（商品页面） | 截流/清仓首选，单次≤10% |
| rest_of_search（搜索结果其余位置） | 默认维持≤15%，>20%需高级审批 |

## 9. 市场竞争态势

从ERP竞品数据衍生的竞品态势判断。每日更新，Agent自动衍生。

| 字段 | 说明 |
| --- | --- |
| competition_intensity | 竞争激烈程度 |
| price_position | 价格定位 |
| review_position | 评价定位 |
| promo_gap | 促销差距 |
| traffic_opportunity | 流量机会 |
| defensive_need | 防守需求 |
| recommended_posture | 推荐姿态 |
