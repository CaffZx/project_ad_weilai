# 关键词类型行为规则（keyword_type_rules.yaml）

5种关键词类型各自的行为策略：出价、匹配方式、预算、否词、复盘节奏。

## 1. Broad（大词/泛词）

低成本曝光，筛选高潜精准词。

| 维度 | 策略 |
| --- | --- |
| 出价系数 | 0.5 |
| 匹配方式 | 广泛或精准匹配 |
| 预算 | 小比例测试预算；P0/P1可适度提高；P2/P3只能小比例；不挤占主力预算 |
| 出价 | 以低成本引流为主，不用高Bid强抢；曝光不足时可小幅提高；CPC过高且无有效词沉淀时应降低或换词 |
| ACOS策略 | 允许阶段性偏高，但必须换来曝光/点击/搜索词样本/有效词根；只有花费没有沉淀→收缩 |
| 否词规则 | 明显不相关→否掉；相关但无转化→降bid观察7-14天；高花费无转化→及时否掉 |
| Listing检查 | Broad带来点击但CVR低→检查主图/价格/标题/五点/评价/变体。女装重点：多场景穿搭展示、尺码表清晰、颜色完整、面料反馈 |

复盘节奏： | 时间 | 检查项 | |——|——–| | 第1天 | 曝光量、花费 | | 第3天 | 搜索词报告、CPC、CTR、预算消耗 | | 第7天 | 搜索词数量、有效词、有效词根、订单、CVR |

交接条件： - 跑出有效搜索词→提取转入精准词或长尾词 - 具备自然位推进价值→进入Ranking - 只有花费无有效词→转控损或换词方向

## 2. Long Tail（长尾词）

精准意图，低竞争，高转化。通常3-6个单词。

| 维度 | 策略 |
| --- | --- |
| 出价系数 | 0.8 |
| 匹配方式 | 精确匹配或广泛匹配 |
| 预算 | 高于Broad但低于主力Ranking核心词；P0/P1中等预算推进；P2/P3以控ACOS和稳定利润为主；清货期优先给高转化长尾词 |
| 出价 | 可高于Broad但不盲目高于建议出价上限；已出单且ACOS达标→保bid或小幅提；点击少无曝光→先小幅提；点击多无单→降bid或转观察 |
| ACOS策略 | 严格监控，长尾词ACOS是整体ACOS的锚定点；只有花费没有沉淀→收缩；相关但无转化→降bid观察3-7天 |
| 否词规则 | 明显不相关→否掉；相关但暂未转化→先降bid观察不过早否定；重复高点击无单→强优化或否定 |

复盘节奏： | 时间 | 检查项 | |——|——–| | 第1天 | 曝光、点击、CPC | | 第3天 | 点击质量、CVR、加购或订单 | | 第7天 | ACOS、订单、自然位变化、是否升级Ranking |

交接条件： - 连续出单且ACOS达标→转入精准重点投放 - 自然位开始上升→进入Ranking - 7天无转化→降级或替换词根

## 3. Competitor（竞品词）

针对性截流，价格/品质优势转化。

| 维度 | 策略 |
| --- | --- |
| 出价系数 | 0.8 |
| 匹配方式 | 精确和广泛匹配 |
| 预算 | 中小预算；P0/P1可设中小预算测试；P2/P3只做小比例；清货期围绕低价优势适当给预算；不挤占主力预算 |
| 出价 | 不建议高Bid硬抢；初始中低Bid测试；有点击有单→保bid或小幅提；点击多无单→降bid或换竞品池 |
| 词的选择 | 优先选直接竞品/同价格带/同款式/评分较低/价格高于我方/断货/促销弱竞品 |
| ACOS策略 | 允许前期略高但必须换来有效点击连续花费无转化→不继续扩大 |
| 否词规则 | 明显不相关→否掉；相关但暂未转化→先降bid观察不过早否定；重复高点击无单→强优化或否定 |
| Listing检查 | 竞品词流量是对比型流量，页面须突出：价格/Coupon/评分/面料/版型/尺码/颜色/场景图/退换货信任点 |

复盘节奏： | 时间 | 检查项 | |——|——–| | 第1天 | 曝光、点击、CPC | | 第3天 | 点击质量、CVR、加购或订单 | | 第7天 | ACOS、订单、自然位变化、是否升级Ranking |

交接条件： - 竞品词稳定后维持投放 - 竞品恢复强势→及时收缩 - 跑出稳定订单→提取竞品属性词根作为Custom词维护

## 4. Brand（品牌词）

借品牌流量，价格优势做平替转化。

| 维度 | 策略 |
| --- | --- |
| 出价系数 | 0.3 |
| 匹配方式 | 精确匹配 |
| 预算 | 小比例预算。品牌词是补充型策略，不是主力方向 |
| 出价 | 以低成本截流为主，不用高Bid强抢品牌词 |
| 词的选择 | 选择与自身产品相似/可替代的知名品牌词；优先有平替属性的品类；避免与自身产品差异过大的品牌 |
| ACOS策略 | 品牌词ACOS通常优于大词；只有花费没有沉淀→收缩 |

复盘节奏： | 时间 | 检查项 | |——|——–| | 第3天 | CTR是否达标 | | 第7天 | ACOS和ROAS是否稳定 、决定保留/暂停 |

## 5. Custom（自定义词池）

运营手动添加。

| 维度 | 策略 |
| --- | --- |
| 出价系数 | 0.5 |
| 匹配方式 | 精确匹配 |
| 预算 | 历史出单词/低ACOS词→中等预算；新词池→小预算测试；profit词池→小预算稳定投放 |
| 出价 | 按词的历史ACOS和CVR单独设定；已验证高效词可适度提价；测试词低Bid观察 |
| 词池来源 | 节日属性词/风格趋势词/组合词/变体词/测试词 |
| ACOS策略 | 根据运营指定的目标ACOS执行 |

复盘节奏： | 时间 | 检查项 | |——|——–| | 第1天 | 词池是否有曝光和点击 | | 第3天 | 不同词组的CPC、CTR、点击质量 | | 第7天 | 搜索词数量、有效词、订单、CVR + 节日/趋势词热度变化 |

交接条件： - 表现好的→转入精准主推或Ranking - 表现一般但相关→观察池 - 高点击无单→降级或否词 - 无曝光→检查出价或词本身搜索量
