# 广泛、自动、词组广告调整规则（broad_auto_phrase_rules.yaml）

> **适用范围**：`campaign_type ∈ [broad_keyword, phrase_keyword, auto_discovery]`，即全部归属
> `auto_broad_group`（广泛自动组）的活动，及其 Search Term 流转。
>
> **本文与 22号 的分工**：`22-调整广告活动规则.md§3` 定义广泛类的三层调整框架
> （Budget → Bid → Search Term）；本文补充 22号 没有的三件事：
> ① 相关性与效率的分支判定；② 产品定位与经营模式如何改变探索强度；③ 提词后原活动的处理。
>

---

## 0. 核心结论

广泛、自动、词组广告的职责是**挖词和提供流量来源**，不承担精准主推。

四条原则：

1. 有效 Search Term 先进入**精准测试组**，不直接进入精准主力组（`23号§3.4` → `32号§3`）。
2. **明显不相关**才否词；**相关但暂时无转化**走低 Bid 或受控预算观察，不否词。
3. 产品定位决定探索强度与预算档位；经营模式决定当前允许哪些动作。
4. 目标 ACOS、父 ASIN 日预算和安全护栏决定调整边界的硬上限。

---

## 1. 三类广告的职责边界

| 广告类型 | 承担 | 不承担 |
| --- | --- | --- |
| 广泛广告 `broad_keyword` | 打开词池、探索搜索词、挖掘词根、获取长尾流量 | 精准主推；广告位调整 |
| 词组广告 `phrase_keyword` | 比广泛更收窄地探索相关搜索词，为精准测试提供词源 | 不单独建立主推逻辑；按广泛策略处理 |
| 自动广告 `auto_discovery` | 发现 Close Match / Loose Match / Substitutes / Complements 及相关 Search Term | 不因 Auto 整体 ACOS 高就批量提高全部 Auto Bid；缺 Target 契约时不调 Target Bid |

依据：`18号§1`、`07号§0`、`ontology/budget_groups.yaml` group_types、`ROUTE-001`。

## 2. 产品定位下的探索强度（四档，按 02号§1）

### 2.1 P0 战略级 / P1 重点产品

精准侧负责抢核心词、推自然排名、承接已验证词；广泛/自动/词组负责挖新词、扩长尾、提供精准测试词源。

- 标题词、后台 Search Term 词、核心卖点词、自然排名相关词，**不因短期无订单直接否词**（`ONT-RUNTIME-004`）。
- 有效 Search Term 先进精准测试组，完成 `23号§3.5` 验证后才进精准主力组。
- 关键词转入精准后，原广泛/自动/词组活动**默认不自动否词**（见 §12）。
- 探索预算档位按 `15号§2.1` 的 P0 / P1 列。
- **P0 专属**：核心词 Bid 每次降幅 ≤5% 且不得连续两次下调同一关键词（`15号§1.3`）；P1 不适用此项。

### 2.2 P2 常规产品

精准侧负责稳定转化和盈利；广泛/自动/词组负责补充流量、挖少量新词、发现可升级 Search Term。

- 探索预算低于 P0/P1（按 `15号§2.1` 的 P2 列）。
- 对高花费无转化词更敏感：进入 §5 的强优化档所需的花费门槛按 `03号§7` 取值，不额外放宽。
- 明显不相关词及时否词；相关但无转化词先判断数据是否充分（§4）。
- 不长期保护大量未验证词。

### 2.3 P3 长尾产品

**P3 不要求建立大量精准主推词。** 广泛/自动/词组可以承担主要流量来源，精准侧只承接少量已验证或高价值词。

- 优先低 Bid 或固定 Bid；预算采用固定或受控预算，避免频繁大幅波动。
- 高相关但暂时无转化的词继续观察；样本不足时观察窗延长至 14 天（`18号§3`）。
- 明显不相关词否词；稳定转化后升级为精准测试。
- **关联说明**：精准主力组当前仍执行固定 $5 门槛（`23号§3.5`）。
  P3 长尾升组困难是已知待验证问题，不能以未经确认的比例参数自动放宽。

## 3. 经营模式下的动作权限

| 经营模式 | 广泛/自动/词组 允许动作 | 限制 |
| --- | --- | --- |
| `active_promotion` 积极推进 | 扩词、增加探索预算、适度提高 Bid、有效词送入精准测试 | 不得突破父 ASIN 预算；不做广告位调整 |
| `stable_operation` 稳定经营 | 保持活动、低幅度扩词、小幅 Bid/预算调整 | 不大规模新增和扩量 |
| `limited_repair` 有限修复 | 否词、降 Bid、降预算、Listing 诊断 | 停止激进扩词和大规模新建；阶段 ACOS 正加值归零（`09号§3`） |
| `controlled_clearance` 控制清货 | 低 Bid 保留有订单或高价值流量，逐步收缩 | 原则上停止大规模扩词（`28号§3.2` 清仓行） |
| `profit_harvest` 获取利润 | 减少探索，保留高效 Search Term，预算优先给精准高效词 | 不积极扩展新词；阶段 ACOS 正加值归零（`09号§3`） |
| `immediate_exit` 立即退出 | 无。确定性执行 `stop_campaign` | 不进入 LLM 判断；禁止新建；见 `18号§0` |

## 4. 相关性优先于效率：四档分支（本文核心）

**判定顺序：先判相关性，再判数据是否达到动作阈值。** 顺序不可颠倒。

相关性档位沿用 `28号§2` 的 `R1 精确相关 / R2 扩展相关 / R3 试探相关 / R4 风险相关`。

| 档 | 场景 | 相关性 | 数据条件 | 动作 | 是否否词 |
| :-: | --- | --- | --- | --- | :-: |
| 1 | 数据不足 | 任意 | 活动上线 <3 天；或 7 天点击 <10 **且** 7 天花费 < 无单花费门槛（`03号§7`） | 不做大幅调整，低 Bid 或原 Bid 观察；P3/长尾词观察窗延长至 14 天 | 否 |
| 2 | 相关但暂时无转化 | R1 / R2 | 7 天点击 ≥10 **或** 7 天花费 ≥ 无单花费门槛，且无订单 | Bid 下降一档（`19号§3` 小降，经 `15号§1.2` 系数修正）；预算保持或小幅下降；观察 7 天 | **否** |
| 3 | 相关且已达强优化档 | R1 / R2 | 7 天点击 ≥20 **或** 7 天花费 ≥ 强优化花费门槛（`03号§7`），仍无订单 | Bid 下降两档（`19号§3` 大降）；预算下降一档；进入人工复评 | 通常不否 R1 词 |
| 4 | 明显不相关 | R3 / R4 或语义冲突 | 无数据门槛 —— 相关性判定即可触发 | 添加精确否定词，记录相关性判定依据与证据 | **是** |

**补充规则：**

- 档 3 命中 R1 词时，若该词属 `29号` 的核心词（`is_core_keyword = true`）或 `ONT-RUNTIME-004` 的四类保护词，**不得否词**，只允许降 Bid / 降预算 / 转 Listing 诊断。
- 「高花费低相关」是档 3 与档 4 的叠加：7 天花费 ≥ 强优化门槛 **且** 相关性为 R3/R4 → 先否词，再降 Bid/预算，必要时 `stop_campaign`。
- 相关性证据不足时，**不得把「无订单」直接等同于「不相关」**（`19号§8` 末句，本节将其规则化）。
- 档 2 与档 3 的点击阈值 `≥10` / `≥20` 与 `22号§3.3` 一致（预警 / 强优化两档制）。

## 5. Bid 调整规则

基础幅度按 `19号§3`，系数修正按 `15号§1.2`，硬上下限按 `03号§8`。本节只定义**触发条件与档位映射**。

| 表现 | 触发信号 | Bid 档位 | 复评窗 |
| --- | --- | --- | --- |
| 曝光不足 | 高度相关（R1）、预算未花满、点击不足 | 小涨；单次幅度上限 15%（`22号§3.2`） | 1–3 天 |
| 轻度偏高 | 有订单，ACOS > 目标 但 ≤ 有效容忍上限（`15号§4`） | **不降**（未超容忍上限不触发降 Bid） | 7 天 |
| 超出容忍上限 | ACOS > 有效容忍上限，有订单 | 小降 | 7 天 |
| 相关但无转化 | §4 档 2 | 小降，同时检查是否应先否词（`22号§3.2`） | 7 天 |
| 已达强优化档 | §4 档 3 | 大降；必要时降预算或 `stop_campaign` | 7 天 |
| 核心保护词 | `is_core_keyword = true` 且仍有自然位价值 | 小降或维持低 Bid，**不得归零**；P0 额外受 `15号§1.3` 的 ≤5% 约束 | 7–14 天 |

## 6. 预算调整规则

| 场景 | 数据条件 | 动作 |
| --- | --- | --- |
| 预算花不满 | 预算利用率连续 3 天 <50% | **先按 `23号§4.3` 做瓶颈判断**；确认瓶颈在活动层后，走 `28号§5` 四档填补（① 回流被压制的有效词 → ② 提现有有效词 Bid/预算 → ③ 精准测试组提词升组 → ④ 才扩新词）；四档都无法消化才降预算 |
| 表现好且预算不足 | 7 天 ACOS ≤ 目标、订单有效、预算利用率 ≥70%、库存天数 ≥30 天 | `active_promotion` 可增加一档（`19号§4` 小涨/大涨，经 `15号§2` 系数修正）；P2 小幅；P3 优先固定或受控预算 |
| 花满且 ACOS 超容忍上限 | 预算利用率高、ACOS > 有效容忍上限、Search Term 质量差 | 先否不相关词（§4 档 4），再降 Bid 和预算；**不做广告位调整** |
| 组合预算瓶颈 | 组合利用率 100% 且活动平均利用率 <80% | 建议提升**组合**预算，不调单个活动预算（`GROUP-BUDGET-007`） |
| 主力预算保护 | 精准主力组 7 天花费 ≥$5 且有出单 | 广泛自动组不得扩张挤占主力组；预算紧时精准测试组优先压缩、广泛自动组次之（`GROUP-BUDGET-004`） |

## 7. 数据窗口

全部使用完整站点自然日数据。窗口定义与用途以 `18号§3` 为准，本节只列广泛侧的特殊点：

| 窗口 | 广泛侧用途 | 能否单独决策 |
| --- | --- | --- |
| 近 1 天 | 单日异常、预算突然花满或花不出去 | 不能单独淘汰或关闭，只能轻微调整或标记异常 |
| 近 3 天 | ACOS 趋势、CVR 趋势、预算利用率、点击质量 | 可小幅调 Bid 或预算；利用率连续 3 天 <50% 触发 §6 第一行 |
| 近 7 天 | 订单、花费、ACOS、Search Term 沉淀、自然位 | **主要决策窗口**；提词与有效性判定 |
| 近 14 天 | 长尾/低流量/样本不足时延长（`18号§3`） | 避免样本不足下误否词或误关闭 |

## 8. 自动广告投放组规则

| 投放组 | 观察重点 | 调整原则 |
| --- | --- | --- |
| Close Match | 相关性、订单、ACOS、Search Term | 有效词优先提取；不因 Auto 整体表现批量提价 |
| Loose Match | 是否产生泛流量和无关点击 | 高点击无单且相关性 R3/R4 时优先否词或降 Bid |
| Substitutes | 是否为有效替代品/竞品流量 | 相关且有订单可保留；R3/R4 或高花费无单则清理 |
| Complements | 是否与产品主需求相关 | 相关性通常最低，优先压至站点最低可执行 Bid；不相关则否词或停止该方向 |

**硬约束**：`runtime_contract.auto_target_groups.missing_contract_behavior = block_target_bid_action` ——
**AUTO Target 数据契约完成前，禁止生成任何 AUTO Target 级 Bid 动作**（`ONT-009`、交接文档§11.2）。
契约完成前，Auto 侧只允许：Campaign 预算调整、Search Term 否词、Search Term 提词。

## 10. Search Term 进入精准测试组

准入条件以 `23号§3.4` 为唯一权威，本节只做引用与广泛侧补充说明。

| 通道 | 条件 | 审核等级 |
| --- | --- | --- |
| 通道一：订单通道 | 近 7 天有效订单 ≥3 单 **且** 近 7 天 ACOS ≤ 目标 ACOS **且** 无对应精准活动 | MANUAL_REVIEW |
| 通道二：词根通道 | 同词根合计 7 天订单 ≥3 单 **或** 合计 ACOS ≤ 目标 ACOS；且无精准活动承接该词根 | MANUAL_REVIEW |
| 通道三：CVR 通道 | CVR > 品类均值 × 0.8 **且** 7 天花费 ≥ 无单花费门槛（`03号§7`）**且** 无对应精准活动 | **HIGH_RISK_REVIEW**（强制人工） |

**共同约束：**

- 候选词必须存在于本轮输入数据，**禁止 LLM 生成输入外的词**（`28号§1` 词保真，违反 → BLOCKED）。
- 新建单关键词 Exact 活动，初始预算按 `16号§2`，归属 `exact_testing_group`。
- **不得从广泛/自动/词组直接进入精准主力组**，必须先完成 `23号§3.5` 的验证。
- 相关性必须达 R1（`28号§2`）。

## 11. 保护型精准测试

战略核心词可以被保护，但保护**不是**「只要相关就进」，也**不是**直接进精准主力组。

### 11.1 字段定义

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `protected_testing` | boolean | 是否处于保护型测试状态 |
| `protection_expires_at` | date | 保护到期日 = 进入日 + 保护期（§11.2） |
| `protection_basis` | array | 进入依据（产品定位 / 相关性档 / 数据证据 / 运营指定） |

### 11.2 进入条件（四条同时满足）

| 条件 | 要求 |
| --- | --- |
| 产品定位 | P0 或 P1；或运营显式确认该词为战略词 |
| 相关性 | 达 `R1 精确相关`（`28号§2`）；或 `29号` 判定 `semantic_core = true` |
| 最低数据 | 近 7 天点击 ≥5 **或** 花费 ≥ `03号§7` 的保护型测试最低数据门槛 |
| 验证结果 | 尚未达到 `23号§3.5` 的精准主力组准入条件 |

### 11.3 保护期内的行为

- 观察 7–14 天（具体值见 `03号§7`，标 `needs_review`）。
- **不自动否词**；不进入 `21号` 淘汰评估；不进入 `32号§2` 的降级判定。
- 允许低 Bid 或受控预算；允许降 Bid / 降预算。
- 必须同步检查 Listing、价格、库存、评价与转化承接（`14号§15` 页面承接排查）。

### 11.4 保护边界（防止无限花费）

- 到达 §4 档 3（强优化档）后，**保护不豁免降 Bid / 降预算**，只豁免否词与淘汰。
- `protection_expires_at` 到期后强制回归常规评估，`protected_testing` 自动置 `false`，
  并输出一条 MANUAL_REVIEW 说明保护期结论。
- 保护期不可由 Agent 自行续期；续期需运营显式操作。

## 12. Search Term 转入精准后，原活动如何处理

按运营共识：Search Term 转入精准测试或精准主力后，原广泛/自动/词组活动**默认不自动否词**。

| 阶段 | 原活动处理 | 原因 |
| --- | --- | --- |
| 该词进入精准测试组 | 继续保留，不自动否词 | 观察精准测试与原探索活动的流量与转化差异 |
| 精准测试稳定 / 已升主力组 | 默认仍不自动否词，除非运营另行确认 | 保留探索功能，避免过早切断长尾来源（切断会直接触发 `28号` TRG-3 词池萎缩） |
| 该 Search Term 被判定明显不相关 | 可以否词 | 否词针对的是**相关性错误**，不是「词已转精准」 |
| 出现明显重复抢量 | 进入人工复评 | 不自动把所有重复流量否掉 |

## 13. 停止投放与低价捡漏组

**广泛、词组、自动活动不得迁入低价捡漏组**（`ONT-016`、`ONT-RUNTIME-002`）。
低价捡漏组只收 EXACT，预算固定 $1，Bid = `min(current_bid, 0.20)`（`ONT-014`）。

广泛类的退出动作是 `stop_campaign`（`30号§2`），**不是** `pause`，也**不是** `eliminate_to_low_bid_pool`。

| 情况 | 处理 |
| --- | --- |
| 数据不足或活动上线 <3 天 | 不能关闭，只观察曝光、点击、花费 |
| 相关但无转化（§4 档 2/3） | 低 Bid、受控预算、Listing 诊断；不关闭 |
| 明显不相关（§4 档 4） | Search Term 否词 |
| 高花费无单且低相关 | 否词 → 降 Bid → 降预算；仍无改善 → `stop_campaign` |
| 整体活动持续长期低效 | `stop_campaign`（HIGH_RISK_REVIEW，必须人工确认） |
| `immediate_exit` 模式 | 确定性 `stop_campaign`，不进入 LLM 判断（`18号§0`） |

**停止投放前必须走完 `21号§3` 的广泛类诊断路径**：高点击无单 → 先否词 → 仍无改善降 Bid/降预算 → 仍无改善才评估停止投放。不得跳过否词直接停止投放。

**停止投放触发预算回算**：释放金额 = `current_daily_budget`，计入 `other_campaign_budget_decrease`（`23号§5`）。

## 14. 扩词

扩词决策以 `28号` 为唯一权威（触发动因 TRG-1~5 × 产品阶段矩阵、来源码、相关性档位、配额公式）。
本节只列广泛侧的接口要点：

- 扩词是 `28号§5` 预算缺口填补的**第 4 档兜底**，前三档消化不完才扩。
- 数量按 `28号§3` 公式动态计算（可分配扩词预算 ÷ 单词最低验证预算），受每日新词上限封顶（`03号§7`，作用域为**每父 ASIN 每日**）。
- 缺 `search_term_report` 时，`SRC_CONVERTED / SRC_AUTO_CLICKED / SRC_BROAD_DERIVED / SRC_AUTO_BROAD_TERM` 全部不可用，扩词降级为「仅人工提案」（`28号§1`）。
- 清仓期（`liquidating`）禁止扩词（`28号§3.2`）。

## 15. 输出字段要求

除 `12号§三` 的通用动作字段外，广泛类必须补以下字段：

| 字段 | 要求 |
| --- | --- |
| `campaign_type` | `broad_keyword` / `phrase_keyword` / `auto_discovery` |
| `action_code` / `physical_action_code` | 按 `30号§1` 成对输出 |
| `relevance_tier` | R1 / R2 / R3 / R4（`28号§2`）；档 4 否词必填判定依据 |
| `branch_hit` | 本轮命中 §4 的哪一档（1/2/3/4） |
| `search_term_action` | 否词 / 观察 / 提词 / 精准测试候选 |
| `promotion_channel` | 提词时必填：订单通道 / 词根通道 / CVR通道（§10） |
| `lookback_window` | 1天 / 3天 / 7天 / 14天 |
| `placement_adjustments` | 固定 `N/A` |
| `protected_testing` / `protection_expires_at` | 命中 §11 时必填 |
| `bottleneck_layer` | 预算类动作必填：组合层 / 活动层 / 父ASIN层（`23号§4.3`） |
| `evidence` | 花费、点击、订单、ACOS、相关性判定、Search Term 来源码 |
| `reason` | 说明为什么调、为什么否词或为什么不否词 |
