# 新增广告活动规则（add_campaign_rules.yaml）

定义 Agent 何时建议新增广告活动，以及新增时的初始预算、初始 bid、主投广告位推荐逻辑。

---

## 1. 触发场景

满足以下任一场景时，Agent 生成新增活动建议：

| 场景码 | 触发条件 | 数据来源 |
|--------|---------|---------|
| `KEYWORD_PROMOTED_FROM_BROAD` | 广泛/自动活动中某词：CVR > 品类均值 × 0.8 且 7天花费 > $10 且 尚无对应精准活动 | 搜索词报告 |
| `RANKING_OPPORTUNITY_NO_EXACT` | 该词自然位 28–48 且连续上升 且 尚无精准活动承接 | 自然排名数据 |
| `COMPETITOR_INTERCEPT_WINDOW` | 竞品弱势期触发（参见 `08-竞品规则.md`）且尚无对应竞品词精准活动 | 竞品规则触发 |
| `CUSTOM_KEYWORD_POOL` | 运营将词加入 Custom 词池且无对应活动 | 运营自定义，优先级最高 |
| `LOW_BUDGET_UTILIZATION` | 现有词池无法消耗预算（预算利用率连续3天 < 50%），需新增 Keyword 或 Campaign 补充流量入口 | 广告指标 |
| `ORDER_GAP_ACOS_OK` | 7天订单达成率 < 80% 且 ACOS 在目标范围内或 ≤ 目标 × 1.1，需新增有效词承接订单 | 广告指标 |
| `FILL_AFTER_ELIMINATION` | 刚淘汰低效活动后，判断词池明显变窄，必须补新活动避免流量盘缩小 | 淘汰动作联动触发 |
| `SEASONAL_ADVANCE_BUILD` | 进入旺季前期或旺季，提前新增 Broad、Long-tail、Competitor、Custom 词池活动 | 淡旺季标签 |

---

## 2. 初始预算推荐

**首次创建广告活动，默认日预算固定为 $3.00。**

| 参数 | 值 | 说明 |
|------|---|------|
| 首次创建默认日预算 | **$3.00** | 人工确认值，所有定位/阶段统一适用 |

**调整规则**：
- Custom 词池词：由运营指定预算，Agent 仅引用不覆盖
- 旺季期间如需提高，由运营手动调整，Agent 不自动上调首次预算

---

## 3. 初始 bid 推荐

```
初始 bid = min(0.5, 建议竞价 × 0.5)
```

| 参数 | 说明 |
|------|------|
| 建议竞价 | ERP 或亚马逊后台提供的该关键词建议竞价（suggested bid） |
| 0.5 上限 | 首次创建硬上限，防止初始出价过高 |
| × 0.5 系数 | 取建议竞价的一半，低价起步观察数据后再调整 |

**出价约束**：
- 下限：$0.20（低于此值亚马逊不可执行）
- 上限：$0.50（首次创建上限；后续调整上限参见 `03-阈值参数.md §9` ERP 硬上限 $3.00）

**计算示例**：建议竞价 $0.80 → $0.80 × 0.5 = $0.40，取 min(0.5, 0.40) = **$0.40**  
建议竞价 $1.20 → $1.20 × 0.5 = $0.60，取 min(0.5, 0.60) = **$0.50**

## 4. 主投广告位策略

**仅适用于 Exact（精准匹配）类型活动。**  
Broad / Phrase / Auto 活动禁止生成广告位建议（参见 `07-广告位规则.md §0`）。

| 新增活动类型 | 广告类型归类 | 广告位调整规则 | 运营备注 |
|------------|------------|------------|---------|
| Broad（广泛扩词） | 广泛广告 | 不做 Placement 调整；primary_placement = N/A | 低成本拿搜索词样本，重点看预算、Bid、搜索词质量和否词 |
| Phrase（词组广告） | 广泛广告 | 不做 Placement 调整；primary_placement = N/A | 归入广泛广告，比 Broad 更收窄但仍不做广告位调整 |
| Auto（自动测词） | 广泛广告 | 不做 Placement 调整；primary_placement = N/A | 先看系统匹配和 Search Term 质量，后续提取精准词。**如已存在自动广告活动，不再新增；无自动广告时才新增** |
| Long-tail（长尾词）— Exact 投放 | 精准广告 | 首次布局暂不推荐广告位调整 | 长尾词相关性高，先跑 Bid / 预算数据，稳定后再看广告位信号 |
| Long-tail（长尾词）— Broad/Phrase 投放 | 广泛广告 | 不做 Placement 调整；primary_placement = N/A | 按广泛广告策略处理，重点看搜索词质量和否词 |
| Exact（精准出单词） | 精准广告 | 首次布局暂不推荐广告位调整 | 词已验证有效，先稳定 Bid 和预算 |
| Ranking Keyword（冲排名词） | 精准广告 | 首次布局暂不推荐广告位调整 | 用于推动自然排名，先跑基础数据再加广告位 |
| Competitor（竞品词） | 精准承接 | 首次布局暂不推荐广告位调整 | 对比型流量，先观察转化 |
| Brand（品牌平替词） | 精准低价截流 | 首次布局暂不推荐广告位调整 | 低成本借品牌流量，不抢广告位 |
| Liquidation（清仓低价活动） | 视投放方式归类（Exact=精准，Broad/Phrase=广泛） | 首次布局暂不推荐广告位调整 | 利用低价优势承接比价流量，控 ACOS 为主 |

**首次布局广告位初始加价参考**（仅 Exact 活动，上线后有数据再调整）：

| 主投位 | 初始加价幅度 | 非主投位 |
|--------|------------|---------|
| 头部（TOS） | +10%（默认起点） | 其他 = 10%，商品 = 0% |
| 商品（PP） | +10%（默认起点） | 头部 = 0%，其他 = 10% |
| 其他（RoS） | +10%（默认起点） | 头部 = 0%，商品 = 0% |

## 5. 新增活动输出要求

Agent 输出新增活动建议时必须包含以下字段：

| 字段 | 中文解释 | 填写要求 |
|------|---------|---------|
| `proposal_type` | 建议类型 | 固定填写：新增广告活动 |
| `action_type` | 动作类型 | `create_campaign`（新建广告活动）/ `create_ad_group`（新建广告组） |
| `campaign_name` | 广告活动名称 | 命名规则：词 + 类型 + ASIN，方便 ERP 创建 |
| `campaign_type` | 广告活动类型 | 必须先判断：Exact = 精准广告；Broad / Phrase / Auto = 广泛广告 |
| `keywords_or_targets` | 关键词或投放对象 | 必须列出具体词或 ASIN |
| `match_type` | 匹配方式 | Broad / Phrase / Exact；Phrase 默认按广泛广告策略处理。**Auto 类型：若账户已存在自动广告活动，不新增；无自动广告时才建议新增** |
| `proposed_daily_budget` | 建议日预算 | 必须给具体金额（参见本文 §2） |
| `proposed_base_bid` | 建议基础竞价 | 必须给具体数值（参见本文 §3） |
| `primary_placement` | 主投广告位 | 仅精准广告必填（头部 / 其他 / 商品）；广泛 / 词组广告填 N/A |
| `placement_adjustment` | 广告位加价 | 仅精准广告可输出；广泛 / 词组广告禁止输出 |
| `negative_strategy` | 否词策略 | 新增广泛 / 词组广告必须设置后续否词观察规则 |
| `reason` | 新增理由 | 必须说明来源：搜索词 / 有效词根 / 竞品 / 历史有效词 / 节日趋势词等 |
| `evidence` | 证据链 | 来源、相关性、预期匹配方式、建议 Bid 理由 |
| `review_level` | 审核等级 | 默认 MANUAL_REVIEW；低风险历史有效词可 AUTO_BATCHABLE |

**输出示例**：

```yaml
action_type: create_campaign
campaign_key:
  child_asin: "..."
  keyword_match_type: "exact"     # 仅 exact 类型会有广告位字段
  keyword: "..."
initial_values:
  budget: 3.0                     # 首次创建默认 $3（参见 §2）
  bid: 0.40                       # 建议竞价 $0.80，min(0.5, 0.80×0.5)=0.40（参见 §3）
  primary_placement: "头部"       # 枚举：头部 / 其他 / 商品（仅 exact 填写）
placement_adjustments:            # 仅 exact 填写，broad/auto 此字段留空
  - placement: "头部"
    proposed_pct: 10
  - placement: "其他"
    proposed_pct: 10
  - placement: "商品"
    proposed_pct: 0
recommendation_reason:
  trigger_scene: "KEYWORD_PROMOTED_FROM_BROAD"
  evidence:
    - "7天花费 $12.3，CVR=6.2%，高于品类均值×0.8"
    - "当前无对应精准活动"
  budget_reason: "首次创建默认 $3"
  bid_reason: "建议竞价 $0.80，min(0.5, 0.80×0.5)=$0.40"
  placement_reason: "主投头部+10%，其他位置+10%，商品页暂不加价"
review_level: MANUAL_REVIEW
```

## 6. 阻断条件

以下情形禁止生成新增活动建议，状态置为 BLOCKED：

| 原因码 | 条件 |
|--------|------|
| `INVENTORY_LOW_BLOCK` | 父ASIN库存天数 < 7天（参见 `04-触发规则.md §3`） |
| `HIGH_RETURN_RATE_BLOCK` | 30天退货率 ≥ 30% |
| `LOW_RATING_BLOCK` | 评分 < 3.8 |
| `LIQUIDATING_ONLY_CORE` | 清仓期且该词不在 TOP 转化词列表 |
