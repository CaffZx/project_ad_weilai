# 核心词定义规则（core_keyword_definition.yaml）

定义广告 Agent 如何识别女装产品的核心词。本规则只定义“什么是核心词”和“依据什么数据识别”，不定义 Bid、预算、广告位、淘汰或审核动作。

---

## 1. 核心词的定位

核心词是指：对当前女装产品具有重要流量价值，需要被识别和重点保留的关键词。

核心词是一个二元标签：`is_core_keyword = true / false`。

- 核心词不等于所有精准匹配词；`EXACT` 是投放方式，不是核心词定义。
- 核心词不等于历史 ACOS 最低或订单最多的词。
- 核心词的识别范围是产品所属的**细分女装品类**，不得用整个女装大类作为判断范围。
- 本规则中的“核心”只表示关键词的重要性，不表示该词当前一定承担 Ranking 任务。

---

## 2. 判定总则

```text
is_core_keyword = no_semantic_conflict AND (semantic_core OR data_core)

其中：
  semantic_core = 命中 §3 的任一语义类型（R1 口径）
  data_core     = 命中 §4 的数据信号 **≥ 2 项**   ← v3.4.0 从「任一命中」收紧
```

含义：关键词首先不得与当前产品存在明确语义冲突；在此前提下，命中语义规则、
或命中至少两项数据信号，即判定为核心词。

> **本文是「核心词」的唯一权威定义**（`14号§3` 已改为引用本文）。
> v3.3.0 `14号§3` 另有一套「近14天订单≥3 AND ACOS≤目标线 AND 自然排名2-48 AND CVR≥品类均值×0.8」
> 四条同时满足的定义，与本文互斥。四条同时满足过严：满足它的词已是成熟主力词，本不需要保护；
> 真正需要保护的是「标题里的核心词但自然位在跌、暂时没出单」，而旧定义会把它排除在外。
>
> **`data_core` 为什么从「任一命中」收紧为「≥2 项」（C-12）**：核心词直接决定三处保护
> （`15号§1.3` 降幅 ≤5%、`05号§2` 审核升级、`21号§2` 禁淘汰、`32号§2.1` 禁降级）。
> 若仅凭「近14天花费位于前 30%」这一条就获得降幅保护，等于给高花费词发免死金牌——
> 而高花费恰恰可能是最需要优化的词，这是反向激励。
> `semantic_core` 单独命中仍可成立（标题词/核心卖点词本身就该被保护）。

### 2.1 识别对象与粒度

| 对象 | 识别粒度 | 说明 |
| --- | --- | --- |
| 不含变体属性的词 | `parent_asin + keyword_text` | 按父 ASIN 的产品定位、细分品类与核心卖点判断。 |
| 含颜色、尺码、款式等变体属性的词 | `parent_asin + child_asin + keyword_text` | 必须与当前投放子 ASIN 的实际在售属性一致。 |
| 搜索词 | 先转为可投放关键词后再识别 | 搜索词是数据对象，不直接赋予核心词标签。 |

### 2.2 明确语义冲突

出现以下任一情况，`no_semantic_conflict = false`，不得判定为核心词：

- 关键词品类与产品实际细分品类不一致；
- 关键词中的款式、结构、功能、人群、场景或变体属性与 Listing 明确不符；
- 关键词对应的颜色、尺码等变体不属于当前子 ASIN，或当前不可售；
- 关键词是纯价格、促销、平台活动或其他不表达产品本体的意图词。

---

## 3. 语义规则（semantic_core）

语义规则判断“该词是否直接代表这个产品”。判断依据为产品标题、五点、变体属性、产品定位标签与细分市场定位。

关键词直接表达以下任一信息时，`semantic_core = true`：

| 语义类型 | 判定要求 |
| --- | --- |
| 细分品类 | 词义直接指向产品所属的细分女装品类。 |
| 核心属性 | 词义直接表达产品实际具备的核心款式、版型、结构或功能。 |
| 真实变体属性 | 词义直接表达当前子 ASIN 真实在售的关键颜色、尺码、款式或其他变体属性。 |
| 核心人群或场景 | 词义直接表达产品明确服务的目标人群或核心使用场景。 |

语义相关性沿用 [28-新增词来源相关性与场景化配额规则 §2](28-新增词来源相关性与场景化配额规则.md#2-相关性分级规则r1-r4) 的 `R1 精确相关` 口径；R2、R3、R4 不得因语义规则判定为核心词。

---

## 4. 数据规则（data_core）

数据规则判断“该词是否已表现出重要流量或经营价值”。下列任一条件满足，即 `data_core = true`。

| 数据条件 | 判定口径 | 数据窗口 / 比较范围 |
| --- | --- | --- |
| 高广告花费 | 近 14 天广告花费位于该父 ASIN 在投关键词花费前 30% | 仅比较同一父 ASIN 的关键词，不跨 ASIN 比较。 |
| 高搜索量 | 搜索量位于该产品细分女装品类高相关词池前 30% | 词池仅包含与该产品细分品类和真实属性相关的关键词，不使用全女装大类词池。 |
| 广告效果已验证 | 近 14 天广告订单 `>= 3`，且 ACOS `<=` 当前有效容忍上限 | 按 `15号§4` 的有效容忍上限口径（含经营模式系数与女装修正）。 |
| 自然排名价值 | 自然排名进入 Top50，且排名稳定或上升 | 以近 14 天自然排名趋势判断。 |

说明：高广告花费、高搜索量、广告效果和自然排名是四个独立的数据识别信号。
**命中 ≥2 项**才满足 `data_core = true`（v3.4.0 收紧，C-12）。
某项数据缺失时该项不得命中，也不得用缺失数据推断（见 §6）。

---

## 5. 细分女装品类词池口径

核心词的搜索量比较，必须使用“产品细分品类高相关词池”，不得使用整个女装大类词池。

词池构成：

1. 产品主品类词；
2. 与产品真实属性一致的款式、版型、结构、功能、变体、人群和场景词；
3. 经相关性判断为 R1 的高相关词。

词池排除：

- 与产品不一致的女装细分类目词；
- 纯价格词、促销词、平台活动词；
- 明显不相关词和 R3/R4 试探词；
- 不属于当前可售子 ASIN 的变体属性词。

---

## 6. 数据来源与不可用处理

| 判断内容 | 首选数据来源 | 使用方式 |
| --- | --- | --- |
| 产品标题、五点、变体、产品定位 | Azlisting MCP | 用于语义规则和语义冲突判断。 |
| 广告花费、广告订单、ACOS | 广告活动/关键词表现数据 | 用于高广告花费和广告效果已验证判断。 |
| 搜索量、自然排名、自然排名趋势 | Starsrock MCP 关键词反查 | 用于高搜索量和自然排名价值判断。 |

- 产品语义资料缺失时，不得判定 `semantic_core = true`。
- 某项数据缺失时，该项数据规则不得命中；不得用缺失数据推断核心词。
- 数据来源、窗口和具体数值必须写入核心词识别证据。

---

## 7. 输出字段

每个被识别为核心词的关键词，必须输出以下字段：

| 字段 | 类型 | 填写要求 |
| --- | --- | --- |
| `is_core_keyword` | boolean | 是否为核心词。 |
| `core_keyword_basis` | array | `semantic_core`、`data_core` 或两者同时命中。 |
| `semantic_evidence` | array | 命中的产品品类、属性、变体、人群或场景证据；未命中则为空数组。 |
| `data_evidence` | array | 命中的花费、搜索量、订单/ACOS、自然排名证据；未命中则为空数组。 |
| `semantic_conflict_check` | pass / fail | 必须输出；fail 时 `is_core_keyword=false`。 |
| `source_report_refs` | array | 标明 Azlisting、广告数据、Starsrock 等实际来源。 |
| `identified_at` | date | 本次识别日期。 |

---

## 8. 数量控制与更新频率

- 每个父 ASIN 最多保留 30 个核心词。
- 核心词每周重新计算一次；产品定位、Listing、变体可售状态或关键词数据发生重大变化时，可提前重算。
- 若符合条件的词超过 30 个，按以下顺序保留：
  1. 同时命中语义规则和数据规则；
  2. 命中广告效果已验证或自然排名价值；
  3. 高广告花费；
  4. 高搜索量；
  5. 仅命中语义规则。
