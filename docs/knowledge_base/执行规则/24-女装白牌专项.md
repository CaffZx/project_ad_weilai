## 1. 女装白牌的三个结构性特征

女装白牌与标品的广告经济学差异，是本知识库许多阈值取值的原因。写在这里避免后人误改。

| 特征 | 表现 | 对广告规则的影响 |
| --- | --- | --- |
| **退货率天然高** | 美国女装品类基准退货率 25%（`03号§5`），远高于标品的 5–8% | 「有订单」不等于「有利润」。退货率 ≥30% 时阻断增长型动作（`09号§11`、`10号§7`） |
| **变体维度多且易断** | 一个父 ASIN 下常有 颜色 × 尺码 数十个子 SKU；断码断色是常态而非异常 | 核心 SKU 库存比例（`03号§5`）比总库存天数更重要；断码断色必须降低相关性档位（§3） |
| **款式生命周期短** | 季节性 + 潮流性叠加，一个款的有效经营窗口常常只有 8–16 周 | 产品阶段 `testing` 最长 60 天（`03号§2`）；旺季提前布局窗口比标品短（§4） |

## 2. 语义相关性的女装口径

`28号§2` 的相关性分级 `R1–R4` 与 `29号§3` 的语义规则，在女装上必须按以下维度判断。
**这是 `semantic_core` 与 `relevance_tier` 判定的女装专用口径。**

### 2.1 女装的五个语义维度

| 维度 | 说明 | R1 判定要求 |
| --- | --- | --- |
| **细分品类** | dress / blouse / cardigan / jumpsuit / skirt / coat … | 词义直接指向产品所属的细分品类，不能用「women's clothing」这类大类词充当 |
| **版型结构** | bodycon / A-line / oversized / wrap / high-waisted / puff sleeve … | 词中的版型必须与 Listing 实际版型一致 |
| **面料工艺** | knit / satin / linen / ribbed / sequin / corduroy … | 面料词必须与实际面料一致。面料错配是女装退货的主要原因之一 |
| **场景人群** | cocktail / work / vacation / maternity / plus size / petite … | 场景与人群必须是产品明确服务的对象 |
| **变体属性** | 颜色、尺码 | 必须属于**当前可售**子 ASIN。见 §3 |

### 2.2 女装的语义冲突（`no_semantic_conflict = false`）

出现以下任一情况，该词**不得**判定为核心词，且相关性最高只能给 R3：

- 品类不一致（如产品是 blouse，词是 dress）
- 版型/结构明确不符（如产品是 A-line，词是 bodycon）
- 面料明确不符（如产品是 polyester，词是 100% linen）
- 人群不符（如产品无加大码，词含 plus size / 4XL）
- 场景明显偏离（如产品是 loungewear，词是 wedding guest dress）
- 变体属性不属于当前可售子 ASIN（见 §3）
- 纯价格词 / 促销词 / 平台活动词（如 cheap dress under 20、prime day dress）

## 3. 断码断色规则（`VAR-*`）

> `28号§0.2` 与 `28号§3.3` 引用本节：「断码断色、高退货、低评分命中时，相关性档位整体收紧一档」。

### 3.1 断码断色的判定

| 条件码 | 判定 | 数据来源 |
| --- | --- | --- |
| `VAR-001` 核心 SKU 短缺 | 核心子 SKU 可售库存比例 < `03号§5` 的健康线 | `get_inventory_status(asin)` 子 SKU 级 |
| `VAR-002` 核心 SKU 严重短缺 | 核心子 SKU 可售库存比例 < `03号§5` 的严重短缺线 | 同上 |
| `VAR-003` 变体不可售 | 该颜色/尺码当前无可售库存或无购物车 | 同上 + Listing 状态 |

「核心子 SKU」= 近 30 天订单量前 50% 的子 SKU 集合。

### 3.2 命中后的动作修正

| 命中 | 相关性档位 | 允许动作 | 阻断动作 |
| --- | --- | --- | --- |
| `VAR-001` | 整体收紧一档（R1 判定门槛提高，R2 降为 R3） | 降 Bid、降预算、否不相关词、Listing 诊断 | TOS 加价、激进提价（`09号§2`） |
| `VAR-002` | 同上，且禁止扩词（`28号` 扩词场景 BLOCKED） | 仅降本动作与 `balance_maintain` | 全部增长型动作 |
| `VAR-003` | 含该变体属性的词一律 `no_semantic_conflict = false` | 对含该属性的词否词或降 Bid | 不得对含不可售变体属性的词提词或扩词 |

**硬规则**：含不可售变体属性的关键词，**不得**判定为核心词（`29号§2.2`），
**不得**进入精准测试组（`23号§3.4` 相关性前提不满足），**不得**扩词（`28号§2` R4 禁止）。

## 4. 节日款与季节款（`SEA-*`）

> `28号§0.1` TRG-4、`28号§0.3` 矩阵的 liquidating 列、`28号§3.2` 旺季提前布局引用本节。

### 4.1 女装的季节节奏

女装的旺季判定不能只看月份（`02号§3` 已明确「不能只按月份判断」）。女装白牌的实际节奏：

| 时段 | 典型品类 | 提前布局窗口 |
| --- | --- | --- |
| 春夏（3–7 月） | dress / blouse / linen / vacation | 旺季前 3–4 周 |
| 秋冬（9–12 月） | cardigan / coat / knit / sweater | 旺季前 4–6 周 |
| 节日尖峰 | holiday party dress / sequin / velvet | 尖峰前 5–7 周（节日款窗口最短、失效最快） |

具体旺季阶段判定仍以 `02号§3` 的四态（淡季 / 旺季前期 / 旺季 / 旺季末期）与
`03号§3` 的系数为准。本节只提供女装的**窗口长度参考**，用于 `SEASONAL_ADVANCE_BUILD` 触发时机。

### 4.2 节日款的特殊处理（`SEA-001`）

节日款（holiday / party / event 类）与常规款的差异：

| 项 | 规则 |
| --- | --- |
| 布局时机 | 尖峰前 5–7 周开始新建活动；`16号§1` `SEASONAL_ADVANCE_BUILD` 场景 |
| 相关性放宽 | 旺季提前布局允许放宽到 R2（`28号§3.2`），节日款不额外放宽 |
| 尖峰后处理 | 尖峰过后 2 周内 ACOS 容忍不额外收紧（避免误杀尾部承接），2 周后按 `旺季末期` 系数（`03号§3`）执行 |
| **清仓期例外** | `liquidating` 阶段原则禁止扩词（`28号§3.2`），**唯一例外是节日款尾货承接**：允许少量 R1 词承接比价流量，单轮 ≤2 个词，强制 `HIGH_RISK_REVIEW`，且必须运营显式确认 |

> `28号§0.3` 矩阵注中的「liquidating 列除『节日款尾货承接』（24号§4 节日款，需人工）外一律禁扩」
> 即指本节此条。

## 5. 毛利率门槛（`PRC-*`）

> `28号§4.1` 引用 `PRC-004`：「我方毛利率 <20% 时禁止竞品词扩词」。

| 条件码 | 门槛 | 阻断动作 | 理由 |
| --- | --- | --- | --- |
| `PRC-001` | 毛利率 < 15% | 阻断全部增长型动作，仅允许 `balance_maintain` 与降本 | 毛利不足以承担任何广告增量 |
| `PRC-002` | 毛利率 < 20% | 阻断 TOS 加价 | TOS 是最贵的位，低毛利不应抢头部 |
| `PRC-003` | 毛利率 < 20% | 阻断品牌词 / 类目大词扩词（`SRC_BRAND_CATEGORY`） | 大词 CPC 高且相关性不可控 |
| `PRC-004` | 毛利率 < 20% | **阻断竞品词扩词**（`SRC_COMPETITOR_ASIN`） | 竞品词是对比型流量，CVR 低于自然搜索词，低毛利下难以回本 |
| `PRC-005` | 毛利率 < 25% 且退货率 ≥ 25% | 有效容忍上限额外收紧 5 个百分点（在 `15号§4` 计算结果上减 5pp） | 退货会二次侵蚀毛利，名义 ACOS 达标不代表实际盈利 |

**毛利率口径**：`margin` 字段由 ERP 提供，为扣除采购、头程、FBA 费、平台佣金后的毛利率，
**不扣广告费**。数据缺失时视为 `PRC-002/003/004` 命中（保守处理），并标 `DATA_MISSING`。

## 6. 退货与评价的女装联动

本节不重复定义阈值（在 `03号§5`），只说明女装特有的联动判断。

### 6.1 品质投诉关键词

以下负面评价关键词命中时，`confidence` 降低 0.3，全部提价类建议升级为 `MANUAL_REVIEW`
（沿用 `03号§5`）：

尺码不准 · 面料差 · 色差 · 做工粗糙 · 不像图片 · 起球 · 透 · 缩水

### 6.2 女装的页面承接排查

`14号§15` 的通用排查清单在女装上的优先级排序（CVR 异常低时按此顺序查）：

1. **尺码表是否清晰** —— 女装退货第一原因，直接影响 CVR 与退货率
2. **主图是否展示多场景穿搭** —— 女装决策高度依赖场景想象
3. 颜色选项是否完整、是否有主推色断货
4. 评价中是否有尺码/面料负面反馈集中出现
5. 价格 / Coupon 是否有竞争力（对比 `08号` 竞品价格定位）
6. A+ 内容是否覆盖面料细节与版型说明
7. 类目节点是否正确
8. 链接是否有购物车

### 6.3 退货率与相关性的联动

| 退货率 | 相关性档位修正 | 依据 |
| --- | --- | --- |
| < 15%（健康） | 不修正 | `03号§5` |
| 15–25% | 不修正 | |
| 25–30%（警戒） | 扩词相关性收紧一档（R2 → R3 门槛） | `28号§0.2` |
| ≥ 30%（阻断放量） | 扩词相关性收紧一档，且阻断全部增长型动作 | `09号§11`、`10号§7` |
| ≥ 40%（极端） | 状态 BLOCKED，建议人工评估是否停投 | `03号§5` |

## 8. 输出要求

命中本文任一条件码的动作，必须在输出中补：

| 字段 | 要求 |
| --- | --- |
| `apparel_rule_refs` | 命中的条件码数组（如 `["VAR-001", "PRC-004"]`） |
| `relevance_tier_adjusted` | 修正后的相关性档位，并注明修正前档位与修正原因 |
