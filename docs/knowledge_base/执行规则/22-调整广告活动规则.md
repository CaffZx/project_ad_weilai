# 调整广告活动规则（adjust_campaign_rules.yaml）

定义 Agent 如何对存量广告活动进行 Budget / Bid / Placement / Search Term 四个维度的调整建议，以及必须输出的字段。

---

## 0. 核心原则

- **必须先判断广告活动类型**，再决定可调整哪些维度（见 §1）
- 精准广告拆成三层：Budget → Bid → Placement
- 广泛/词组广告拆成三层：Budget → Bid → Search Term（否词/提词）
- 广泛/词组广告**禁止输出 Placement 调整**，placement 字段填写 `N/A`
- AI 不能直接从「ACOS 高」跳到「降 Bid」或「淘汰」，必须先走分层诊断

---

## 1. 广告活动类型判定（调整前必判）

| 投放方式/活动类型 | 归类 | 允许调整项 | 禁止调整项 |
|-----------|------|----------|-----------|
| EXACT | 精准广告 | Budget + Bid + Placement（头部/其他/商品） | 不能大规模否词；不能盲目扩泛词 |
| BROAD | 广泛广告 | Budget + Bid + Search Term（否词/提词） | Placement 调整，填 N/A |
| PHRASE | 广泛广告（按广泛策略处理） | Budget + Bid + Search Term（否词/提词） | Placement 调整，填 N/A |
| AUTO | 广泛广告（按测词逻辑） | Budget + Bid + Search Term（否词/提词） | Placement 调整，填 N/A |

---

## 2. 精准广告调整规则

### 2.1 Budget（预算）调整

| 场景 | 建议动作 | 审核等级 |
|------|---------|---------|
| 预算利用率 ≥ 70% + ACOS ≤ 目标×1.1 + 库存天数 ≥ 30天 | `campaign_budget_increase`（增加预算） | 默认 MANUAL_REVIEW；增幅 > 30% 升 HIGH_RISK_REVIEW |
| 3天 ACOS ≥ 目标×1.3 | `campaign_budget_decrease`（降低预算） | 默认 AUTO_APPROVED；主力精准活动需 MANUAL_REVIEW |

### 2.2 Bid（基础竞价）调整

| 场景 | 建议动作 | 审核等级 |
|------|---------|---------|
| `ranking_opportunity` 触发（自然位上升 + ACOS 可控 + CVR 不下降） | `bid_up_for_ranking`（提价冲排名） | 提价 ≤ 10% 可 AUTO_APPROVED；> 20% 需 HIGH_RISK_REVIEW |
| 3天 Keyword ACOS > 目标×1.2 且 7天订单 < 2单 | `bid_down_for_acos`（降价控 ACOS） | 核心词必须 MANUAL_REVIEW；非核心词 AUTO_APPROVED |

> **Ranking 保护**：如果关键词承担冲排名任务，即使 ACOS 短期偏高，也**禁止降 Bid**。

### 2.3 Placement（广告位）调整

**仅精准广告（Exact）适用**，广泛/词组广告此节跳过。

按三个广告位分别评估，每个位置独立输出建议：

| 数据情况 | 判断逻辑 | 建议动作 |
|---------|---------|---------|
| 有花费 + 有有效广告位 | 对比头部/商品/其他三个广告位的 ACOS、订单、CVR；哪个位置 ACOS 更低、转化更好，优先加该位置比例 | 提高表现最好广告位的加价比例 |
| 有花费 + 无有效广告位 | 广告位有消耗但无订单，或 ACOS 明显偏高（> 目标×1.5），该位置无有效转化 | 降低对应广告位比例 |
| 无花费 | 当前广告位无消耗，无法判断好坏 | 可试探其他（RoS）和头部（TOS）；优先测其他再测头部 |

广告位最终有效出价按 `07-广告位规则.md` 计算：`placement_effective_bid = base_bid × (1 + placement_pct / 100)`。若基础 Bid 与广告位比例同轮变化，必须先确定 `proposed_base_bid`，再用各广告位 `proposed_pct` 计算对应广告位的理论有效出价。

**广告位调整阻断条件：**

| 阻断场景 | 影响 | 处理 |
|---------|------|------|
| 缺少广告位数据 | 阻断全部 Placement 调整 | 状态 BLOCKED，原因码 `PLACEMENT_DATA_MISSING` |
| 库存不足（< 15天） | 阻断头部（TOS）和商品（PP）加价 | BLOCKED |
| 高退货率（≥ 30%） | 阻断头部（TOS）加价 | BLOCKED |
| 低评分（< 3.8） | 阻断头部（TOS）加价 | BLOCKED |
| TOS/PP 花费高但无单 | 先降广告位加价；不降基础 Bid；不直接淘汰活动 | 降 Placement % |

**广告位输出格式（三个位置必须全部输出）：**

```yaml
placement_adjustments:
  - placement: "头部"
    current_pct: 20
    proposed_pct: 30
    action: "上调"
    evidence: "头部7天ACOS=18%，目标25%，7天订单4单"
  - placement: "其他"
    current_pct: 0
    proposed_pct: 0
    action: "维持"
    evidence: "无花费，暂不调整"
  - placement: "商品"
    current_pct: 10
    proposed_pct: 0
    action: "下调"
    evidence: "商品页7天花费$6，点击8次，0订单，ACOS=MAX"
```

## 3. 广泛广告/词组广告调整规则

### 3.1 Budget（预算）调整

| 场景 | 建议动作 | 审核等级 |
|------|---------|---------|
| 预算花不出去，曝光/点击不足 | 先检查 Bid 是否过低、词搜索量是否太小；词覆盖不足时补广泛词根；提Bid后仍花不完 → 降预算（花不完说明预算过剩） | 不可因预算低直接开广告位加价 |
| 预算花完但 ACOS 高、搜索词质量差 | 降低预算，或把预算转移给有效词/精准承接 | 非主力广泛 AUTO_APPROVED；主力广泛 MANUAL_REVIEW |

### 3.2 Bid（基础竞价）调整

| 场景 | 建议动作 | 审核等级 |
|------|---------|---------|
| 曝光不足但词高度相关 | 小幅提高 Bid，观察1–3天 | 提 Bid 幅度建议 ≤ 15% |
| 点击多无单 或 搜索词质量差 | 降 Bid；必要时转低价捡漏组 | 降 Bid **前必须先检查是否应先否词** |

### 3.3 Search Term（搜索词）治理

广泛/词组广告**每轮调整必须读取搜索词报告**，无效/不相关/高点击无单的搜索词必须进入否词判断。

| 场景 | 建议动作 | 审核等级 |
|------|---------|---------|
| 明显不相关词 | `add_negative`（加否词） | 广泛/词组广告必须执行 |
| 高点击无单词（点击 ≥ 10 次无单） | 先判断相关性：不相关→否词；相关但转化弱→降 Bid 或继续观察 | 点击 ≥ 10 无单：预警；点击 ≥ 20 无单：强优化 |
| 有订单 + 有 CVR + 有词根价值 | 提取为 Exact 精准广告或 Long-tail 承接 | 提词后原广泛保留测词功能 |

### 3.4 Placement（广告位）— 广泛广告禁区

| 规则 | 执行 |
|------|------|
| 任何广泛/词组/自动广告场景，禁止输出广告位调整建议 | placement 字段填写 `N/A` |

## 4. 调整广告活动必须输出的字段

| 字段 | 中文说明 | 精准广告填写要求 | 广泛/词组广告填写要求 |
|------|---------|--------------|-------------------|
| `proposal_type` | 建议类型 | 固定：**调整广告活动** | 固定：**调整广告活动** |
| `object_class` | 对象类型 | `Campaign` / `KeywordTarget` / `Placement` | `Campaign` / `SearchTerm` |
| `campaign_type` | 广告活动类型 | `exact_keyword` | `broad_keyword` / `phrase_keyword` / `auto_discovery` |
| `campaign_name` | 被调整的活动名称 | 必须明确 | 必须明确 |
| `current_budget` | 当前日预算 | 必须读取 | 必须读取 |
| `proposed_budget` | 建议日预算 | 必须给具体金额 | 必须给具体金额 |
| `current_base_bid` | 当前基础竞价 | 必须读取 | 必须读取 |
| `proposed_base_bid` | 建议基础竞价 | 必须给具体数值 | 必须给具体数值 |
| `current_tos` / `proposed_tos` | 头部广告位当前值/建议值 | 必须读取；缺数据则阻断 | **N/A，禁止输出** |
| `current_pp` / `proposed_pp` | 商品页广告位当前值/建议值 | 必须读取；缺数据则阻断 | **N/A，禁止输出** |
| `current_ros` / `proposed_ros` | 其他位置广告位当前值/建议值 | 可读取并输出维持/调整 | **N/A，禁止输出** |
| `negative_search_terms` | 否词建议列表 | 仅明显不相关时输出 | **必须读取搜索词报告并给出否词判断** |
| `extract_to_exact` | 提取为精准的词 | 可用于补充精准承接 | 跑出有效词时必须判断是否提取 |
| `evidence` | 证据链 | 花费、订单、ACOS、CVR、自然位、广告位数据 | 花费、订单、ACOS、CVR、搜索词质量、否词依据 |
| `source_report_refs` | 证据来源 | targeting_report / placement_report / organic_rank_signal | search_term_report / targeting_report |
| `ontology_validation_status` | ontology 校验状态 | passed / blocked / downgraded / review_required | passed / blocked / downgraded / review_required |
| `expected_impact` | 预期影响 | 说明订单、ACOS、自然排名、预算影响 | 说明词池质量、无效点击下降、有效词沉淀 |
| `adjustment_decision_path` | 决策路径说明 | 说明走了哪个判断分支 | 说明走了哪个判断分支 |
| `review_level` | 审核等级 | 按风险和护栏输出 | 按风险和护栏输出 |

## 5. 输出示例

### 精准广告调整示例

```yaml
proposal_type: 调整广告活动
object_class: Campaign
campaign_type: exact_keyword
campaign_name: "floral_dress_exact_B0XXXXXXXX"
current_budget: 20.0
proposed_budget: 20.0              # 预算利用率72%，未达70%+连续3天，维持
current_base_bid: 0.85
proposed_base_bid: 0.98            # ranking_opportunity触发，提价+15%
placement_adjustments:
  - placement: "头部"
    current_pct: 10
    proposed_pct: 20
    action: "上调"
    evidence: "头部7天ACOS=18%，目标25%，7天订单4单，自然位32连续上升"
  - placement: "其他"
    current_pct: 0
    proposed_pct: 0
    action: "维持"
    evidence: "无花费，无信号"
  - placement: "商品"
    current_pct: 0
    proposed_pct: 0
    action: "维持"
    evidence: "无花费，无信号"
negative_search_terms: []
extract_to_exact: []
evidence:
  - "7天花费$14.2，订单6单，ACOS=22%（目标25%）"
  - "自然排名：32位，7天上升4位"
  - "CVR=5.8%，高于品类均值"
source_report_refs:
  - targeting_report
  - placement_report
  - organic_rank_signal
ontology_validation_status: passed
expected_impact:
  orders: "预计自然排名继续上升，带动自然单增加"
  acos: "短期ACOS可能小幅上升，在目标容忍范围内"
  organic_rank: "预计排名进入Top25"
  budget: "预算无变化"
adjustment_decision_path: "精准广告→Bid：ranking_opportunity触发→提价+15%；Placement：头部有效→上调+10%"
review_level: MANUAL_REVIEW
```

### 广泛广告调整示例

```yaml
proposal_type: 调整广告活动
object_class: Campaign
campaign_type: broad_keyword
campaign_name: "casual_dress_broad_B0XXXXXXXX"
current_budget: 15.0
proposed_budget: 13.0              # 预算花完但ACOS高，降预算
current_base_bid: 0.70
proposed_base_bid: 0.63            # 点击多无单，降Bid（先确认已否词）
placement_adjustments: N/A         # 广泛广告禁止输出广告位调整
negative_search_terms:
  - keyword: "wedding dress"
    reason: "明显不相关，7天点击12次，0订单"
    match_type: "精确否定"
  - keyword: "plus size evening gown"
    reason: "品类差异过大，7天点击8次，0订单"
    match_type: "精确否定"
extract_to_exact:
  - keyword: "floral casual summer dress"
    reason: "7天花费$8，3单，CVR=4.2%，有词根价值"
    suggested_action: "新增精准承接活动"
evidence:
  - "7天花费$13.8，3单，ACOS=38%（目标25%）"
  - "搜索词报告：20个搜索词，有效词3个，不相关词5个，高点击无单词4个"
  - "否词执行后预计无效点击下降30%"
source_report_refs:
  - search_term_report
  - targeting_report
ontology_validation_status: passed
expected_impact:
  orders: "否词后流量质量提升，CVR预计小幅改善"
  acos: "ACOS预计降至目标范围内"
  organic_rank: "不涉及"
  budget: "降预算$2，控制无效花费"
adjustment_decision_path: "广泛广告→否词：5个不相关词否定；Bid：点击多无单→降Bid-10%；Budget：ACOS高→降预算$2"
review_level: MANUAL_REVIEW
```
