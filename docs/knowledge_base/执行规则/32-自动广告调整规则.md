# 自动广告调整规则（正式补充稿）

> 状态：正式补充规则，可并入正式知识库。  
> 适用对象：Sponsored Products `campaign_type=auto_discovery`。  
> 继承 Ontology：`AutoTarget` 包含 `close_match / loose_match / substitutes / complements`；Budget 属于 Campaign，Bid 属于 AutoTarget。  
> 本稿不修改现有“自动广告不输出 Placement 调整”的系统约束，Placement 统一 N/A。

---

## 1. 业务目标

1. 将自动广告从“统一当成一个 BROAD”升级为四类投放分别诊断。
2. 正确区分 Campaign 预算与 AutoTarget Bid，避免四类投放虚构四个预算。
3. 用自动广告发现搜索词、商品和类目机会，并将有效流量迁移到可控的精准承接。
4. 对无效流量执行可解释、可审核的否词或否定商品投放。
5. 自动广告的核心定位是“发现流量、验证搜索词、补充商品流量”，不是推关键词自然位的主力工具。
6. 自动广告预算不得在整体广告预算中占比过高；推自然位预算应优先分配给已验证的精准词、核心词和自然位机会词。

## 2. 对象层级

| 层级 | 对象 | 允许动作 |
| --- | --- | --- |
| Campaign | 自动广告活动 | 调整共享日预算；移组；整体保持或低价观察 |
| AdGroup | 自动广告组 | 承载 ProductAd 和 AutoTarget |
| AutoTarget | 四类自动投放目标 | 分别调整 Bid、保持或关闭建议（关闭仅人工） |
| SearchTerm | 实际用户搜索词 | 提取精准词、添加否定关键词 |
| Product Target Evidence | 替代/互补触发的商品 ASIN | 创建商品投放建议、否定商品投放 |

SearchTerm 不能直接调 Bid；AutoTarget 不能拥有独立 Campaign Budget。

## 3. 必需数据

### Campaign 层

- 当前日预算；
- 近 1/3/7/14 天花费、销售额、订单、ACOS、预算利用率；
- Campaign 状态、上线天数、投放策略；
- 父 ASIN 库存、评分、退货、产品阶段和目标 ACOS。

### AutoTarget 层

- `auto_target_type`；
- 当前 Bid；
- 近 3/7/14 天曝光、点击、花费、订单、销售额、ACOS、CPC、CVR；
- 数据是否能按四类投放拆分。

### 搜索词/商品层

- Search Term 文本或被投放 ASIN；
- 点击、花费、订单、ACOS、相关性；
- 现有 EXACT/BROAD/商品投放重复检查；
- 搜索词报告更新时间。

若四类 AutoTarget 数据无法拆分，允许 Campaign 层诊断，但禁止生成四类目标的独立 Bid 建议。

## 4. 数据状态与动作边界

| 数据状态 | 处理 |
| --- | --- |
| Bid 未获取到 | 显示 `BID_DATA_MISSING`，禁止用 0 替代，阻断 Bid 动作 |
| Search Term 报告缺失 | 否词和提词 BLOCKED；降 Bid 最低人工审核 |
| 四类目标表现无法拆分 | 只允许 Campaign 级诊断，不输出目标级好坏 |
| 样本不足 | 保持、延长观察、设置复评；禁止降价、否词、淘汰 |
| Campaign 预算数据缺失 | 所有预算动作 BLOCKED |
| 数据正常且样本充分 | 进入四类投放决策 |

## 5. 亚马逊自动广告四类匹配方式定义

自动广告必须按 `close_match / loose_match / substitutes / complements` 四类分别理解和诊断，不得在页面或 Agent 输出中统一写成“广泛匹配”。

| 自动投放类型 | 中文名称 | 流量来源 | 业务定义 | 运营关注点 |
| --- | --- | --- | --- | --- |
| `close_match` | 紧密匹配 | 基于关键词 | 买家使用与商品高度相关的搜索词时，亚马逊根据 Listing 标题、五点、描述、后台词等内容抓取关键词并展示广告 | Listing 必须布局高度精准的产品词、款式词、功能词、属性词；需要建立并维护本品关键词词库 |
| `loose_match` | 宽泛匹配 | 基于关键词 | 买家使用与商品相关但不够精准、搜索意图更宽的词时，亚马逊可能展示广告 | 用于探索搜索词，但必须依赖 Search Term 报告治理；无效词要进入否词评估 |
| `substitutes` | 同类商品 | 基于商品 / ASIN | 亚马逊根据商品相似度和大数据分析，将广告展示在同类产品列表页或详情页中 | 属于 ASIN 型流量，默认权重低于关键词型流量；重点看竞品 ASIN 的品类、款式、价格带、评分、评论量、ACOS 和毛利承接能力 |
| `complements` | 关联商品 | 基于商品 / ASIN | 亚马逊将广告展示在互补商品详情页中，例如鼠标展示在键盘详情页 | 属于 ASIN 型流量，女装类目中互补关系通常更弱；默认低权重，必须谨慎控制 Bid 和预算，不能仅凭曝光判断有效 |

自动广告优化原则：站在数据角度优化投放，用尽可能少的预算获取有效销量和有效搜索词。节省下来的广告费用，应优先支持更可控、更能承接自然位推进的精准广告。

### 5.0 四类投放权重原则

自动广告四类投放的权重不是相同的：

| 类型 | 权重倾向 | 原因 |
| --- | --- | --- |
| 紧密匹配 `close_match` | 相对最高 | 基于 Listing 关键词抓取搜索词，和产品语义最接近，适合发现可迁移精准的有效 Search Term |
| 宽泛匹配 `loose_match` | 中等 | 基于关键词扩展搜索词，适合探索词池，但必须依赖 Search Term 报告治理无效词 |
| 同类商品 `substitutes` | 较低 | 基于 ASIN/竞品页面流量，女装类目款式、价格、评分、图片差异会显著影响转化 |
| 关联商品 `complements` | 最低 | 基于互补商品页面流量，女装类目互补关系通常不强，误流量风险更高 |

ASIN 型投放（`substitutes / complements`）只有在以下条件同时满足时，才允许提高权重或保留较高 Bid：

1. 近 7/14 天有广告出单；
2. ACOS 明显健康，且不高于当前阶段目标ACOS倍数阈值；
3. 结合售价、广告花费和单件成本后，广告订单仍有一定毛利空间；
4. 被投放 ASIN 与本品在品类、款式、价格带、目标人群上有明确承接关系；
5. 没有挤占父 ASIN 下更高价值精准词或 close/loose 关键词型自动流量预算。

若 ASIN 型投放只有曝光/点击，没有订单或毛利证据，不得因为“同类/关联”标签默认保留高预算或高 Bid。

### 5.1 Listing 与关键词词库要求

紧密匹配和宽泛匹配都依赖亚马逊对 Listing 文本的理解，因此自动广告运行前必须检查：

- 标题、五点、描述、后台 Search Terms 是否覆盖产品真实品类、款式、结构、功能、颜色、人群和场景；
- Listing 是否存在错误属性、父体其他变体属性、非本品功能词；
- 是否已形成本品关键词词库，至少包含核心品类词、款式结构词、功能卖点词、颜色/变体属性词、人群场景词和禁投/谨慎词；
- 若 Listing 关键词基础明显缺失，自动广告产生的搜索词质量下降时，不应直接归因于自动广告无效，应先进入 Listing/关键词词库修正建议。

### 5.2 自动广告与自然位目标关系

- 自动广告不作为“推关键词自然位”的主力动作。
- 自动广告跑出的优质 Search Term，可以迁移为 EXACT 精准广告后再承担自然位推进。
- 若目标是推自然位，预算应优先给已验证的精准核心词、排名机会词和转化健康词。
- 自动广告可以帮助发现新词、验证搜索意图、补充同类/关联商品流量，但不得因为“推自然位”标签而盲目提高自动广告预算。
- 当自动广告与精准广告争抢预算时，优先保障精准广告中有订单、ACOS 健康、自然位有机会的词。

## 6. 四类自动投放场景

### 6.1 紧密匹配 `close_match`

**作用**：发现与 Listing 高度相关的搜索词，是自动广告中最接近产品核心语义的流量。

| 场景 | 动作 | 审核 |
| --- | --- | --- |
| ACOS 健康、有订单、预算未花完 | 保持 Bid；优先提取有效 Search Term | 保持可低风险，提词按规则审核 |
| ACOS 健康、有订单、曝光不足且预算未耗尽 | 可小幅提高 AutoTarget Bid | 单次幅度≤5%，统一 `MANUAL_REVIEW` |
| 点击高无单 | 先按 Search Term 逐词检查相关性，不直接降低整个 close_match | `MANUAL_REVIEW` |
| 搜索词相关但转化弱 | 检查 Listing、价格、变体；必要时人工降 Bid | `MANUAL_REVIEW` |
| 搜索词明显不相关 | 建议否定精准/词组，不能仅凭 Target 整体 ACOS 否定 | `MANUAL_REVIEW` |

### 6.2 宽泛匹配 `loose_match`

**作用**：扩大词根和搜索意图探索，允许比 close_match 更宽，但必须依赖 Search Term 治理。

| 场景 | 动作 | 审核 |
| --- | --- | --- |
| 持续跑出相关 Search Term | 保持或小幅调整 Bid，提取有效词 | 按具体动作 |
| 搜索词相关率低 | 先否定不相关词，再评估 loose_match Bid | 否词/降 Bid 均人工 |
| 高花费无订单 | 检查是否由少数无效词造成；先治理搜索词 | `MANUAL_REVIEW` |
| 无曝光且 Campaign 预算未耗尽 | 检查 Bid 和目标状态，可小幅提高 Bid | 数据完整时可低风险提案 |
| 预算已花完但 ACOS 差 | 不增加预算；先治理 Search Term 和 Bid | `MANUAL_REVIEW` |

### 6.3 同类商品 `substitutes`

**作用**：在相似商品详情页或相近商品流量中获取竞品替代机会。该类流量基于 ASIN，不是基于搜索关键词，默认权重低于 close_match 和 loose_match。

必须检查：被投放 ASIN 的品类、款式、价格带、评分、评论量、库存、ACOS、广告订单毛利和我方承接能力。

| 场景 | 动作 | 审核 |
| --- | --- | --- |
| 相似商品带来订单、ACOS 健康且广告订单有毛利 | 保持 Bid；可建议建立独立商品投放承接 | 新建承接人工审核 |
| 相似商品有订单但 ACOS 或毛利不健康 | 不提 Bid、不加预算；先观察或人工降 Bid | `MANUAL_REVIEW` |
| 少数 ASIN 高花费无单 | 优先否定具体商品 ASIN，不直接压低整个 substitutes | `MANUAL_REVIEW` |
| 大量相似 ASIN 均低效 | 完成商品级诊断后可人工降低 substitutes Bid | `MANUAL_REVIEW` |
| 商品数据无法识别 | 禁止否定商品和降低目标 Bid | `BLOCKED` |

### 6.4 关联商品 `complements`

**作用**：探索搭配或场景关联商品，相关性通常低于紧密、宽泛和同类商品。该类流量基于 ASIN/页面关联，不是基于搜索关键词，默认低权重，不能仅凭曝光判断有效。

| 场景 | 动作 | 审核 |
| --- | --- | --- |
| 有订单、互补关系明确、ACOS 健康且广告订单有毛利 | 保持或建立独立商品投放测试 | `MANUAL_REVIEW` |
| 有订单但毛利或 ACOS 不健康 | 不提 Bid、不加预算；人工评估是否降 Bid 或否定具体 ASIN | `MANUAL_REVIEW` |
| 有点击无单但样本不足 | 延长观察，不降 Bid |
| 高花费无单且互补关系弱 | 建议否定具体商品或人工降 Bid | `MANUAL_REVIEW` |
| 类目明显不相关 | 否定商品投放建议 | `MANUAL_REVIEW` |

complements 不得因“场景化拓展”被默认保护；也不得因短期无单直接停止投放。

## 7. Campaign 预算规则

### 7.1 层级规则

- 同一自动 Campaign 中四类 AutoTarget 共用一个日预算。
- 页面和 Agent 不得为 close/loose/substitutes/complements 各输出独立预算。
- 若业务需要独立预算，必须建议拆成独立 Campaign，并进入人工审核。

### 7.2 自动广告预算定位

自动广告预算是探索预算和补充预算，不是主推预算。系统在输出预算建议前，必须先判断该父 ASIN 的广告目标：

| 父 ASIN / 广告目标 | 自动广告预算原则 |
| --- | --- |
| 推自然位 | 自动广告占比应保持低位，预算优先给已验证精准词和自然位机会词 |
| 新品/测试期 | 可保留适度自动广告预算用于探索搜索词，但必须设置上限和复盘；优先给 close/loose 关键词型流量 |
| 稳定期 | 自动广告以发现增量词和补充商品流量为主，不应持续扩大占比 |
| 清货期 | 原则上不扩大自动广告预算，仅保留低成本有效流量 |
| 长尾/P3产品 | 自动广告预算必须更谨慎，避免大量低意图流量消耗 |
| ASIN 型流量出单 | 仅当 ACOS 健康且广告订单有毛利时，才允许保留或小幅提高 ASIN 型投放权重 |

正式占比口径：

- 自动广告预算占该父 ASIN 总广告预算的比例，作为预算占比判断口径；
- 通用上限：自动广告预算占比原则上不超过 15%；
- 推自然位、P0/P1 主推产品：自动广告预算占比建议控制在 10% 至 15%，预算优先给已验证精准词和自然位机会词；
- 新品/测试期：自动广告仍不建议超过 15%；如确需探索，必须说明产品阶段、词池不足原因、Search Term 质量复盘计划，并进入 `MANUAL_REVIEW`；
- P3长尾、淡季、清货期：自动广告预算占比建议不高于 10%，除非已有明确低 ACOS 且有毛利的广告订单；
- ASIN 型投放（substitutes/complements）不得单独推动自动广告预算突破 15% 上限，除非有持续订单、ACOS 健康、且广告出单仍有毛利；
- 不同产品可以根据阶段、库存、目标、毛利和历史转化做人工评估，但超出 15% 一律不能自动执行，必须进入 `MANUAL_REVIEW`。

触发超占比时，Agent 不得自动增加自动广告预算，应优先治理无效 Search Term、降低低效 AutoTarget Bid、否定低效 ASIN，或把有效词迁移到精准广告。由运营判断是否保留、收缩或迁移预算。

### 7.3 预算动作

| 场景 | 预算结论 |
| --- | --- |
| 预算花不完 | 禁止增加预算；先检查目标 Bid、开启状态、流量和相关性 |
| 无花费 | 预算保持，优先检查 Bid 和数据链路 |
| 预算利用率高、整体 ACOS 健康、订单稳定、库存健康，且自动广告占比未超 15% 上限 | 可建议增加 Campaign 预算，最低人工审核 |
| 预算利用率高、整体 ACOS 健康，但自动广告占比已高 | 不优先加自动广告预算；建议把有效 Search Term 迁移到精准广告 |
| 预算利用率高主要由 substitutes/complements 消耗 | 不直接加预算；必须先验证 ASIN 型流量是否 ACOS 健康且有毛利 |
| 预算花完但 ACOS 高或搜索词质量差 | 禁止加预算；先治理搜索词和目标 Bid |
| 只有一类 AutoTarget 表现好 | 不直接增加整体预算；先评估其他目标是否会抢占新增预算 |
| 数据无法拆分 | 预算动作仅依据 Campaign 整体，必须标明目标级不确定性 |

所有降预算动作 `MANUAL_REVIEW`；增预算沿用现有 Campaign 预算准入和组合预算回算。

## 8. AutoTarget Bid 规则

```text
先看该目标数据是否可用
→ 再看 Campaign 是否预算受限
→ 再看目标 ACOS/订单/搜索词或商品质量
→ 最后决定保持、提 Bid 或人工降 Bid
```

| 场景 | Bid 动作 |
| --- | --- |
| ACOS 健康、有订单、预算未耗尽但曝光不足 | 可小幅提 Bid |
| ACOS 健康且流量已经充足 | 保持 Bid |
| ACOS 高但由少数无效 Search Term/ASIN 导致 | 先否定具体流量，不先降整个 AutoTarget |
| ACOS 高且目标内多数流量持续低效 | 样本充分后人工降 Bid |
| 无花费 | 检查 Bid 是否过低；预算不增加 |
| 数据缺失或样本不足 | 不调整 Bid |

所有降低 AutoTarget Bid 的动作最低 `MANUAL_REVIEW`。

## 9. 搜索词迁移精准

### 9.1 准入条件

Search Term 同时满足以下条件时，才可建议 `promote_search_term_to_keyword`：

1. 与目标子 ASIN 为 R1 高度相关；
2. 无颜色、款式、功能、人群或场景冲突；
3. 有订单和可验证转化；
4. ACOS 不高于当前阶段目标ACOS倍数阈值；
5. 不存在同词同 match_type 的有效精准活动；
6. 库存、评分和退货允许新增承接；
7. 输出 Search Term 来源、窗口、花费、点击、订单、ACOS 和 CVR。

正式阈值：近 14 天订单不少于 2，或满足现有“历史有效词”定义；统一进入 `MANUAL_REVIEW`。

### 9.2 迁移后的自动广告处理

- 提词后默认保留自动广告的发现功能。
- 不允许“提词即自动否定”。
- 只有精准活动稳定获得曝光/订单，且自动流量造成明显重复竞争时，才评估添加否定精准。
- 若精准活动尚未跑出数据，禁止在自动活动中先否定该词。
- 迁移、创建和否定是三个独立动作，必须分别输出状态和审核结果。

## 10. 否词与否定商品规则

### 10.1 否定类型

| 类型 | 适用场景 |
| --- | --- |
| 否定精准 | 单个明确无效或迁移后需要隔离的 Search Term |
| 否定词组 | 同一不相关词根持续产生多个无效 Search Term |
| 否定商品 | substitutes/complements 中明确无效或不相关的 ASIN |

### 10.2 准入

以下任一方向可进入否定评估：

- 语义明确不相关，有足够点击/花费证据；
- 点击达到现有门槛且 0 订单，并确认不是样本、Listing、价格或季节问题；
- ACOS 高于目标ACOS倍数阈值，且无核心、季节或历史价值；
- 商品 ASIN 品类/价格/款式明确不匹配，并持续消耗。

### 10.3 禁止否定

- 数据缺失或延迟；
- 样本不足；
- 核心词；
- 季节保护词；
- 高度相关但短期 ACOS 偏高；
- 刚迁移到 EXACT、精准活动尚未获得有效数据；
- 仅因搜索量大或 CPC 高；
- 商品投放对象无法识别。

所有否词和否定商品动作统一 `MANUAL_REVIEW`；否定词组因影响范围更大，建议 `HIGH_RISK_REVIEW`。

## 11. 数据不足处理

数据不足时只允许：

- 保持 Campaign Budget；
- 保持 AutoTarget Bid；
- 检查 Bid 是否缺失或异常；
- 检查目标是否开启；
- 检查 Search Term/Targeting 报告链路；
- 设置下一复评日期。

禁止：降 Bid、降预算、否词、否定商品、转低价捡漏、关闭目标，以及把缺失 Bid 显示成 0。

## 12. 审核等级

| 动作 | 最低审核 |
| --- | --- |
| 保持 | `AUTO_APPROVED` |
| 数据充分、无风险的小幅提 AutoTarget Bid（单次不超过 5%） | `MANUAL_REVIEW` |
| 提 Campaign 预算 | `MANUAL_REVIEW` |
| 降 AutoTarget Bid | `MANUAL_REVIEW` |
| 降 Campaign 预算 | `MANUAL_REVIEW` |
| 搜索词迁移 EXACT | `MANUAL_REVIEW` |
| 否定精准/否定商品 | `MANUAL_REVIEW` |
| 否定词组、拆分自动 Campaign | `HIGH_RISK_REVIEW` |
| 数据缺失下的危险动作 | `BLOCKED` |

## 15. 业务案例

| 案例 | 场景 | 正确结论 |
| --- | --- | --- |
| 1 | close_match 有订单、ACOS 健康 | 保持，检查可迁移搜索词 |
| 2 | close_match 高 ACOS，由单个不相关词造成 | 否定该词建议，不先降整个目标 |
| 3 | loose_match 无花费、预算花不完 | 检查并小幅提 Bid，预算不增加 |
| 4 | loose_match 花完预算且 ACOS 高 | 不加预算，先治理搜索词 |
| 5 | substitutes 某 ASIN 高花费 0 单 | 否定具体商品建议，不压整个目标 |
| 6 | complements 点击少无单 | 样本不足，继续观察 |
| 7 | 四类目标无法拆分 | 只做 Campaign 诊断，目标 Bid 动作 BLOCKED |
| 8 | Bid 字段未获取到 | 显示缺失，禁止用 0 和生成 Bid 动作 |
| 9 | 自动搜索词稳定出单且无精准活动 | 建议迁移 EXACT，人工审核 |
| 10 | 刚迁移 EXACT 尚无数据 | 自动广告中暂不否定该词 |
| 11 | 同一不相关词根产生多个高耗搜索词 | 否定词组建议，高级审核 |
| 12 | Campaign 预算利用率高且整体健康 | 可提预算，但需组合预算回算和人工审核 |
| 13 | 父 ASIN 目标是推自然位，自动广告占比已高 | 不加自动广告预算，优先把有效搜索词迁移精准 |
| 14 | close/loose 搜索词质量差，Listing 关键词基础缺失 | 先建议修正 Listing/关键词词库，不直接扩大自动广告 |
