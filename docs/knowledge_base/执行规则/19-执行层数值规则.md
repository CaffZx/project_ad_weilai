# 执行层数值规则（execution_numeric_rules.yaml）

定义 Agent 在执行调整时使用的具体数值：Bid 变化幅度、预算变化金额、表现判断阈值、花费级别定义、按位置的 Bid 决策矩阵、自动广泛组规则、否词触发阈值。

---

## 1. 表现定义（ACOS 分级）

| 表现等级 | 条件 | Agent 动作方向 |
|---------|------|--------------|
| 表现好 | ACOS ≤ 目标 ACOS | 可放量、提价、加广告位 |
| 表现一般 | 目标 ACOS < ACOS ≤ 目标 ACOS + 10% | 维持或小幅优化 |
| 表现差 | ACOS > 目标 ACOS + 10% | 降价、降预算、进入淘汰判断 |
| 无转化 | ACOS 为 MAX（有花费无订单） | 降价或淘汰 |

> **ACOS 取值窗口**：Bid 调整看 3 天；预算调整看近1天和近3天趋势组合。
> **进入 HIGH_ACOS 或淘汰路径前，必须先按 `15-策略约束值规则.md §4` 与 `17-问题诊断与动作优先级.md §2` 计算有效容忍上限，不能直接用“目标ACOS+10%”代替上位判断。**

---

## 2. 花费级别定义

| 花费级别 | 条件 |
|---------|------|
| 高花费 | 预算使用率 ≥ 50% |
| 低花费 | 预算使用率 < 50% |
| 无花费 | 当前活动无任何消耗 |

---

## 3. Bid 变化幅度定义

| 操作名称 | 变化比例 | 变化绝对值 | 适用场景 |
|---------|---------|---------|---------|
| 大涨 | +10% | +$0.05 | 无花费时三个位置全部大涨；冲排名机会且信号强 |
| 小涨 | +5% | +$0.02 | 有好位置时保持；曝光不足小幅刺激 |
| 大降 | -10% | -$0.05 | 差的位置大降；ACOS持续超标 |
| 小降 | -5% | -$0.02 | 一般位置小降；ACOS轻微超标 |
| 维持 | 0% | $0 | 好的位置维持；样本不足 |

> **注意**：变化方式取比例与绝对值中**较大者**执行，以确保低价词也有实际调整效果。
>
> **亚马逊加价比例上限为 900%**，若变更 Bid 后广告位加价比例超过此值，需自动截断。
>
> 若变更 Bid，应同步计算并展示广告位加价后的 CPC 预估值。

---

## 4. 预算变化金额定义

| 操作名称 | 变化金额 | 说明 |
|---------|---------|------|
| 大涨 | +20%（min $2） | 活动预算不能花完且近1天表现好 |
| 小涨 | +10%（min $1） | 活动预算能花完且近1天表现好 |
| 降（统一） | MAX($1, 当前预算 × 10%) | 取两者中较大值，确保低预算活动有实际降幅 |
| 维持 | $0 | 活动无花费；或其他情形不满足调整条件 |

> **翻倍规则**：如果活动近期花费>50时×1.5
）。

## 5. 按广告位的 Bid 调整决策矩阵（精准广告）

### 高花费（预算使用率 ≥ 50%）

#### 预算能花完

| 位置情况 | 调整策略 | 约束 |
|---------|---------|------|
| 多个好的位置 | 最好的位置不变；其他好的位置小降；不好的位置大降 | 位置如果2天内调整过，则不调整 |
| 有1个好的位置 | 好的不变；一般的小降；差的大降 | 位置如果2天内调整过，则不调整 |
| 没有好的位置 | 一般的小降；差的大降；如果没有有效花费则小涨 | — |

#### 预算不能花完

| 位置情况 | 调整策略 |
|---------|---------|
| 有好的位置 | 好的位置小涨；一般的位置维持；差的位置小降 |
| 没好的位置 | 一般的位置维持；差的位置大降；如果没有有效花费则小涨 |

### 低花费（预算使用率 < 50%）

#### 不能花完（不包含所有位置都无有效花费）

| 位置情况 | 调整策略 |
|---------|---------|
| 有好的位置 | 好的位置小涨；一般的位置维持；差的位置大降 |
| 没有好的位置 | 一般的维持；差的大降；如果没有有效花费则小涨 |

#### 无花费（所有位置均无消耗）

- 三个位置都**大涨**
- 如果是**头部（TOS）或其他（RoS）**，需先对比三个位置的初始加价比例（头部 vs 其他 vs 商品，取最大值），以该最大值为基准初始化比例后再执行上涨
- 如果是**商品（PP）**，则正常执行大涨，无需初始化对比

> **位置好坏判断**：参照本文 §1 表现定义，结合该位置的 3天 ACOS 判断。

## 6. 预算调整决策矩阵

### 活动预算能花完

| 近期表现 | 调整策略 |
|---------|---------|
| 近1天表现好（ACOS ≤ 目标） | 预算小涨（+$1，花费>$20则+$2） |
| 近1天表现差 且 近3天表现差 | 预算大降（MAX($1, 当前×10%)） |
| 其他 | 维持 |

### 活动预算不能花完

| 近期表现 | 调整策略 |
|---------|---------|
| 近1天表现好（ACOS ≤ 目标） | 预算大涨（+$2，花费>$20则+$4） |
| 近1天表现差 且 近3天表现差 | 预算小降（MAX($1, 当前×10%)） |
| 其他 | 维持 |

### 活动无花费

- 维持预算不变，优先检查 Bid 是否过低

## 7. 自动广泛组调整规则

适用于 AUTO / BROAD / PHRASE 类型活动的统一快速调整逻辑。

| 3天表现 | Bid 操作 | 预算操作 |
|---------|---------|---------|
| 3天表现好（ACOS ≤ 目标） | 不变 | 小涨（+$1） |
| 3天表现一般 且 3天实际花费高 | 下降（小降） | 不变 |
| 3天表现一般 且 3天实际花费低 | 不变 | 小降 |
| 3天表现差（ACOS > 目标+10%） | 下降（大降） | 大降 |
| 无花费 | 上涨（大涨） | 不变 |

> 表现判断以3天 ACOS 为准，参照本文 §1 表现定义。

## 8. 否词触发规则

### 触发阈值

对应广告活动内的搜索词，**7天内点击超过10次**，开始进入否词判断。

### 否词条件（满足任一）

| 条件 | 说明 |
|------|------|
| 无转化 | 超过10次点击，0订单 |
| ACOS 表现为差 | ACOS > 目标 ACOS + 10% |

### 否词执行规则

| 广告类型 | 否词方式 | 优先级 |
|---------|---------|--------|
| 广泛/词组/自动广告 | 必须执行，作为常规优化动作 | 每轮调整必须读取搜索词报告 |
| 精准广告 | 谨慎使用，仅在搜索词明显不相关时 | 相关但无转化时先降 Bid 观察，不急于否词 |

> 否词默认使用精确否定（Exact Negative）。含品牌词或竞品词时升级至 MANUAL_REVIEW。

---

## 9. 广告位调整位置好坏判断标准

| 位置评级 | 判断条件 |
|---------|---------|
| 好的位置 | 该广告位 3天 ACOS ≤ 目标 ACOS，且有订单 |
| 一般的位置 | 该广告位 3天 ACOS 在 目标 ACOS 到 目标ACOS+10% 之间 |
| 差的位置 | 该广告位 3天 ACOS > 目标 ACOS + 10%，或有花费无订单 |
| 无有效花费 | 该广告位花费 = $0 或点击 = 0 |
