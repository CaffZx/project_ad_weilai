# 执行层数值规则（execution_numeric_rules.yaml）

定义 Agent 在执行调整时使用的具体数值：Bid 变化幅度、预算变化金额、表现判断阈值、花费级别定义、按位置的 Bid 决策矩阵、广泛自动组规则、否词触发阈值。

---

## 1. 表现定义（ACOS 分级）

| 表现等级 | 条件 | Agent 动作方向 |
|---------|------|--------------|
| 表现好 | ACOS ≤ 目标 ACOS | 可放量、提价、加广告位 |
| 表现一般 | 目标 ACOS < ACOS ≤ **有效容忍上限**（`15号§4`） | 维持或小幅优化。**不触发降 Bid、不触发降预算** |
| 表现差 | ACOS > **有效容忍上限**（`15号§4`） | 降价、降预算、进入淘汰判断 |
| 无转化 | 有花费无订单，且花费已达 `03号§7` 的无单花费门槛 | 先判相关性（`31号§4`），再决定否词或降价 |

> **ACOS 取值窗口**：Bid 调整看 3 天；预算调整看近 1 天和近 3 天趋势组合。

---

## 2. 花费级别定义

| 花费级别 | 条件 |
|---------|------|
| 高花费 | 预算使用率 ≥ 50% |
| 低花费 | 预算使用率 < 50% |
| 无花费 | 当前活动无任何消耗 |

---

## 3. Bid 变化幅度定义

| 操作名称 | 变化比例 | 变化绝对值 | 适用场景 |
|---------|---------|---------|---------|
| 大涨 | +10% | +$0.05 | 无花费时三个位置全部大涨；冲排名机会且信号强 |
| 小涨 | +5% | +$0.02 | 有好位置时保持；曝光不足小幅刺激 |
| 大降 | -10% | -$0.05 | 差的位置大降；ACOS持续超标 |
| 小降 | -5% | -$0.02 | 一般位置小降；ACOS轻微超标 |
| 维持 | 0% | $0 | 好的位置维持；样本不足 |

> **注意**：变化方式取比例与绝对值中**较大者**执行，以确保低价词也有实际调整效果。
>
> **亚马逊加价比例上限为 900%**，若变更 Bid 后广告位加价比例超过此值，需自动截断。
>
> 若变更 Bid，应同步计算并展示广告位加价后的 CPC 预估值。

---

## 4. 预算变化金额定义

| 操作名称 | 变化金额 | 触发条件 |
|---------|---------|------|
| 大涨 | +20%（min $2） | 预算花费率 > 90% + 近1天表现好（ACOS ≤ 目标） |
| 小涨 | +10%（min $1） | 预算花费率 70%–90% + 近1天表现好（ACOS ≤ 目标） |
| 维持 | $0 | 预算花费率 50%–70%；或活动无花费 |
| 降（统一） | MAX($1, 当前预算 × 10%) | **仅在**表现差（ACOS > 有效容忍上限）触发；或走完 §4.1 三步后仍无法消化预算 |

> **翻倍规则**：活动近期花费 > $50 时，涨幅 × 1.5。

### 4.1 预算利用率 < 50% 的唯一处置路径

**「预算花不完」不是降预算的理由。** 必须按以下三步，顺序不可跳：

```text
Step 1 — 瓶颈判断（必执行，23号§4.3 / GROUP-BUDGET-007）
   组合利用率 = 100% 且 活动平均利用率 < 80%  → 瓶颈在【组合层】
        → 建议提升组合预算，本轮不调单个活动的预算或 Bid，结束
   活动利用率 = 100% 且 组合利用率 < 80%      → 瓶颈在【活动层】→ 进入 Step 2
   组合利用率 = 100% 且 活动平均利用率 ≈ 100% → 瓶颈在【父ASIN层】
        → 建议提升父 ASIN 总预算，结束

Step 2 — 四档填补（28号§5，逐档判断，消化不完才进下一档）
   第1档：回流被压制的有效词（恢复此前被降的 bid/预算）
   第2档：提现有有效词的 bid/预算（幅度受 25号§2 封顶）
   第3档：从精准测试组提词升组（达 23号§3.5 标准的词）
   第4档：扩全新词（28号§1–§4 选词；受 03号§7 每日新词上限封顶）

Step 3 — 仍无法消化 → 才降预算
   四档全部走完仍有剩余缺口，且非组合层/父ASIN层瓶颈，方可降预算
```

## 5. 按广告位的 Bid 调整决策矩阵（精准广告）

### 高花费（预算使用率 ≥ 50%）

#### 预算能花完

| 位置情况 | 调整策略 | 约束 |
|---------|---------|------|
| 多个好的位置 | 最好的位置不变；其他好的位置小降；不好的位置大降 | 位置如果2天内调整过，则不调整 |
| 有1个好的位置 | 好的不变；一般的小降；差的大降 | 位置如果2天内调整过，则不调整 |
| 没有好的位置 | 一般的小降；差的大降；如果没有有效花费则小涨 | — |

#### 预算不能花完

| 位置情况 | 调整策略 |
|---------|---------|
| 有好的位置 | 好的位置小涨；一般的位置维持；差的位置小降 |
| 没好的位置 | 一般的位置维持；差的位置大降；如果没有有效花费则小涨 |

### 低花费（预算使用率 < 50%）

#### 不能花完（不包含所有位置都无有效花费）

| 位置情况 | 调整策略 |
|---------|---------|
| 有好的位置 | 好的位置小涨；一般的位置维持；差的位置大降 |
| 没有好的位置 | 一般的维持；差的大降；如果没有有效花费则小涨 |

#### 无花费（所有位置均无消耗）

- 三个位置都**大涨**
- 如果是**头部（TOS）或其他（RoS）**，需先对比三个位置的初始加价比例（头部 vs 其他 vs 商品，取最大值），以该最大值为基准初始化比例后再执行上涨
- 如果是**商品（PP）**，则正常执行大涨，无需初始化对比

> **位置好坏判断**：参照本文 §1 表现定义，结合该位置的 3天 ACOS 判断。

## 6. 预算调整决策矩阵

### 活动预算能花完

| 近期表现 | 调整策略 |
|---------|---------|
| 近1天表现好（ACOS ≤ 目标） | 预算大涨（+$2，花费>$20则+$4） |
| 近1天表现差 且 近3天表现差 | 预算大降（MAX($1, 当前×10%)） |
| 其他 | 维持 |

### 活动预算不能花完

**先执行 §4.1 Step 1 瓶颈判断。** 确认瓶颈在活动层后，再按下表：

| 近期表现 | 调整策略 |
|---------|---------|
| 近1天表现好（ACOS ≤ 目标） | 预算维持；走 §4.1 Step 2 四档填补以消化预算 |
| 近1天表现差 且 近3天表现差（均 > 有效容忍上限） | 预算小降（MAX($1, 当前×10%)） |
| 其他 | 维持 |

### 活动无花费

- 维持预算不变，优先检查 Bid 是否过低

## 7. 广泛自动组调整规则

适用于 AUTO / BROAD / PHRASE 类型活动的统一快速调整逻辑。

| 3天表现 | Bid 操作 | 预算操作 |
|---------|---------|---------|
| 3天表现好（ACOS ≤ 目标）且 预算利用率 ≥ 70% | 不变 | 小涨（+$1） |
| 3天表现好（ACOS ≤ 目标）但 预算利用率 < 70% | 不变 | 维持（花不完不构成加预算条件）；走 §4.1 三步 |
| 3天表现一般（目标 < ACOS ≤ 有效容忍上限）且 3天实际花费高 | 下降（小降） | 不变 |
| 3天表现一般 且 3天实际花费低 | 不变 | 维持（**不降**）；走 §4.1 三步 |
| 3天表现差（ACOS > **有效容忍上限**） | 下降（大降） | 大降 |
| 无花费 | 上涨（大涨） | 不变 |

> 表现判断以 3 天 ACOS 为准，参照本文 §1 表现定义（有效容忍上限口径）。
> **广泛类的完整调整规则见 `31号`**：本表是快速通道，`31号§4` 的相关性四档分支优先于本表 ——
> 相关但无转化的词走 `31号§4` 档 2/3，不按本表直接大降。

## 8. 否词触发规则

### 触发阈值（两档制）

| 档 | 阈值 | 含义 |
|---|------|------|
| 预警档 | 7天内点击 **≥ 10** 次，或 7天花费 ≥ `03号§7` 无单花费门槛 | 进入判断，不等于否词 |
| 强优化档 | 7天内点击 **≥ 20** 次，或 7天花费 ≥ `03号§7` 强优化花费门槛 | 进入强优化与人工复评 |

### 否词条件（相关性优先）

**必须先判相关性，再判数据。顺序不可颠倒。** 完整四档分支见 `31号§4`。

| 相关性 | 数据条件 | 动作 | 是否否词 |
|------|------|------|:-:|
| R3 / R4 或语义冲突（`24号§2.2`） | 无数据门槛 —— 相关性判定即可触发 | 添加精确否定词 | **是** |
| R1 / R2 | 达预警档，无订单 | 降 Bid 一档，观察 7 天 | **否** |
| R1 / R2 | 达强优化档，仍无订单 | 降 Bid 两档 + 降预算，人工复评 | 通常不否 R1 |
| R1 且属 `29号` 核心词 或 `ONT-RUNTIME-004` 四类保护词 | 任意 | 仅降 Bid / 降预算 / Listing 诊断 | **禁止否词** |

### 否词执行规则

| 广告类型 | 否词方式 | 优先级 |
|---------|---------|--------|
| 广泛/词组/自动广告 | 读取搜索词报告后判断；标题词、后台ST词、历史转化词和高度相关词禁止否定 | 普通低风险动作，灰区人工确认 |
| 精准广告 | 不生成否词动作，只允许调整或关闭现有Target | 关闭规则引用精准活动退出模块 |

> 否词默认使用精确否定（Exact Negative）。相关性证据不足时不得把“无订单”直接等同于“不相关”。

## 9. 广告位调整位置好坏判断标准

| 位置评级 | 判断条件 |
|---------|---------|
| 好的位置 | 该广告位 3天 ACOS ≤ 目标 ACOS，且有订单 |
| 一般的位置 | 该广告位 3天 ACOS 在 目标 ACOS 到 目标ACOS+10% 之间 |
| 差的位置 | 该广告位 3天 ACOS > 目标 ACOS + 10%，或有花费无订单 |
| 无有效花费 | 该广告位花费 = $0 或点击 = 0 |
