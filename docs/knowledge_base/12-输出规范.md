# 输出规范（output_schema.yaml）

定义 Agent 输出给 ERP 的数据格式。

## 一、批处理结构

Agent 每次输出一个批处理提案，包含以下字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| batch_id | 字符串 | 批次ID |
| generated_at | 日期时间 | 生成时间 |
| kb_version | 字符串 | 知识库版本 |
| marketplace | 字符串 | 站点 |
| category | 字符串 | 品类 |
| total_asins | 整数 | ASIN总数 |
| review_level_counts | 对象 | 各审核等级的提<br>案数量统计 |
| estimated_budget_impact | 对象 | 预算影响预估（当前总预算/提议总预算/变化金额/变化比例） |
| proposals | 数组 | 每个ASIN的提案详情 |

## 二、ASIN提案结构

每个 ASIN 的提案包含：

| 字段 | 说明 |
| --- | --- |
| parent_asin | 父ASIN编码 |
| tag_snapshot | 当前标签快照 |
| strategy_summary | 策略摘要 |
| data_quality | 数据质量说明 |
| proposed_actions | 提议的动作列表 |
| blocked_actions | 被阻断的动作列表 |
| memory_update_proposal | 记忆更新建议 |

### 标签快照

包含：产品定位、产品阶段、淡旺季、广告目的、广告方向、关键词类型、特殊场景

### 策略摘要

包含：运营状态、库存态势、核心SKU态势、退货评价态势、市场竞争态势、推荐姿态、主要原因

### 数据质量

包含：完整度评分、缺失必需数据列表、陈旧数据源、降级数据源

## 三、单条动作结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| action_id | 字符串 | 动作ID |
| idempotency_key | 字符串 | 幂等键 |
| parent_asin | 字符串 | 父ASIN |
| object_level | 字符串 | 对象层级（asin/campaign/ad_group/keyword/target/search_term/placement） |
| object_id | 字符串 | 对象ID |
| action_type | 字符串 | 动作类型（no_action/bid_up/bid_down/budget_change/pause/add_negative/add_keyword/placement_adjustment） |
| status | 字符串 | 状态（仅允许PROPOSED或BLOCKED） |
| current_value | 数字或字符串 | 当前值 |
| proposed_value | 数字或字符串 | 建议值 |
| change_pct | 数字 | 变化百分比 |
| kb_params_used | 对象 | 使用的知识库参数 |
| evidence | 数组 | 证据链（指标/记忆引用/竞品引用） |
| expected_impact | 对象 | 预期影响（订单/ACOS/自然排名/预算） |
| risk_reasons | 数组 | 风险原因 |
| confidence | 数字 | 置信度（0-1） |
| risk_score | 数字 | 风险评分（0-1） |
| review_level | 字符串 | 审核等级（AUTO_BATCHABLE/MANUAL_REVIEW/SENIOR_APPROVAL/BLOCKED） |

### 使用的知识库参数

| 子字段 | 说明 |
| --- | --- |
| kb_version | 知识库版本号 |
| param_paths | 使用的参数路径 |
| threshold_statuses_used | 使用的阈值状态列表 |

### 预期影响

| 子字段 | 说明 |
| --- | --- |
| orders | 预期订单变化描述 |
| acos | 预期ACOS变化描述 |
| organic_rank | 预期自然排名变化描述 |
| budget | 预期预算变化描述 |

## 四、阻断动作结构

| 字段 | 说明 |
| --- | --- |
| parent_asin | 父ASIN |
| blocked_action_type | 被阻断的动作类型 |
| reason_code | 原因码 |
| evidence | 证据 |
| recommended_next_step | 建议下一步操作 |

## 五、记忆更新建议结构

| 字段 | 说明 |
| --- | --- |
| proposed_adjustment_history | 建议的调整记录 |
| competitor_memory_update | 竞品记忆更新 |
| segment_memory_update | 细分市场记忆更新 |
| pending_effectiveness_feedback | 待处理的有效性反馈 |
