# 冲突裁决规则（conflict_rules.yaml）

当多个规则或场景产生冲突时，按优先级裁决。

## 裁决优先级顺序（高→低）

1. 特殊场景
2. 硬安全护栏
3. 库存与核心SKU
4. 退货与评价风险
5. 产品阶段
6. 淡旺季
7. 广告目的
8. 市场竞争态势
9. 广告方向
10. 产品定位

> **P0定位临时优先级提升**：当产品定位=P0 且场景为淡季/旺季末期/核心词维护时，产品定位优先级临时上调至第4.5级（产品阶段之前、退货与评价风险之后），详见规则 8「P0定位优先例外」。此时 P0 核心维护策略不得被普通风控规则删除，仅硬阻断场景例外。

## 三种冲突处理类型

| 类型 | 含义 |
| --- | --- |
| hard_block（硬阻断） | 直接阻断动作，输出BLOCKED或移出可执行提案 |
| modifier（修正） | 允许动作但修正幅度、系数或审核等级 |
| review_escalation（审核升级） | 允许提案但提高审核等级 |

## 具体冲突规则

### 1. 库存不足 vs 增长动作（硬阻断）

| 项目 | 内容 |
| --- | --- |
| 触发 | 父ASIN库存天数<7天 且 非紧急清仓 |
| 阻断动作 | 提价、加预算、广告位加价、扩词 |
| 结果状态 | BLOCKED |

### 2. 核心SKU短缺 vs TOS加价（硬阻断）

| 项目 | 内容 |
| --- | --- |
| 触发 | 核心子SKU库存比例<70% |
| 阻断动作 | TOS加价、激进提价 |
| 回退动作 | 平衡维持、PP加价（如果适合） |

### 3. 紧急清仓 vs 库存不足（修正）

| 项目 | 内容 |
| --- | --- |
| 触发 | 同时存在 inventory_low 和 urgent_liquidation 标签 |
| 胜出方 | urgent_liquidation（紧急清仓覆盖库存不足） |
| 效果 | 暂停ACOS逻辑、需HIGH_RISK_REVIEW、禁止无限预算、Agent最大预算增幅30% |

### 4. 促销 vs 库存不足（硬阻断）

| 项目 | 内容 |
| --- | --- |
| 触发 | 同时存在 promotion 和 inventory_low |
| 胜出方 | inventory_low（库存不足覆盖促销） |
| 阻断动作 | 促销出价加成、促销预算增加 |

### 5. 冲排名 vs ACOS超标 + 排名上升（修正）

| 项目 | 内容 |
| --- | --- |
| 触发 | 广告目的=ranking + ACOS超标 + 7天排名上升≥2位 + 退货率≤20% |
| 效果 | 允许继续冲排名，但提价上限15%，审核等级=MANUAL_REVIEW，7天后跟进 |

### 6. 冲排名 vs ACOS超标 + 排名不动（修正）

| 项目 | 内容 |
| --- | --- |
| 触发 | 广告目的=ranking + ACOS超标 + 排名无变化或下降 |
| 效果 | 允许继续冲排名，建议优化ACOS，审核等级=MANUAL_REVIEW |

### 7. 页面优化中（修正）

| 项目 | 内容 |
| --- | --- |
| 触发 | listing_optimization 标签激活 |
| 效果 | 广告目的不新增“维持”枚举；强制执行方向=balance_maintain，最大出价调整5%，阻止新增否定词，观察期7天 |

### 8. P0定位优先例外（优先级例外）

| 项目 | 内容 |
| --- | --- |
| 触发 | 产品定位=P0 + 场景=淡季/旺季末期/核心词维护 |
| 效果 | 产品定位优先级临时上调至产品阶段之前（原第10级→第5级前）；风控规则可限制预算、出价、扩词比例，但不得删除P0核心维护策略 |
| 硬阻断例外 | 不可投放、库存断货、严重差评、广告资格异常场景下，按硬阻断规则裁决，不适用本例外 |

### 9. SOP核心策略保留规则（策略级裁决）

| 项目 | 内容 |
| --- | --- |
| 触发 | SOP标准答案或上游规则已命中 core_strategy_tags |
| 裁决原则 | 普通风险规则仅可限制动作强度，不得删除SOP核心策略标签 |
| 必须保留字段 | original_core_strategy_tags / final_core_strategy_tags / downgraded_actions / blocked_actions |
| 允许替换条件 | 仅 hard_block 可替换或删除核心策略，包括不可投放、库存断货、广告资格异常、严重差评 |
| 禁止行为 | 因ACOS偏高、亏损、滞销库存、退货率偏高而直接将Traffic改写为Profit，或将推进期Conversion/Ranking改写为Traffic/Profit；保守执行应用balance_maintain方向表达 |

### 10. 推进期旺季前期策略保留规则

| 项目 | 内容 |
| --- | --- |
| 触发 | 产品阶段=pushing + 淡旺季=旺季前期/旺季 + SOP命中Conversion或Ranking |
| 必须保留的核心策略 | Conversion / Ranking；若利润风险存在，同时附加Profit；若需要保守执行，附加执行方向balance_maintain |
| 风险修正方式 | Ranking可降级为"少数强词保守推进"或"核心自然位保护词"；Conversion必须保留 |
| 禁止行为 | Traffic不得成为唯一或主要策略；Profit不得覆盖Conversion/Ranking |
| 输出要求 | final_core_strategy_tags 必须包含 SOP 核心标签；若Ranking降级，须在 downgraded_actions 中说明 |

### 11. 退货风险不覆盖推进期核心策略

| 项目 | 内容 |
| --- | --- |
| 触发 | 退货率≥30% 或 评分<3.8，同时产品阶段=pushing |
| 裁决原则 | 退货风险仅阻断激进动作，不替换推进期主策略 |
| 阻断动作 | 增长型Traffic、TOS加价、激进提价、激进Ranking |
| 必须保留动作 | 高转化Long-tail、精准词承接、核心自然位保护词、Conversion、balance_maintain方向 |
| 输出要求 | 须写明"退货风险触发：增长型动作被阻断，推进期核心策略保留并降级执行" |

## 广告目的切换冷却

| 规则 | 值 |
| --- | --- |
| 最小切换间隔 | 7天 |
| 30天最大切换次数 | 2次 |
| 反向切换预警 | 14天内切回之前的目的触发预警 |
| 状态 | 已确认 |
