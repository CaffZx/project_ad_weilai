# 动作规则（action_rules.yaml）

定义 Agent 可执行的 8 种广告操作，每种都规定了触发条件、阻断条件、审核等级。

## 1. 提价冲排名（bid_up_for_ranking）

| 项目 | 内容 |
| --- | --- |
| 操作对象 | 关键词 |
| 动作类型 | 提价 |
| 默认幅度 | +15% |
| 最大幅度 | 参照阈值设定（默认30%） |

准入条件：触发 ranking_opportunity 事件

必需证据：自然排名、7天排名变化、3天ACOS、7天CVR、7天预算利用率、父库存天数、核心SKU库存比例

阻断条件： - 父ASIN库存严重不足 - 核心SKU短缺 - 高退货率 - 低评分 - 冲排名但缺少自然排名数据

审核等级：

| 条件 | 等级 |
| --- | --- |
| 默认 | MANUAL_REVIEW（人工审核） |
| 提价≤10% | AUTO_BATCHABLE（自动批量） |
| 提价>20% | SENIOR_APPROVAL（高级审批） |

## 2. 降价控ACOS（bid_down_for_acos）

| 项目 | 内容 |
| --- | --- |
| 操作对象 | 关键词 |
| 动作类型 | 降价 |
| 默认幅度 | -15% |
| 最大幅度 | -30% |

准入条件（同时满足）： -3天关键词ACOS > 目标ACOS × 1.2 - 7天关键词订单 < 2单

不适用场景： 该词承担冲排名任务 - 测试期样本量不足

必需证据：3天ACOS、7天订单量、自然排名值、自然订单趋势

审核等级：

| 条件 | 等级 |
| --- | --- |
| 默认 | AUTO_BATCHABLE（自动批量） |
| 如果是核心词 | MANUAL_REVIEW（人工审核） |

## 3. 加否定词（add_negative_search_term）

| 项目 | 内容 |
| --- | --- |
| 操作对象 | 搜索词 |
| 动作类型 | 加否定 |
| 默认匹配类型 | 精确否定 |

准入条件（同时满足）： - 7天搜索词ACOS > 目标ACOS × 1.5 - 7天搜索词花费 > $20- 该搜索词尚未被否定

每日上限：参照阈值（默认10个）

阻断条件： - 页面正在优化中 - 测试期样本量不足

审核等级：

| 条件 | 等级 |
| --- | --- |
| 默认 | AUTO_BATCHABLE（自动批量） |
| 含有品牌词或竞品词 | MANUAL_REVIEW（人工审核） |

## 4. 扩词（expand_keywords）

| 项目 | 内容 |
| --- | --- |
| 操作对象 | 关键词 |
| 动作类型 | 新增关键词 |
| 每日新词上限 | 参照阈值（默认15个） |
| 预算比例 | 参照阈值（默认15%） |

词来源： - 搜索词报告 - 有效词根扩展 - 竞品反查 - 历史有效词 - 节日或趋势词 - 运营自定义词池

准入条件（同时满足）：预算花不完 - 现有词效果差 - 单量想要更大

阻断条件： - 父ASIN库存严重不足 - 高退货率 - 低评分 - 紧急清仓且低库存

必需证据：来源、相关性评分、预期匹配类型、建议初始出价以及预算、理由  

审核等级：

| 条件 | 等级 |
| --- | --- |
| 默认 | MANUAL_REVIEW（人工审核） |
| 来源为历史有效词 | AUTO_BATCHABLE（自动批量） |

## 5. 增加预算（campaign_budget_increase）

| 项目 | 内容 |
| --- | --- |
| 操作对象 | 活动 |
| 动作类型 | 预算变化 |
| 默认幅度 | +10% |
| 最大幅度 | 参照阈值（默认50%） |

准入条件（同时满足）： - 预算利用率高 - ACOS可控 - 库存健康

阻断条件： - 父ASIN库存严重不足 - 核心SKU短缺 - 高退货率

后置条件（回算组合预算）:

| 后置步骤 | 说明 |
| --- | --- |
| 回算所属组合预算 | Campaign 预算变更后，必须重新汇总所属 AdBudgetGroup 的 `proposed_group_budget`，更新 `group_budget_delta` |
| 回算父 ASIN 总预算 | 组合预算变更后，必须计算 `proposed_total_group_budget` 和 `net_budget_change`，确保不超 `parent_target_daily_budget` |
| 标记 ontology 校验状态 | 输出须包含 `ontology_validation_status`，引用 `actions.yaml` post_conditions 与 `budget_groups.yaml` 回算公式 |

审核等级：

| 条件 | 等级 |
| --- | --- |
| 默认 | MANUAL_REVIEW（人工审核） |
| 增幅>30% | SENIOR_APPROVAL（高级审批） |

## 6. 降低预算（campaign_budget_decrease）

| 项目 | 内容 |
| --- | --- |
| 操作对象 | 活动 |
| 动作类型 | 预算变化 |
| 默认幅度 | -10% |
| 最大幅度 | 参照阈值（默认50%） |

准入条件（满足任一）： - 连续3天ACOS过高 - 低转化或低相关性

后置条件（回算组合预算）：

| 后置步骤 | 说明 |
| --- | --- |
| 回算所属组合预算 | Campaign 预算减少后释放的预算计入 `released_budget`，必须回算所属 AdBudgetGroup 的 `group_requested_delta` |
| 回算父 ASIN 可用预算 | 组合降低释放的预算进入 `available_reallocation_budget` 池，可供其他组合的 `positive_delta` 使用 |
| 标记释放来源 | 降预算活动若仍留在原组合内，释放金额归属`other_campaign_budget_decrease`，与转入低价捡漏的 `eliminated_campaign_release` 区分 |

审核等级：

| 条件 | 等级 |
| --- | --- |
| 默认 | AUTO_BATCHABLE（自动批量） |
| 如果是主力活动 | MANUAL_REVIEW（人工审核） |

## 7. 转低价捡漏（eliminate_to_low_bid_pool）

| 项目 | 内容 |
| --- | --- |
| 操作对象 | 广告活动 |
| 动作类型 | 转低价捡漏 |

准入条件（同时满足）： - 7天CVR = 0 - 7天花费 > $10 - 对自然排名无支持作用

每日上限：参照阈值（默认1个）

执行值说明：活动转入低价捡漏组后，默认日预算固定为 $1.00，基础 Bid 固定为 $0.20；该动作不是 `pause`，也不是关停。

后置条件（回算组合预算 + 淘汰约束）：

| 后置步骤 | 说明 |
| --- | --- |
| 目标组校验 | 必须移入 `elimination_group`，不得移入其他组合；elimination_group 预算锁死 $1 / Bid 锁死 $0.20，不接收增量分配 |
| 活动层释放预算 | 释放金额 = `current_daily_budget - $1`，归入 `eliminated_campaign_release` |
| 回算父 ASIN 可用预算 | `eliminated_campaign_release` 计入 `released_budget`，与 `other_campaign_budget_decrease` 共同抵扣本轮 `requested_increase` |
| 组合层不变 | elimination_group 的 `group_delta = 0`，不出现组合层负预算；释放预算只流向推广组/测试组/自动广泛组，不回流淘汰组 |   

审核等级：

| 条件 | 等级 |
| --- | --- |
| 默认 | SENIOR_APPROVAL（高级审批） |
| 如果是非核心词 | MANUAL_REVIEW（人工审核） |

## 8. 维持现状（balance_maintain_no_action）

| 项目 | 内容 |
| --- | --- |
| 操作对象 | ASIN |
| 动作类型 | 不操作 |
| 输出状态 | PROPOSED |

准入条件：触发 maintain_when_all_stable 事件

必需证据： - ACOS在目标范围内 - 花费节奏正常 - 订单稳定 - 库存支持当前节奏

审核等级：AUTO_BATCHABLE（自动批量）

## 9. Ontology 补充引用

> 以上 8 个动作的作用对象（object_class）、禁止对象/场景、是否增长型、必需证据来源，详见 [20-亚马逊广告ontology补充 §7 动作合法性 Ontology](20-亚马逊广告ontology补充.md#7-动作合法性-ontology)。关键约束摘要：

| action_code | 作用对象（object_class） | 禁止对象/场景 | 是否增长型 |
| --- | --- | --- | --- |
| `bid_up_for_ranking` | KeywordTarget / ProductTarget | SearchTerm、库存缺失、库存不足、高退货、低评分、缺排名数据 | 是 |
| `bid_down_for_acos` | KeywordTarget / ProductTarget / AutoTarget | SearchTerm、承担 Ranking 任务且未超容忍上限 | 否 |
| `campaign_budget_increase` | Campaign | 库存缺失、库存不足、高退货、核心 SKU 短缺 | 是 |
| `campaign_budget_decrease` | Campaign | 样本不足时大幅降预算 | 否 |
| `add_negative_search_term` | SearchTerm → NegativeTarget | Listing 优化中、测试期样本不足、品牌/竞品词未人工审核 | 否 |
| `promote_search_term_to_keyword` | SearchTerm → KeywordTarget | 库存不足、高退货、低评分、无相关性 | 是 |
| `placement_adjustment` | Placement | 广泛/词组/自动广告、缺广告位数据 | 是 |
| `eliminate_to_low_bid_pool` | Campaign | 新活动<3天、核心词排名支持、未完成淘汰前诊断；目标组必须为 `low_bid_retention_group` | 否 |
| `balance_maintain_no_action` | ASIN / Campaign | 数据缺失导致无法判断时不得伪装为健康维持 | 否 |
