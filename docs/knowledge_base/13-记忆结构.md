# 记忆结构（memory_schema.yaml）

定义 Agent 如何存储和更新 ASIN 及市场的历史信息。

## 一、ASIN短期记忆

存储路径：memory/asins/{parent_asin}.json 更新方：ERP（审核或执行后）

### 标签快照

| 字段 | 说明 |
| --- | --- |
| current_tags | 当前标签 |
| last_confirmed_date | 最后确认日期 |
| last_confirmed_by | 最后确认人 |
| confirmation_status | 确认状态 |

### 调整历史

| 字段 | 说明 |
| --- | --- |
| date | 调整日期 |
| adjustment_id | 调整ID |
| kb_version_used | 使用的KB版本 |
| actions | 执行的动作列表 |
| agent_confidence | Agent置信度 |
| agent_risk_score | Agent风险评分 |
| human_review | 人工审核结果 |
| execution | 执行结果 |

### 关键词记忆

以关键词或Target ID为键，记录：

| 字段 | 说明 |
| --- | --- |
| first_added | 首次添加日期 |
| bid_history | 出价历史 |
| performance_trend | 表现趋势 |
| last_evaluation | 最近评估 |
| organic_rank_history | 自然排名历史 |

### 竞品记忆

| 字段 | 说明 |
| --- | --- |
| competitor_asin_pool | 竞品ASIN池 |
| relative_price_position | 相对价格定位 |
| relative_review_position | 相对评价定位 |
| promo_gap | 促销差距 |
| competition_intensity | 竞争强度 |
| traffic_opportunity | 流量机会 |
| last_competition_context | 上次竞品态势 |
| last_competitor_driven_actions | 上次竞品驱动的动作 |
| post_action_effectiveness | 动作后效果 |

### 女装风险记忆

| 字段 | 说明 |
| --- | --- |
| return_rate_history | 退货率历史 |
| rating_history | 评分历史 |
| complaint_tags | 投诉标签 |
| core_child_sku_stock_history | 核心子SKU库存历史 |

### 人工覆盖日志

记录所有人工干预的操作历史。

## 二、细分市场记忆

存储路径：memory/markets/{market_segment}.json 更新方：ERP或记忆任务

| 字段 | 说明 |
| --- | --- |
| market_segment | 细分市场标识 |
| marketplace | 站点 |
| category | 品类 |
| generated_at | 生成时间 |
| common_competitor_pool | 公共竞品池 |
| competition_intensity_trend | 竞争强度趋势 |
| median_price_trend | 价格中位数趋势 |
| promo_pressure_periods | 促销压力时段 |
| seasonal_windows | 季节性窗口 |
| effective_placement_strategy | 有效的广告位策略（TOS/PP/RoS） |
| competitor_interception_targets | 竞品截流目标（有效/无效） |
| strategy_effectiveness | 策略有效性（ranking/conversion/traffic/profit） |
| parameter_recommendations | 参数建议列表 |

## 三、记忆更新策略

| 规则 | 值 |
| --- | --- |
| Agent只输出建议 | ✅ Agent仅产生提案，不直接写入记忆 |
| ERP审核后持久化 | ✅ ERP在审核后负责写入 |
| 驳回后更新 | ✅ 被驳回的动作也要记录 |
| 修改后更新 | ✅ 被修改的动作也要记录 |
| 执行后创建反馈 | ✅ 已执行的动作创建待处理有效性反馈 |

### 反馈时间窗口

| 时间 | 检查指标 |
| --- | --- |
| 第1天 | 花费、订单、ACOS |
| 第3天 | ACOS、CVR、预算利用率 |
| 第7天 | 自然排名、自然订单、有效词数 |
| 第14天 | 策略有效性、退货率、细分市场趋势 |
