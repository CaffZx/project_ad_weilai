# 风险评分（risk_scoring.yaml）

定义每条广告调整建议的风险评分算法，用于决定审核等级。

## 评分规则

- 评分范围：0.0 ~ 1.0

- 基准分：0.10

- 各维度风险分累加到基准分上

## 一、动作幅度风险

| 场景 | 加分 |
| --- | --- |
| 出价变化 > 10% | +0.05 |
| 出价变化 > 20% | +0.15 |
| 预算变化 > 20% | +0.15 |
| 预算变化 > 30% | +0.25 |
| 广告位加价 > 10% | +0.15 |
| 广告位加价 > 20% | +0.25 |
| 转低价捡漏动作 | +0.30 |

## 二、库存风险

| 场景 | 加分 |
| --- | --- |
| 父ASIN库存警戒（14-30天） | +0.15 |
| 父ASIN库存警告（7-14天） | +0.25 |
| 核心SKU部分短缺（50-70%） | +0.25 |
| 核心SKU严重短缺（<50%） | +0.40 |

## 三、女装品质风险

| 场景 | 加分 |
| --- | --- |
| 退货率警戒（＞25%） | +0.15 |
| 退货率高（25-35%） | +0.30 |
| 评分低于警戒（3.5-3.8） | +0.15 |
| 评分低于阻断（<3.5） | +0.30 |
| 近期差评激增 | +0.20 |

## 四、数据质量风险

| 场景 | 加分 |
| --- | --- |
| 数据陈旧 | +0.10 |
| 缺少竞品数据 | +0.10 |
| 缺少评价退货数据 | +0.15 |
| 缺少自然排名（非ranking动作） | +0.05 |

## 五、市场竞争风险

| 场景 | 加分 |
| --- | --- |
| 高竞争强度 | +0.10 |
| 竞品Deal压价 | +0.15 |
| 我方评价弱于竞品 | +0.15 |
| 我方价格更贵 | +0.10 |

## 六、历史风险

| 场景 | 加分 |
| --- | --- |
| 同一方向连续调整3天 | +0.15 |
| 之前同类动作失败 | +0.20 |
| 14天内人工驳回类似建议 | +0.25 |

## 置信度评分

置信度影响最终审核等级的判定：

| 维度 | 权重 |
| --- | --- |
| 数据完整度 | 40% |
| 信号一致性 | 30% |
| 历史有效性 | 20% |
| 阈值确认状态 | 10% |

使用未确认的阈值（needs_review）：置信度扣减 -0.10

## 审核等级阈值

| 等级 | 风险分上限 | 置信度下限 | 额外限制 |
| --- | --- | --- | --- |
| AUTO_APPROVED | ≤0.25 | ≥0.80 | 不允许转低价捡漏、大预算变化、大幅广告位加价 |
| MANUAL_REVIEW | ≤0.60 | ≥0.65 | - |
| HIGH_RISK_REVIEW | ≤0.85 | ≥0.50 | - |
| BLOCKED | ≥0.85 或 硬护栏触发 | - | - |

## 升级规则

以下情况直接设定最低审核等级，不受风险分影响：

| 场景 | 最低审核等级 |
| --- | --- |
| 使用了任何”需确认”的阈值 | MANUAL_REVIEW |
| TOS加价 > 20% | HIGH_RISK_REVIEW |
| 紧急清仓 | HIGH_RISK_REVIEW |
| 转低价捡漏 | HIGH_RISK_REVIEW |
| 真正停投语义 | BLOCKED + 人工评估是否停投 |
