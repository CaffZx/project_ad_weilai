# 竞品规则（competitor_rules.yaml）

## 市场竞争态势字段

| 字段 | 取值 | 数据来源 |
| --- | --- | --- |
| competition_intensity（竞争强度） | low / medium / high | ERP或MCP竞品数据 |
| price_position（价格定位） | cheaper / parity / expensive | 竞品价格 vs 我方价格 |
| review_position（评价定位） | stronger / parity / weaker | 竞品评分和评价数 |
| promo_gap（促销差距） | none / competitor_advantage / our_advantage | Coupon/Deal对比 |
| traffic_opportunity（流量机会） | none / weak / moderate / strong | 竞品可获性、广告强度、排名趋势 |
| defensive_need（防守需求） | low / medium / high | 核心词或市场份额压力 |
| recommended_posture（推荐姿态） | attack / maintain / harvest / defend / avoid / clearance | 综合衍生 |

## 竞品规则

### 规则1：竞品Deal压价 + 我方无价格优势

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 竞品促销占优势 且 我方价格持平或更贵 |
| 推荐姿态 | avoid（回避） |
| 避免动作 | 主词提价、TOS加价 |
| 优先动作 | 长尾词扩展 |
| 出价修正系数 | 0.8（打八折） |
| 审核等级 | MANUAL_REVIEW |

### 规则2：竞品弱势 + 我方库存健康

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 流量机会中/强 + 竞争强度低/中 + 父ASIN可售库存≥30天 + 核心SKU比例≥70% |
| 推荐姿态 | attack（进攻） |
| 允许动作 | 核心词提价、TOS加价、PP加价、ROS加价 |
| 出价修正系数 | 1.0（正常出价） |
| 审核等级 | MANUAL_REVIEW |

### 规则3：我方评价弱于竞品

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 评价定位弱于竞品 |
| 推荐姿态 | avoid（回避） |
| 提价上限 | 10% |
| 阻断动作 | 大幅TOS加价、激进扩词 |
| 审核等级 | MANUAL_REVIEW |

### 规则4：竞品页面截流机会

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 流量机会中/强 + 我方价格持平或更便宜 + 我方评价持平或更强 |
| 推荐姿态 | harvest（收割） |
| 优先动作 | PP加价、竞品定位 |
| 避免动作 | 主词激进提价 |
| 审核等级 | MANUAL_REVIEW |

### 规则5：竞品降价压力

| 项目 | 内容 |
| --- | --- |
| 触发条件 | 竞品7天价格中位数下降≥10% |
| 出价倍数 | 0.8 |
| 避免动作 | 激进提价 |
| 审核等级 | MANUAL_REVIEW |

## 竞品记忆更新策略

| 策略 | 值 |
| --- | --- |
| 写入短期ASIN记忆 | ✅ 是 |
| 写入细分市场记忆 | ✅ 是 |

实质性变化阈值（以下任一变化触发记忆更新）： - 价格定位变化 - 促销差距变化 - 竞争强度变化 - 流量机会变化 - 评价定位变化

无变化时行为：复用上次的竞品态势结论，降低计算优先级
