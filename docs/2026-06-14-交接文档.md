## ★ 双轨适配器（Dual-Track Adapter）— 业务背景 / 总体设计 / 阶段状态

> 本日多数前后端工作（§1 方向A、§2 决策快照富化、§3 前端左栏重构）都是这条主线的落地。单列此章作为统领。

### A. 业务背景（为什么需要）
**同一块前端 UI，要能渲染两种来源的数据**：① **实时态**（进行中分析，内存/缓存，可编辑）② **快照态**（已完成批次，读数据库，只读）。适配器负责把两种来源**归一成同一个 ViewModel + 一个 `editable/executable` 标志**，前端只认 ViewModel、不感知来源。

### B. 总体设计：关键对称性（单源 vs 双轨）
系统两大块，生命周期性质不同 → 架构不同：

| | 性质 | 正确架构 |
|---|---|---|
| **执行层 campaign（tab5）** | 分析**一完成即终结**，无再编辑需求 | **单一真相源**：analyze → **先落库** → 回读 → 渲染。无两套 mapper 漂移 |
| **前置工作流（tab1-4）** | **既是事件产物，又是下游输入配置** | **双轨适配器**：事件结束前=内存/缓存（可编辑）；结束后=落库+读库渲染（只读）。同 ViewModel + `editable` 标志 |

> 记忆：**campaign 写完即死（单源）；前置写完还要被下次读（双轨）。**

### C. 关键实体与状态机
- `run_id` 批次句柄（分析启动即生成）；`decision_id` ERP 主键（**write_full 落库才生成**）；`analysis_session`（state 库进行中标记，TTL 12h，不污染 ERP）；`is_latest`（ERP 列，每 ASIN 唯一最新）。
- **操作权与来源解耦**：`executable/editable` 控制能否操作；`mode/source` 只标来源。
- **执行权公式**：`executable = is_latest AND NOT 存在进行中 session`。
- **页面三态**：A 首访/未配置（实时·tabs 可编辑·tab5 锁）/ B 已配置无进行中（快照·tabs 只读·tab5 可执行最新批次）/ C 进行中（实时续·tabs 可编辑·tab5 锁）。

### D. 阶段状态（✅完成 / ⚠️部分 / ❌未做）

**D1. campaign 单源轨 —— ✅ 本日完成（§1 方向A收敛）**

## 五、核心关键词监控（Tab1）— 现状/断点/源头改造方案（★待实现）

### 5.1 现状与断点（已查实）
- 表数据：`tactics.py` 的 `merged_kws` = `data.keywords[:20]`（排名）+ purpose-agent（类型/建议，按 word 匹配）。
- **排名源头在 `mcp_adapter._assemble`（224-292）**：`ASINData.keywords` 来自 `ad_keyword_report`（**MCP 失效→Doris 回落，给词不给排名**）；自然排名是另一份 `rankings = normalize_keyword_rankings(keyword_competitors, keyword_child_asins)`，按词名 left-join 贴到 keyword 上（271/288）。
- **断点**：
  1. `own_keyword_flow`（实测可返该 ASIN 全部词当前自然排名，B0B7S3PWWB ~157 行）**不在任何 META 映射**（`mcp_mapping` 只在 `TOOL_ARG_BUILDERS` 有定义，从不被自动拉取）。
  2. `mcp_tool_fallback.py:15` `own_keyword_flow → META_FLOW_KEYWORD` **映射错**（应 `META_KW_COMPETITOR_RANK`）。
  3. **词集 left-join 缺陷**：自然高排名词若不在广告词表里 → 无行可贴 → 源头就不可见（"在榜强词"消失的真因）。
  4. `ad_keyword_report` Unknown tool → 词表本身 Doris 依赖。

### 5.2 已撤的补丁（方案A还原）
- 当日先做了 tactics 出口补丁（`keyword_ranks.py` 抽 `fetch_asin_keyword_ranks` + `tactics._build_merged_kws` 事后糊排名+补强词）——**这是出口止血、非数据源修复**，且 union 进 `data.keywords` 会污染全链路（recommender/规则/诊断看到幽灵词）。**已 revert**。
