## 1. 问题：两种"一个活动多个出价单位"场景

### 1.1 同词混合匹配（既有 bug）

同一活动对同一关键词打两种匹配类型，如：

```
活动A  — 关键词 "cover up"  BROAD   Bid=$0.50  keyword_id=K1
       — 关键词 "cover up"  PHRASE  Bid=$0.50  keyword_id=K2
```

当前 `ad_campaign_product_keyword_list` 返回两行 → 两个 CampaignUnit → LLM 看到两个独立条目 → 预算可能被调两次 → 落库时 `card_id = stable_id("car", decision_id, campaign_id)` 相同 → 后写覆盖前写。

### 1.2 自动广告（新增）

```
LCX-渔网-自动  — 紧密匹配  Bid=$0.20  target_id=T1
              — 宽泛匹配  Bid=$0.20  target_id=T2
              — 同类商品  Bid=$0.20  target_id=T3
              — 关联商品  Bid=$0.20  target_id=T4
```

## 3. 领域模型设计

### BidUnit

```python
class BidUnit(BaseModel):
    unit_type: str = ""           # "keyword" | "targeting"
    keyword_text: str = ""        # 手工
    keyword_id: str = ""          # 手工
    match_type: str = ""          # 手工: EXACT/BROAD/PHRASE
    target_type: str = ""         # auto: 紧密匹配/宽泛匹配/同类商品/关联商品
    target_code: str = ""         # auto: queryHighRelMatches/asinSubstituteRelated/...
    target_id: str = ""           # auto
    current_bid: float = 0.0
    # auto 定向组效果
    impressions/clicks/cost/sales/orders: int/float
    acos/ctr/cvr/cpc: float | None
```

### CampaignUnit 改造

删除 4 个平级字段（match_type/keyword_text/keyword_id/current_bid），改为只读 property，数据源统一为 `bid_units[0]`。

新增 `bid_units: list[BidUnit]`，单出价活动 1 个元素、同词混合匹配 2 个、auto 4 个。
