# AD-Agent Project Knowledge Graph

本目录是 AD-Agent 项目自身的知识图谱文档，不是广告业务知识库，也不是短期交接日志。

它的目标读者有两类：

- 人类开发者：快速恢复项目全局心智模型。
- 开发 Agent：在修改代码前定位真源文件、理解边界、识别风险点。

## 阅读路线

新接手开发者建议按这个顺序读：

1. `00-项目知识图谱总览.md`
2. `01-核心数据对象与领域模型.md`
3. `02-数据库表结构说明-ERP库与State库.md`
4. `04-广告Agent-MCP实际调用链路说明.md`
5. `07-广告策略推荐工作流引擎架构.md`
6. `08-Campaign分析引擎架构说明.md`
7. `11-前端设计说明.md`

开发 Agent 修改某个子系统前建议先读：

1. 对应专题文档的“当前代码真源”。
2. `05-网关连接池信号量与超时设置.md`。
3. `14-测试与验证地图.md`。
4. `15-项目知识图谱维护规则.md`。

## 文档目录

- `00-项目知识图谱总览.md`：项目边界、子系统地图、数据流总览。
- `01-核心数据对象与领域模型.md`：ASINData、CampaignData、四层工作流、决策快照。
- `02-数据库表结构说明-ERP库与State库.md`：两个数据库的定位、表责任和读写边界。
- `03-MCP工具原始Schema说明.md`：项目侧记录的 MCP 工具入参、返回消费点和功能说明。
- `04-广告Agent-MCP实际调用链路说明.md`：从 ASIN 数据到 Campaign 分析再到广告执行的实际工具调用链。
- `05-网关连接池信号量与超时设置.md`：MCP、LLM、Campaign、ERP、执行 MCP 的运行时限制。
- `06-缓存机制说明.md`：Redis/LRU、meta_filter、ASINData 缓存和失效策略。
- `07-广告策略推荐工作流引擎架构.md`：Campaign 前置的策略推荐工作流。
- `08-Campaign分析引擎架构说明.md`：Campaign 分析、预算重分配、新建活动、复评和护栏。
- `09-知识库切片加载说明.md`：项目如何按 preset 加载业务知识库切片。
- `10-定时分析机制说明.md`：批量定时分析脚本、状态文件、失败策略。
- `11-前端设计说明.md`：单页前端、Campaign panel、状态和 API 交互。
- `12-广告执行链路与安全开关.md`：确认、执行、Advert MCP、dry-run 和幂等边界。
- `13-Codex复核组件说明.md`：项目内 Codex 复核组件的边界、当前调用方式和演进约束。
- `14-测试与验证地图.md`：测试文件到子系统的映射。
- `15-项目知识图谱维护规则.md`：文档更新规范和审查清单。

## 维护原则

文档以当前代码为真源。若文档和代码冲突，先相信代码，再更新文档。

每篇专题文档都应保留以下信息：

- 目的
- 适用读者
- 当前代码真源
- 核心说明
- 常见误区
- 更新检查清单
