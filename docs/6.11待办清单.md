## 一、前端合并：campaign 进主看板第 5 tab

### 已定决策

| 决策 | 结论 |
|------|------|
| 双轨渲染 | **一套前端 + 后端适配层**。实时轨和快照轨返回同一 ViewModel，前端不感知来源 |
| 技术载体 | **ES module + CSS 前缀(`.camp-`) + 事件委托**。禁 iframe |
| 文件结构 | `campaign-panel/` 独立目录：`panel.js`(入口) / `render.js`(渲染) / `events.js`(事件委托) / `panel.css`(全加前缀) |
| campaign 左侧控制栏 | **全砍**。ASIN 选择和前置上下文由主看板 1-4 标签提供 |
| tab5 解锁时机 | **选定父 ASIN 即可点**（快照只读 T+1，实时可独立操作，不依赖前置 1-4 完成） |
| mode 开关 | `interactive`(操作台，渲染复选框/执行按钮) / `readonly`(快照，全隐藏操作件) |
