# v2.3 更新公告

> 发布日期: 2026-05-19

## 功能优化

1. **广告目的评分理由更详细**：点击评分卡片的理由文字后，弹窗现在展示完整的决策逻辑——包含"决策依据"（引用了哪些具体数据指标）、"建议"（做什么、为什么）、"后续关注"（需要监控什么、什么条件下重新评估），不再只是一句简短的结论。并且现在LLM推荐建议的决策依据现在会附上准确的时间窗口和口径。

2. **目标关键词和每日预算评分理由更详细**：同上。

3. **关键词监控排名说明更准确**：排名变化列改名为"距上一次爬虫排名变化"，如实反映数据来源（对比上一次爬虫抓取结果），避免此前"14天变化"名不副实的误导。

4. **趋势分析新增字段**：新增了更多趋势分析可用字段，可以按需查询。
（💡tips：点击趋势图的各颜色小圆点可以按需查看想看的指标。）

5. **趋势分析更可靠**：AI 在分析每日趋势数据时，现在会排除最新一天可能不完整的当日数据（受时区和数据抓取窗口影响），避免因不完整数据做出误判。

6. **关键词 Bid 调整建议完整展示**：Tab3 每日预算推荐中的关键词 Bid 调整下拉列表，关键词不再被截断省略，完整显示所有文字。

7. **评分理由弹窗阅读体验优化**：弹窗内段落间距更清晰，三个部分（决策依据 / 建议 / 后续关注）之间有明显的视觉分隔。
