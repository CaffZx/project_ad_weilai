# v2.6 更新公告

> 发布日期: 2026-05-29

## 功能优化

1. **新看板上线**：主推前端切换为 `ad-asisitant-agent.html`，左右分栏 + 四个标签页（广告目的与关键词、数据监控、目标 ACOS/预算、广告方向），一屏内完成配置与洞察查看。
2. **产品阶段与广告目的命名统一**：产品阶段改为「测试期 / 推进期 / 收割利润期 / 维持期 / 清货期」；广告目的改为「引流型 / 转化型 / 排名型 / 盈利型」，前后端与 AI 输出口径一致，旧配置自动兼容。
3. **数据完整性闸门**：核心数据不足时拦截 AI 生成并提示缺失项；重要维度缺失时降置信度分析；支持自动刷新重试一次。
4. **数据未抓全提醒覆盖四个 Tab**：当部分维度拉取失败、使用缓存或数仓补数时，各页统一显示黄色提示条，并说明可点击本页「刷新 / 重新推荐」重新拉取数据。
5. **P3 手动覆盖体验优化**：Tab3 可取消手动覆盖并恢复 AI 推荐；「AI 重新推荐」在存在手动值时也能正常触发。
6. **首页版本号更新为 v2.6**。

## 修复

- 修复 P3 在已手动覆盖时点击「AI 重新推荐」仍返回旧手动值的问题。
- 修复策略确认接口未校验 `accepted=false` 时前端误显示「已保存」的问题。
