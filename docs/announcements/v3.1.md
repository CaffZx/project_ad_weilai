# v3.1 更新公告

> 发布日期: 2026-06-16

本次是自 v2.6 以来的一次大版本更新：在原有「广告目的 / 数据监控 / 目标 ACOS·预算 / 广告方向」四个标签（解决"往哪个方向打"）之上，新增了**广告活动分析**这一执行层标签（解决"每个活动具体怎么动"），并补齐了决策批次、历史回看、真实执行等全链路能力。

## 功能优化

1. **新增「广告活动分析」标签页（第 5 个 Tab）—— 从"给方向"到"逐个活动给执行建议"**：前四个标签帮你定策略与方向，新的第 5 个标签直接分析该父 ASIN 下的**每一个广告活动**，逐个给出 **淘汰 / 调整出价 / 调整预算 / 调整广告位 / 保持 / 新增** 的具体建议，并附判断理由与证据数据（近 7 天花费、ACOS、CVR、预算利用率、广告位加价等）。一屏看完整个 ASIN 的广告该怎么动，支持按动作、置信度、匹配类型、组合筛选与搜索。

2. **策略总览（执行总纲）—— 先定调，再逐个动**：第 5 个标签顶部，AI 先结合知识库与当前现状，对整个 ASIN 的广告盘给出**宏观判断 + 打法方向**（以哪个广告方向为主、低效流量如何处理、核心词与排名如何保护），作为后续逐活动建议的统一基调，避免"单看一个活动合理、放到全局却打架"。

3. **AI 汇总 —— 把上百条调整按共同原因归并成运营叙事**：第 5 个标签的「汇总」子页，把几十上百条单活动建议按**共同原因分组**（如"12 个广泛词都因 ACOS 不可恢复被建议淘汰"），每组可「全选本组」一键批量勾选、点活动名跳转定位到明细；特殊/个例调整单独列出，不用再逐条翻看。

4. **决策批次制 —— 每次分析自动存成一个批次，随时回看**：右上「历史决策批次」下拉可切换查看过往每一次分析结果，最新一次标注「最新·可操作」。点「新建分析事件」进入实时分析（期间执行功能暂冻结，避免新旧批次混淆），前置策略配置好后即可在第 5 个标签运行执行层分析；不想分析时可「放弃本次分析」恢复到上一批次。

5. **历史批次一键还原当时的完整 AI 分析**：选择某个历史批次后，左侧战略层 / 策略层 / 目标 ACOS·预算 / 广告方向，以及策略层评分卡、目标 ACOS 与预算的**完整推理文字**、广告方向卡的评分与理由，都按当时落库内容**只读还原**——不再像以前那样只剩几个标签，AI 当时给的成段建议看得回。

6. **广告活动按"组合"分类 + 智能预算回算**：活动自动归入 4 个逻辑组合——**精准主力组 / 精准测试组 / 自动广泛组 / 低价捡漏组**，按"调整后预算"定位归属（如把活动降到 $5 以下会归入测试组）。顶部「组合预算汇总」展示总预算约束与各组约束；其中各组约束按照知识库回算给出（AI 不可用时自动回落固定占比兜底）。勾选活动时实时显示"执行后预计总预算"，超约束会高亮提示。

7. **AI 自动建议"该新建哪些广告活动"**：除了分析已有活动，系统会基于关键词流量与自然排名机会，建议该 ASIN **应新建哪些广告活动**（含匹配类型、初始出价、每日预算、投放子 ASIN、否词策略），以绿色「新增」卡片展示，经双轮 AI 校验取交集以降低误建。

8. **广告调整真实执行能力接入（灰度上线，默认安全空跑）**：勾选并「同意所选」标记确认后，新增「**执行已确认调整**」按钮，可把已确认的调整通过广告调整工具真正下发执行；「**调整记录**」表回看每一项的变更与结果（成功 / 失败 / 空跑分色显示）。出于安全，默认开启"空跑"模式：只构造并记录指令、**不会真实改动广告**，需由管理员显式开启后方可真实下发。

9. **自然搜索排名接入精准活动分析**：精准活动的分析现在会带上关键词的**当前自然排名**与**较上次爬取的变化（↑/↓）**，AI 据此判断是否保护在榜强词、是否对掉榜词谨慎降价或淘汰，排名相关建议更有据可依。

10. **首页版本号更新为 v3.1**。

## 修复

- 修复广告活动建议的「动作标签」与实际不符的问题：全维持的健康活动不再被误标为"调出价/调广告位"，现按"调整 / 保持"如实显示，具体改了什么以卡片内"调整前 → 调整后"为准。
- 修复出价或预算已到底（出价 ≤ $0.21 或 预算 ≤ $1）的活动应被淘汰却被 AI 漏判的情况：现由代码强制淘汰并归入低价捡漏组，执行值强制修正为 $1 / $0.20。
- 修复「组合预算汇总」顶部总约束与各组约束加总对不上的问题：顶部约束现等于各组（含低价捡漏组）之和。
- 修复出价 / 预算"调整前 → 调整后"颜色方向（涨绿降红）与展示对齐
- 修复汇总叙事过长导致的偶发截断。
- 修复广告位加价比例无法正确拉取数据并分析的问题。
- 修复广告活动调整前的预算/bid偶发拉取不正确的问题。
