# v2.5 更新公告

> 发布日期: 2026-05-28

## 功能优化

1. **AI 推荐全面遵循广告调整 SOP 知识库（v3.1.0）**：此前 AI 的决策逻辑分散在多处，偶尔出现"同一场景不同建议"的问题。现在所有 AI 推荐（广告目的、关键词类型、执行方向、目标 ACOS、预算/Bid）统一遵循一套 19 章的结构化知识库，含完整的产品阶段策略、触发条件、动作规则、冲突裁决、安全护栏等
2. **数据服务升级，加载更稳定**：广告报表数据改为通过 MCP 网关获取，单报表支持最长 20 分钟超时，大报表（如搜索词报告）不会再因为超时而缺少数据。如果 MCP 超时或返回空数据，系统自动切回数据库直连补齐缺失项，不需要手动刷新重试。黄色提示条现在能区分"确实无数据"和"获取失败"，前者不再误报为异常。
3. **广告目标推荐、每日预算推荐的理由展示更详细**：策略层（Tab2）的 AI 推荐现在包含完整的决策依据、建议动作和后续关注指标，每条依据都带时间窗口和口径（如"近 7 日 ACOS 从 5 月 21 日的 32% 逐日降至 5 月 27 日的 25%"），不再只给一句话结论。
4. **执行方向推荐更贴合阶段策略**：Tab3 的执行方向（推自然位 / 扩词 / 优化 ACOS / 平衡维持）现在会结合知识库中的产品阶段、广告目的、触发条件、冲突裁决规则综合判断，减少"评分高但不合阶段逻辑"的误推荐。
5. **首页版本号更新为 v2.5**。

## 修复

- 修复策略层 AI 推荐偶发崩溃（回传数据格式异常时页面白屏），增加兼容处理。
- 修复文案 Prompt 注入知识库后的格式异常，确保分析报告与推荐的排版不受影响。
