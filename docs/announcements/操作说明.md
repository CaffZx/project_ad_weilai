> 发布日期: 2026-07-22
> 本说明覆盖广告活动分析页（Tab 5）及前置配置流程

## 一、页面数字说明

### 1. 组合分类标签

当前 4 个组合：**精准主力组 / 精准测试组 / 自动广泛组 / 低价捡漏组**

每个组合由代码按规则自动判定（不是 AI 随意分类）：
- **精准主力组**：EXACT 匹配 + 日预算 ≥ $5
- **精准测试组**：EXACT 匹配 + 日预算 < $5
- **自动广泛组**：BROAD / PHRASE / AUTO 匹配
- **低价捡漏组**：已被 AI 判定淘汰 或 bid≤$0.10/budget≤$1 且无出单

### 2. 组合气泡里的数字

示例：

```
精准主力组
当前预算 $85.00    过去7天花费 $62.30
AI建议 $90.00
```

- `当前预算 $85.00` = Amazon 后台该 Portfolio 的**真实日预算**（通过 MCP 实时拉取）
- `过去7天花费 $62.30` = 该组合内所有活动近 7 天**实际花费**（= spend / 7 × 天数，等价日均花费×天数）
- `AI建议 $90.00` = AI 综合表现后**建议的新预算**（仅在"组合预算调整"弹窗里可修改和执行）
- 组合气泡旁还会显示 **1天 / 3天 / 7天 / 14天 / 30天** 多周期花费趋势，供运营判断

**注意**：只有运营主动点「组合预算调整 → 执行」后才会真改 Amazon，数字只展示不自动生效。

### 3. 卡片顶部的"调整前 / 调整后"

示例：

```
调整前 $117  ｜  调整后 $120
```

- `调整前` = 当前勾选中项的**原始出价/预算之和**
- `调整后` = 如果采用 AI 建议值后的**新出价/预算之和**
- 打勾/取消勾选会**即时更新**这个数字

### 4. 单个调整项卡片

```
☑ keyword: "stocking 3pcs"
   ASIN: B09SGC3YZB  |  匹配类型: 精准
   自然排名: 第3位(↑1)  核心词  触发规则: NO_CVR_HIGH_SPEND
   当前竞价 $0.50  →  建议竞价 $0.80
   当前预算 $15.00  →  建议预算 $20.00
   审核: 可直接执行
```

- **彩色标签（meta chips）**: ASIN(蓝)、匹配类型(绿)、关键词(粉)、触发规则(黄)、审核等级(橙) — 不同颜色快速区分信息
- `核心词` 标签 = 该词经过 AI 语义判定确认为核心词，受淘汰保护
- `自然排名: 第3位(↑1)` = 该词在 Amazon 自然搜索排第 3，较上周上升 1 位
- `审核: 可直接执行` = 该建议的审核等级：
  - **可直接执行** — AI 高置信，运营可直接勾选同意
  - **需人工审核** — AI 中/低置信，建议人工复查后再勾选
  - **高风险审核** — 触发重要护栏，必须人工核实
- `当前竞价/预算 → 建议竞价/预算` = 现在值 → AI 建议值，勾选后执行时生效

### 5. 卡片密度切换

明细 tab 栏右侧有 **紧凑 / 舒适 / 详细** 三个按钮：
- **紧凑**：卡片收窄，隐藏详情区，适合快速浏览批量调整
- **舒适**：默认视图，详情区手动展开
- **详细**：全部展开详情区，适合逐项审查

密度选择会记住（localStorage），下次打开保持。

### 6. 左侧配置栏恢复已保存值

页面重载或切换 ASIN 后，**广告方向复选框会自动恢复上次保存的勾选**——不需要重新勾一遍。

如果你手动改过 ACOS/预算/方向，AI 刷新时**不会覆盖你的手动输入**。只有点「刷新推荐」按钮才会用 AI 新值覆盖。

### 7. 核心词管理弹窗

在广告活动卡片区域，标注为"核心词"的条目可以点击查看 **核心词判定详情**：
- 展示该词的语义冲突判定（pass / fail）及原因
- 展示是否被判定为语义核心词
- 运营可以手动**开启/关闭**某个词的核心词标记（覆盖 AI 判定）

## 二、核心按钮说明

### 1.「同意所选」按钮

**作用**：勾选 → 点「同意所选」→ 弹窗展示**调整详情表格** → 确认 → 真改 Amazon

确认弹窗现在会展示每项的：
| 活动名 | 关键词 | 动作 | 预算(当前→建议) | 出价(当前→建议) | 广告位 |

点「确认执行」后通过 ERP/MCP 下发，**不可撤销**。Toast 提示执行结果（成功数/失败数），如有挪组失败会单独分组展示。

### 2.「不同意所选」按钮

把勾选项标记为"不同意"，不改 Amazon，留拒绝记录。

### 3.「全选 / 取消全选」

在筛选栏右侧，一次性勾选/取消当前筛选结果里的所有可见卡片。

### 4.「组合预算调整」区域

在页面顶部的 sticky 控制区，展示 3 个活跃组合的预算值 + 低价捡漏组固定 $1。

- 点「回算修改」→ 弹窗展示 AI 回算建议 → 运营可手动修改各组预算 → 保存
- 点「执行」→ 确认后真改 Amazon 后台 Portfolio 预算
- 点「恢复」→ 恢复到 AI 建议值（存在手动覆盖时可见）

**注意**：只有已在 Amazon 后台创建过 Portfolio 的 SKU 才能成功执行。如果该 SKU 没有 Portfolio，会 Toast 提示"挪组失败"。

### 5.「生成调整建议」按钮

**何时用**：首次分析，或想重新跑 AI 分析生成新建议

**操作流程**：
1. 在左侧配置栏**完成并保存**前置配置（战略层 → 策略层 → 执行层）
2. 进入 Tab 5，点「生成调整建议(AI 分析)」
3. 出现全屏遮罩"AI 拼命分析中..."，可以点「放弃本次分析」取消
4. 3-5 分钟后自动完成，遮罩消失，展示新分析结果
5. 期间可以在 ERP 列表里操作其他 ASIN

⚠️ 期间不要重复点击！如果遮罩 60 秒没消失，点「放弃」后刷新页面重试。

## 三、典型操作场景

### 场景 1：同意 AI 部分建议

1. 在明细 tab 里勾选认可的项
2. 可切换「紧凑」密度快速浏览，切换「详细」密度逐项审查
3. 看顶部"调整后"数字和确认弹窗中的表格，确认总额合理
4. 点「同意所选」→ 弹窗确认 → 点「确认执行」
5. 看 Toast：成功数 / 失败数 / 挪组失败详情（如有）

### 场景 2：拒绝 AI 建议后重新分析

1. 点「全选」→「不同意所选」→ 确认
2. 回到左侧重新调整策略配置（广告目的/关键词/ACOS/预算/方向）
3. 保存后回到 Tab 5，点「生成调整建议」
4. 等 3-5 分钟出新结果

### 场景 3：调整组合总预算

1. 在 sticky 控制区找到"组合预算调整"
2. 点「回算修改」→ 弹窗中修改各组预算 → 保存
3. 满意后点「执行」→ 确认弹窗 → 真实修改 Amazon Portfolio 预算

### 场景 4：卡片点选快速操作

**点击卡片空白区域**即可勾选/取消勾选（不用非得点小复选框），拖选文字时不会触发勾选（防止误操作）。

## 四、常见报错处理

| Toast 提示 | 含义 | 怎么办 |
|---|---|---|
| **核心数据不足，缺失项：ACOS、CPC** | 该产品近 7 天没投广告 | 先激活广告，有花费数据后再分析 |
| **存在进行中分析事件，执行权已冻结** | 该 ASIN 正在跑分析 | 等 3-5 分钟刷新页面 |
| **该批次非最新批次，不可执行** | 看到的是老批次 | 切换到最新批次或强刷页面 |
| **部分下发成功：X 个成功 / Y 个失败** | 部分项成功，部分失败 | 看 Toast 后半段错误信息定位原因 |
| **挪组失败：精准主力组ID缺失，已跳过 N 个活动** | 该 SKU 没建对应 Portfolio | 在 Amazon Ads 后台创建 Portfolio，或仅用同意所选调单个活动 |
| **missing product identity: asin, shop_id...** | 缺少产品身份信息 | 检查地址栏参数是否完整 |
| **护栏告警：XX 条被修正** | AI 建议触发了安全规则，已自动修正 | 检查修正后的值是否合理，如有疑问找技术 |

## 七、安全提示

1. **「同意所选」+「确认执行」= 立即真改 Amazon**，无法回滚
2. 确认弹窗中的**表格详细列出每项的改动**（活动名/关键词/动作/预算/出价/广告位），执行前仔细核对
3. 核心词受系统保护，**不会被 AI 误淘汰**（即使 AI 判淘汰也会被拦下）
4. 上线 ≤3 天的新活动、复评后 ≤3 天的活动**受样本保护**，不会被淘汰
5. 数额异常（预算暴涨 10 倍、竞价跌为 $0.01）务必复核
6. 一次勾选建议 ≤ 30 项，避免批量超时
7. Toast 一直转圈时**别重复点确定**，等 60 秒再操作
8. 误改了**只能在 Amazon Ads 后台手工改回**
